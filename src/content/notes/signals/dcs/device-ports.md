# 器件端口术语表

> 全部条目取自教材原文（标注章节号），只收**"功能修饰语 + 端/输入/输出"**这一类端口名词，以及配套的地址、数据、控制类名词。

## 零、命名规律：先看懂这个，其余都是套用

中文教材给引脚命名，一律是 **【功能修饰语】+【端】** 的结构：

$$
\underbrace{\text{地址}}_{\text{干什么}}+\underbrace{\text{输入}}_{\text{方向}}+\underbrace{\text{端}}_{\text{是个引脚}}
$$

- **端** = 引脚的统称，可以不带方向（"地址端""数据端"），此时方向由上下文决定；
- **输入端 / 输出端** = 明确方向，考试里靠它判断"是几个口"；
- **输入/输出端**（带斜杠）= **双向**口，同一组线分时复用（如 SRAM 的 $I/O_0\sim I/O_7$）；
- **上划线** = 低电平有效。教材原话：「74148 输入和输出有效的逻辑电平都是低电平，因此输入、输出在符号上方加划线表示」（6.1）。

## 一、地址类

| 术语 | 英文 | 含义（教材原话/要点） | 出处 |
| --- | --- | --- | --- |
| 地址端 | address terminal | 「74138 也有三个地址端，因此将变量 A、B、C 分别接到三个地址端」 | 6.2 译码器 |
| 地址输入端 | address input | 「地址输入端从 000 按照二进制码的顺序变化到 111，就会在输出端轮流送出单个低脉冲节拍」 | 6.4 数据分配器 |
| 地址码 | address code | 「一个代表存储器地址的二进制地址码将放在一组称为地址总线的连线上」 | 10.1 存储器基本概念 |
| 地址码输入端 | address code input | 「在只读存储器的地址码输入端给定一个地址码后，便可在它的数据输出端得到一个确定数据」 | 10.4 ROM |
| 地址译码器 | address decoder | 「将一个存储器的地址代码，转换成一个有效的选通信号，从而选中对应的存储单元」 | 6.2 译码器 |
| 地址线 / 地址总线 | address bus | 「为了减少地址线的数量，采用了地址复用技术」（DRAM 行/列地址分时复用） | 10.2 DRAM |
| 行地址 / 列地址 | row / column address | DRAM 中同一组引脚分两次送入的地址 | 10.2 DRAM |
| 行选择线 | row select line | 存储单元矩阵中选中一整行的线（部分教材称"字线"） | 10.2.1 SRAM |

> **一句话**：地址类端口的作用永远是"**选中哪一个**"——选单元、选通道、选输出线。

## 二、数据类

| 术语 | 英文 | 含义（教材原话/要点） | 出处 |
| --- | --- | --- | --- |
| 数据端 | data terminal | 「4 路数据加在数据端 $D_0\sim D_3$」 | 6.3 数据选择器 |
| 数据输入端 | data input | 与地址端相对，是"被选中的内容" | 6.3 / 10.2 |
| 数据输出端 | data output | 「存储在由 $A_0\sim A_{14}$ 指定的单元中的 8 比特数据将出现在输出数据端上」 | 10.2.2 SRAM |
| 数据输入/输出端 | data I/O | 「8 个数据输入/输出端 $(I/O_0\sim I/O_7)$」——**双向**，读时作输出、写时作输入 | 10.2.2 SRAM |
| 串行输入端 | serial input | $D_{SR}$ 为右移串行输入端，$D_{SL}$ 为左移串行输入端 | 9.1 寄存器和移位寄存器 |
| 并行输入端 | parallel input | 「$D_0D_1D_2D_3$ 和 $Q_0Q_1Q_2Q_3$ 分别为并行输入端和并行输出端」 | 9.1 寄存器和移位寄存器 |
| 位线 | bit line | SRAM 存储单元通过传输门与「数据位线 $B$ 和 $\overline B$」相连 | 10.2.1 SRAM |

> **一句话**：数据类端口回答"**送什么 / 取什么**"。选择器、分配器、存储器都同时有地址类和数据类两组口，**别把 $D_i$ 当地址、把 $A_i$ 当数据**。

## 三、使能与控制类

| 术语 | 英文 | 含义（教材原话/要点） | 出处 |
| --- | --- | --- | --- |
| 使能端 | enable, EN | 「TTL 三态门是在普通门电路的基础上，通过增加控制端和控制电路构成的」；使能端决定器件**是否工作** | 4.3 TTL 三态门 |
| 输入使能端 | enable input, $EI$ | 「输入使能端控制编码器是否工作，当使能端为高电平时，编码器所有的输出端为高电平」 | 6.1 编码器 |
| 输出使能端 | output enable, $OE$ | SRAM 的 1 个输出使能端，控制数据口是否输出 | 10.2.2 SRAM |
| 片选端 | chip select, $CS$ | 多片系统中"选中哪一片"，未选中片输出高阻 | 10.2.2 SRAM |
| 控制端 | control | 泛称；三态门、锁存器都有（「7.2 带有控制端的锁存器」） | 4.3 / 7.2 |
| 写控制端 | write enable, $WE$ | 读写方向控制 | 10.2.2 SRAM |
| 加/减计数控制端 | $D/\overline U$ | 「为 0 时作加法计数，为 1 时作减法计数」 | 9.3 集成计数器 |
| 选通输出端 | strobe output, $Y_S$ | 「当它为 0 时，代表没有效的输入信号」——告诉下一级"我这片没被选中" | 6.1 编码器 |
| 扩展端 | expansion, $\overline{Y}_{EX}$ | 「可以用来扩展编码器」——级联扩展专用 | 6.1 编码器 |
| 高阻态 | high impedance, Hi-Z | 「除了上述两种状态的输出之外，还有高阻态的输出，也就是输出端的阻抗非常大」 | 4.3 TTL 三态门 |

> **一句话**：使能/控制类端口回答"**让不让它干活**"。三态门、片选、$OE$、$EI$ 本质是同一个思想——用一根线把器件从总线上"摘下来"。

## 四、时钟与置位类

| 术语 | 英文 | 含义（教材原话/要点） | 出处 |
| --- | --- | --- | --- |
| 时钟端 | clock, CP | 「锁存器一般没有时钟端，触发器受时钟控制」——**有没有时钟端是锁存器/触发器的分界** | 7 触发器 |
| 时钟输入端 | clock input | 「计数器的时钟输入端」 | 9.3 / 12.6 |
| 时钟脉冲输入端 | CP input | 「最低位触发器 $FF_0$ 的时钟脉冲输入端与计数脉冲 CP 相连接」 | 9.3 异步计数器 |
| 预置端 | preset, $S_D$ | 「$\overline S_D$ 和 $\overline R_D$……它们分别是预置端和清零端，低电平有效」 | 7 触发器 |
| 清零端 | clear, $R_D$ | 使 $Q=0$；分**异步清零**（不受 CP 控制）与**同步清零** | 7 / 9.3 |
| 置数端 / 预置数端 | load, $LD$ | 「利用其清零端或预置数端，外加适当的门电路」构成任意进制计数器 | 9.3 |
| 送数端 | load（同步） | 「状态转移是在时钟脉冲的上升沿同步完成的，因此 $LD$ 端被称为**同步送数端**」 | 9.3 集成计数器 |
| 复位端 | reset | 与清零端同义，多用于触发器语境 | 7 触发器 |

> **一句话**：**异步** = 不看时钟，来了就动；**同步** = 等时钟边沿。题目问"异步清零还是同步清零"就是在问这一句。

## 五、进位与借位类

| 术语 | 英文 | 含义（教材原话/要点） | 出处 |
| --- | --- | --- | --- |
| 进位输入端 | carry in, $C_{-1}$ | 「将低 4 位 74283 芯片进位输出端 $C_0$ 连接到高 4 位 74283 的进位输入端 $C_{-1}$」 | 6.7 算术运算电路 |
| 进位输出端 | carry out, $C_0$ | 向更高位的进位 | 6.7 |
| 进位产生项 | carry generate, $G_i$ | 本位一定产生进位 | 6.7 超前进位 |
| 进位传递项 | carry propagate, $P_i$ | 本位把低位进位传上去 | 6.7 超前进位 |
| 借位输出端 | borrow out | 「RCO 是进位/借位输出端」——可逆计数器在减法计数时该端表示借位 | 9.3 集成计数器 |
| 最大/最小输出端 | MAX/MIN | 可逆计数器的状态标志 | 9.3 |

> **一句话**：级联时**进位一定从低位流向高位**；比较器的级联输入则相反（低位结果送高位片），别记混。

## 六、易混辨析（考试就考这几组）

| 对比 | 区别 | 判定口诀 |
| --- | --- | --- |
| **地址端 vs 数据端** | 地址端选"哪一个"，数据端是"那个东西本身" | 选择器：$n$ 位地址 → $2^n$ 个数据端 |
| **输入端 vs 输出端 vs 输入/输出端** | 前者单向进、中者单向出、后者双向分时复用 | 带斜杠就是双向（$I/O$） |
| **使能端 vs 片选端** | 使能 = 让不让它工作；片选 = 多片里选哪一片 | 单片器件谈"使能"，多片系统谈"片选" |
| **$Y_S$ vs $Y_{EX}$** | $Y_S$ 告诉下级"我这片没选中"；$Y_{EX}$ 专门用于扩展 | $S$=status，$EX$=expand |
| **清零端 vs 置数端** | 清零把 $Q$ 全置 0；置数把外部数据装进去 | 清零不用数据线，置数要 |
| **异步 vs 同步** | 异步不看 CP、立即生效；同步等 CP 边沿 | 题目里出现"与 CP 无关"就是异步 |
| **进位输入 vs 进位输出** | 一个是"从低位收"，一个是"往高位送" | 低位片 $C_0$ → 高位片 $C_{-1}$ |
| **地址译码器 vs 通用译码器** | 地址译码器专指"地址码→选通信号"，用于存储器 | 6.2 明确分成两类 |

## 七、数量关系（本次选择题栽的就是这里）

| 器件 | 地址/输入 | 输出 | 关系 |
| --- | --- | --- | --- |
| 74138 译码器 | 3 个地址端 | 8 个输出端 | $2^3=8$ |
| 74151 数据选择器 | **3 个地址端** | **8 个数据端** | $2^3=8$（本次错题 19） |
| 74148 编码器 | 8 个输入端 | 3 个输出端 + $Y_S$ + $Y_{EX}$ | 反向 |
| 存储器 | $n$ 根地址线 | $2^n$ 个单元 | 地址线数决定容量 |
| 74138 做 4-16 扩展 | 4 个地址端 | 16 个输出端 | 两片 $2\times8$ |
| 乘法器 | $n$ 位 × $n$ 位 | — | 与门 $n^2$ 个（本次错题 8） |

## 八、怎么用这张表

1. **读题先划端口**：把题干里"××端"圈出来，分清是地址、数据还是控制——数量关系题几乎全在这一步定生死。
2. **画图先标方向**：地址/数据/控制三组线用三种颜色，级联时确认信号往哪个方向流。
3. **见到"有效电平"就问一句**：有没有上划线？低有效还是高有效？（74138 是"两低一高"，74148 全低有效）
