# 第七章 离散时间信号与系统变换域分析

## §7.1 引言

在上一章我们讨论了离散时间信号与系统的时域分析，按照连续时间信号与系统相同的分析方法，我们将讨论离散时间信号与系统的变换域分析。在连续时间信号与系统变换域分析中，我们分别讨论了傅里叶变换和拉普拉斯变换，在此我们主要讨论对应于拉普拉斯变换的序列的z变换，并简要介绍序列的傅里叶变换。

由拉普拉斯变换的分析方式，我们可以想象到序列的z变换的讨论内容，首先介绍序列的z变换定义及其基本序列的z变换，随后将讨论z变换的性质及z变换的逆变换。在序列的z变换基础上，应用z变换求解离散时间系统的响应。在讨论了序列及离散时间系统响应的z变换分析后，我们将通过z变换讨论系统的特性。类似于拉普拉斯变换，首先介绍离散时间系统的系统函数 $H(z)$，然后讨论 $H(z)$ 零极点位置与系统单位样值响应 $h(n)$ 增长与衰减的关系，并以此讨论系统的稳定性。在简要介绍序列的傅里叶变换之后，讨论系统频率响应的几何确定方法。最后讨论数字滤波器完成对模拟信号滤波的实现方法，实现连续时间信号与系统与离散时间信号与系统分析的有机结合。

从计算结果来看，序列的z变换等于相应抽样信号的拉普拉斯变换，所以z变换与拉普拉斯变换之间存在着一定的对应性。但正如上一章讨论一样，由于序列是在离散的时间点上存在，由此将导致其具有新的特点以及相应的结果，所以读者既应利用其对应性帮助理解z变换，也要注意其两者之间的差别，避免混淆。

下面我们将沿着上述的顺序，展开离散时间信号与系统的z变换讨论。

## §7.2 z 变换

### §7.2.1 z 变换的定义

对于序列 $x(n)$，其 z 变换 $X(z)$ 的定义为

$$X(z)=\mathcal{Z}\left[x(n)\right]=\sum_{n=-\infty}^{\infty}x(n)z^{-n}$$

类似于拉普拉斯变换，z变换分为单边z变换和双边z变换。上式为序列 $x(n)$ 的双边z变换，其单边z变换定义为

$$X(z)\;=\mathcal{Z}\left[x(n)\right]=\sum_{n=0}^{\infty}x(n)z^{-n}$$

在式(7.2.1)和式(7.2.2)中，$\mathcal{Z}$ 表示对序列取 z 变换，且 z 是复变量。显然，如果 $x(n)$ 为从 0 时刻开始取值的因果序列，则其双边 z 变换与单边 z 变换是等同的。

式(7.2.1)及式(7.2.2)表明，序列的z变换是复变量 $z^{-1}$ 的幂级数，其系数是序列 $x(n)$ 的样值，即

$$X(z)=\cdots+x(-2)z^{2}+x(-1)z+x(0)+x(1)z^{-1}+x(2)z^{-2}+\cdots$$

z 变换的定义可以借助抽样信号的拉普拉斯变换引出。若信号 $x(t)$ 经过理想抽样，则抽样信号 $x_{s}(t)$ 的表达式为

$$x_{s}\left(t\right)=x\left(t\right)\cdot\delta_{T}\left(t\right)=\sum_{n=-\infty}^{\infty}x\left(nT\right)\delta\left(t-nT\right)$$

式中 T 为抽样间隔。如果对上式取拉普拉斯变换，得到

$$X_{s}\left(s\right)=\int_{0}^{\infty}x_{s}\left(t\right)\mathrm{e}^{-s t}\mathrm{d}t=\int_{0}^{\infty}\left[\sum_{n=0}^{\infty}x\left(n T\right)\delta\left(t-n T\right)\right]\mathrm{e}^{-s t}\mathrm{d}t$$

将积分与求和的次序对调，并利用冲激函数的抽样特性，便可得到抽样信号的拉普拉斯变换

$$X_{s}(s)=\sum_{n=-\infty}^{\infty}x(nT)\mathrm{e}^{-snT}$$

此时，若引入一个新的复变量 z，令 $z=\mathrm{e}^{sT}$，或写为 $s = \frac{1}{T} \ln z$，则式 (7.2.6) 变成了复变量 z 的函数式 $X(z)$

$$X(z)=\sum_{n=-\infty}^{\infty}x(nT)z^{-n}$$

在离散时间系统中，通常令 T=1，则式(7.2.7)变成

$$X(z)=\sum_{n=-\infty}^{\infty}x(n)z^{-n}$$

其中 $z=\mathrm{e}^{sT}$ 式(7.2.4)到式(7.2.7)的讨论说明，如果序列 $x(n)$ 各样值与抽样信号 $x(t)\delta_T(t)$ 各冲激信号的强度相同，可借助符号 $z=\mathrm{e}^{sT}$ 将抽样信号的拉普拉斯变换移植来表示离散序列的 z 变换。这里引入抽样信号拉普拉斯变换的目的之一，是便于在后续 z 变换讨论中应用 z 变换与拉普拉斯变换的对应性。

### §7.2.2 z 变换的收敛域

如同拉普拉斯变换一样，z变换也存在收敛域问题。由定义可知，序列的z变换是 $z^{-1}$ 的幂级数，只有当该级数收敛即 $X(z)$ 为有限值时，z变换才存在。对任意给定的序列 $x(n)$，使得幂级数 $\sum_{n=-\infty}^{\infty}x(n)z^{-n}$ 或 $\sum_{n=0}^{\infty}x(n)z^{-n}$ 收敛的z的所有取值称为z变换 $X(z)$ 的收敛域，通常用ROC表示。

级数收敛的判别方法包括同号级数和变号级数，在高等数学中已有较多的讨论，读者可以参阅相关的数学书籍，这里介绍最常用的达兰贝尔判别法。对于变号级数 $\sum_{n=-\infty}^{\infty}x(n)z^{-n}$，满足条件

$$\lim_{n\to\infty}\left|\frac{x(n+1)z^{-(n+1)}}{x(n)z^{-n}}\right|=\rho$$

若 $\rho<1$，则级数绝对收敛；若 $\rho>1$，则级数发散；若 $\rho=1$，级数可能收敛也可能发散。

利用式（7.2.8）可以确定具体序列 z 变换的收敛域，但科学研究总是希望在具体研究个体的同时，能尽量得到一些定性的结论，以指导进一步的研究和应用，而基本的方法就是从定义的特点入手。我们不妨观察 z 变换稍微具体一点的表达式（7.2.3），可以发现在 n < 0 和 n > 0 时 z 变换中的 z 的幂次由正数变为负数，则相同的 z 对级数的收敛作用是不同的，例如 z = 0 在 n < 0 时不影响级数的收敛性，但在 n > 0 时将导致级数不收敛。同样地，对于 z = ∞，则情况正好相反。因此我们可以将序列分为三类：一是不存在 n < 0 样值的序列；二是不存在 n ≥ 0 样值的序列；三是同时包含 n ≥ 0 样值和 n < 0 样值的序列。实际上，我们可以发现，这和双边拉普拉斯变换收敛域的一般性讨论的分类方法是相同的，只不过拉普拉斯变换讨论中是分为 t ≥ 0 和 t < 0。下面我们采用和拉普拉斯变换中相同的形式，即通过基本序列分别讨论上述各种情况下序列 z 变换收敛域的特点。

#### 1. $n \geqslant 0$ 序列

在这里 $n \geqslant 0$ 序列即为因果序列，其满足 $x(n) = x(n)u(n)$ 的条件。对于基本指数序列 $x_{1}(n) = a^{n}u(n)$，则其 z 变换

$$X_{1}(z)=\sum_{n=0}^{\infty}x_{1}(n)z^{-n}=\sum_{n=0}^{\infty}\left(a z^{-1}\right)^{n}$$

根据式(7.2.8)可知，要使得 $X_{1}(z)$ 收敛，则要求

$$\lim_{n\to\infty}\left|\frac{a^{(n+1)}z^{-(n+1)}}{a^{n}z^{-n}}\right|=\left|az^{-1}\right|<1$$

因此 $X_1(z)$ 的收敛域为 $|z| > |a|$，如图 7.2.1 所示，其中斜线部分表示收敛域。

2. n < 0 序列

在这里 n<0 序列是指满足 $x(n)=x(n)u(-n-1)$ 条件的序列。对于基本指数序列 $x_{2}(n)=b^{n}u(-n-1)$，则其 z 变换

$$X_{2}\left(z\right)=\sum_{n=-\infty}^{-1}\left(b z^{-1}\right)^{n}=\sum_{n=1}^{\infty}\left(b^{-1}z\right)^{n}$$

根据式(7.2.8)可知，要使得 $X_{2}(z)$ 收敛，则要求

$$\lim_{n\to\infty}\left|\frac{\left(b^{-1}z\right)^{n+1}}{\left(b^{-1}z\right)^{n}}\right|=\left|b^{-1}z\right|<1$$

因此 $X_2(z)$ 的收敛域为 $|z| < |b|$，如图 7.2.2 所示，其中斜线部分表示收敛域。

#### 3. 双边序列

双边序列是同时包含 $n \geq 0$ 和 $n < 0$ 的序列，一般的处理方法是将其看做 $n \geq 0$ 序列与 $n < 0$ 序列之和，这和双边拉普拉斯变换的处理方法是相同的。对于基本指数序列 $x_3(n) = a^n u(n) + b^n u(-n-1)$，则其 $z$ 变换

$$X_{3}\left(z\right)=\sum_{n=0}^{\infty}\left(a z^{-1}\right)^{n}+\sum_{n=-\infty}^{-1}\left(b z^{-1}\right)^{n}$$

由1、2两种情况的讨论可知，$X_{3}(z)$ 的收敛域为 $\sum_{n=0}^{\infty}\left(az^{-1}\right)^{n}$ 和 $\sum_{n=-\infty}^{-1}\left(bz^{-1}\right)^{n}$ 收敛域的交集即 $\left|a\right|<\left|z\right|<\left|b\right|$，如图7.2.3所示，其中斜线部分表示收敛域。

显然，若 $|a| > |b|$，则 $\sum_{n=0}^{\infty}(az^{-1})^{n}$ 和 $\sum_{n=-\infty}^{-1}(bz^{-1})^{n}$ 不存在公共的收敛域，这意味着序列 $x_{3}(n) = a^{n}u(n) + b^{n}u(-n-1)$ 的 z 变换不存在。

在上述三种情况讨论的基础上，我们可以直接得到相关情况下的收敛域。如果序列长度有限，则上述三种情况分别成为 $n \geq 0$、$n < 0$ 以及过零点的有限长序列，其收敛域分别为 $z = \infty$、$z = 0$ 以及同时除去 0 和 $\infty$ 点的全部 z 平面。如果是过零点的有始无终或无始有终的序列，则收敛域分别为在图 7.2.1 及图 7.2.2 所示收敛域中去除 $z = \infty$ 和 $z = 0$ 点后的结果。下面我们通过两个例题对 z 变换的收敛域加以进一步的说明。

例题7.2.1 求有限长序列 $x(n)=\left\{\begin{array}{l}1,2,1\end{array}\right\}$ 的z变换。

$$n=-1$$

解：

$x(n)$ 的z变换为

$$X(z)=\sum_{n=-\infty}^{\infty}x(n)z^{-n}=z+2+\frac{1}{z}$$

所以除 z=0 和 $z=\infty$ 外，对任意 z，$X(z)$ 有界，因此其收敛域为 $0<|z|<\infty$。

例题 7.2.2 求序列 $x_{1}(n) = a^{n} u(n)$ 以及 $x_{2}(n) = -a^{n} u(-n -1)$ 的 z 变换。

解：

对于序列 $x_{1}(n)$,

$$X_{1}\left(z\right)=\sum_{n=-\infty}^{\infty}x_{1}\left(n\right)z^{-n}\ =\ \sum_{n=0}^{\infty}\left(a z^{-1}\right)^{n}$$

则 $X_{1}(z)$ 的收敛域为 $\left|z\right| > \left|a\right|$，且

$$X_{1}(z)=\frac{1}{1-a z^{-1}}=\frac{z}{z-a}$$

对于序列 $x_{2}(n)$,

$$\begin{aligned}X_{2}\left(z\right)&=\sum_{n=-\infty}^{\infty}-a^{n}u\left(-n-1\right)z^{-n}\\&=\sum_{n=-\infty}^{-1}-a^{n}z^{-n}\\&=-\sum_{n=1}^{\infty}\left(a^{-1}z\right)^{n}\end{aligned}$$

则 $X_{2}(z)$ 的收敛域为 $\left|z\right| < \left|a\right|$，且

$$X_{2}\left(z\right)=-\frac{a^{-1}z}{1-a^{-1}z}=\frac{z}{z-a}$$

显然，$x_{1}(n) \neq x_{2}(n)$，但对比 $X_{1}(z)$ 和 $X_{2}(z)$，可得 $X_{1}(z) = X_{2}(z)$，所不同的是 $X_{1}(z)$ 的收敛域为 $|z| > |a|$，$X_{2}(z)$ 的收敛域为 $|z| < |a|$。所以对于双边 z 变换而言，一定要明确标明其收敛域，这和双边拉普拉斯变换是一样的。

同样地，对于单边z变换，由于其收敛域都是z平面上大于某个半径的圆外部分，通常不专门标注收敛域不会引起歧义，这和单边拉普拉斯变换也是相同的。

由上面的讨论我们发现，z 变换收敛域与拉普拉斯变换的收敛域表现出明显的对应性，有必要对两者之间的关系进行进一步地说明。

### §7.2.3 z平面与s平面的关系

在前面介绍 z 变换定义时，已经引出了复变量 z 与 s 有如下关系

$$z=\mathrm{e}^{sT}$$

由拉普拉斯变换的定义，知道 $s = \sigma + j\omega$，则

$$z=\mathrm{e}^{(\sigma+\mathrm{j}\omega)T}=r\mathrm{e}^{\mathrm{j}\theta}$$

其中

$$r=\mathrm{e}^{\sigma T}$$

$$\theta=\omega T=2\pi\frac{\omega}{\omega_{\mathrm{s}}}$$

而 $\omega_{s}$ 为理想抽样的角频率。

由此，我们可以看到，$s = \sigma + j\omega$ 和 $z = re^{j\theta}$ 实际上是表示复数平面的两种坐标系，分别为直角坐标和极坐标，对此许多读者在高中数学中已经接触过。下面具体说明两者之间的对应关系。

1. 考虑 $\sigma$ 的变化

（1）当 $\sigma=0$ 时，相应的 $z=e^{j\theta}$。这说明 s 平面上的虚轴 $(\sigma=0)$ 对应于 z 平面上的单位圆；

（2）当 $\sigma > 0$ 时，$z = e^{\left| \sigma \right|} T e^{j\theta}$，且 $e^{\left| \sigma \right|} T > 1$。这说明 s 右半平面 $(\sigma > 0)$ 对应于 z 平面上单位圆外的区域；

（3）当 $\sigma < 0$ 时，$z = e^{-\left|\sigma\right|} e^{j\theta}$，且 $e^{-\left|\sigma\right|} < 1$。这说明 s 左半平面 $(\sigma < 0)$ 对应于 z 平面上单位圆内的区域。

2. 考虑 $\omega$ 的变化

（1）当 $\omega = 0$ 时，相应的 $z = e^{\sigma T}$。这说明 s 平面上的实轴 $(s = \sigma)$ 对应于 z 平面上的正实轴 $(\theta = 0)$，其中原点 $(\sigma = 0, \omega = 0)$ 对应于 z 平面上 z = 1 的点；

(2) 当 $\omega = \frac{k\omega_{\mathrm{s}}}{2}$，$(k = \pm1, \pm3, \cdots)$ 时，相应的平行于实轴的直线对应于 z 平面的负实轴。

（3）因为 $e^{j\omega T}$ 是以 $\omega_{s}=2\pi/T$ 为周期的函数，而 $\theta=\omega T$，因此当在 s 平面上沿着虚轴 $\omega$ 从 $-\pi/T$ 变化到 $\pi/T$ 时，在 z 平面上沿单位圆 $\theta$ 从 $-\pi$ 变化到 $\pi$，正好是一个圆周。$\omega$ 沿虚轴每变化 $\omega_{s}$，则 z 平面上 $\theta$ 沿单位圆转一圈。

图 7.2.4 直观化地给出了 s 平面与 z 平面的映射关系。

需要指出的是，上述 s 平面与 z 平面的对应关系以及抽样信号的拉普拉斯变换等值于序列的 z 变换，是一种数学上的关系，在物理意义上是有明确区别的。但在科学研究的过程中，人们往往利用这种数学上的关系，借鉴已有的研究结果去指导另一者的研究，例如在军用通信网络可靠性的研究中就可以借鉴城市自来水管道抗震研究的成果。这里，利用因果连续时间系统稳定性的讨论，基于 s 平面与 z 平面的对应关系，我们可以猜测因果离散时间系统稳定的条件是，$h(n)$ 的 z 变换的 $H(z)$ 极点位于 z 平面的单位圆里，后面的讨论将告诉我们这个猜测是正确的，有兴趣的读者不妨猜测一下其他情况。

### §7.2.4 典型序列的z变换

按照前面章节讨论的顺序，在介绍了 z 变换的定义之后，我们讨论基本序列的 z 变换

#### 1. 单位样值序列 $\delta(n)$

单位样值序列

$$\delta\left(n\right)=\left\{\begin{aligned}{1}&{}&{\left(n=0\right)}\\ {0}&{}&{\left(n\neq0\right)}\\ \end{aligned}\right.$$

取其z变换，得到

$$\mathcal{Z}\left[\begin{array}{c}{\delta(n)}\\ \end{array}\right]=\sum_{n=0}^{\infty}\delta(n)z^{-n}\;=\;1$$

由于任何 z 的取值都有 $z^{0}=1$，因此其收敛域为整个 z 平面。

#### 2. 单位阶跃序列 $u(n)$

单位阶跃序列

$$u\left(n\right)=\left\{\begin{aligned}&1&&\left(n\geqslant0\right)\\ &0&&\left(n<0\right)\end{aligned}\right.$$

取其z变换，得到

$$\mathcal{Z}\left[\begin{array}{c}{u\left(n\right)}\\ \end{array}\right]=\sum_{n=0}^{\infty}u\left(n\right)z^{-n}=\sum_{n=0}^{\infty}z^{-n}$$

若 $\left|z^{-1}\right|<1$，即 $\left|z\right|>1$，该级数收敛，此时有

$$\mathcal{Z}\left[\mathrm{u}(n)\right]=\frac{1}{1-z^{-1}}=\frac{z}{z-1}$$

可见，单位阶跃序列的 z 变换的收敛域为 z 平面上以原点为圆心的单位圆的外部。

#### 3. 因果指数序列 $a^n u(n)$

对于单边指数序列 $a^{n}u(n)$，例题 7.2.2 中已经给出了其 z 变换为

$$\mathcal{Z}\left[\begin{array}{l}{a^{n}u(n)}\\ \end{array}\right]=\frac{z}{z-a}$$

且收敛域为 $\left|z\right|>\left|a\right|$。

实际上，u(n)可以看作 $a^n u(n)$ 为 $a=1$ 的特例。在连续时间信号与系统的分析中，核心的基本信号是 $\delta(t)$ 和 $e^{-\alpha t} u(t)$，分别代表了奇异信号和指数类信号。同样地，在离散时间信号与系统的分析中，核心的基本序列是 $\delta(n)$ 和 $a^n u(n)$。斜变序列以及正弦和余弦序列等基本序列的 z 变换，可以在指数序列 $a^n u(n)$ 的 z 变换基础上，通过 z 变换的性质求得。下面我们将介绍 z 变换的性质。

## §7.3 z 变换的性质

序列的 z 变换的求解方法和连续时间信号傅里叶变换以及拉普拉斯变换的求解相同，通常不是直接把序列代入到 z 变换的定义式求解，而是以基本序列的 z 变换为基础，利用一般序列与基本序列之间的运算关系来求解。而这种时域中序列的运算关系在 z 域中的表现就是我们要讨论的 z 变换的性质。

对于 z 变换的性质，我们将同时介绍双边 z 变换的性质和单边 z 变换的性质。绝大多数性质对单边，双边 z 变换是相同的，少数对单、双边 z 变换有差别的性质，在讨论中将予以说明，请读者注意两者中的差别。

### §7.3.1 基于序列时间运算的性质

#### 1. 反褶性质

若序列 $x(n)$ 的双边 z 变换为

$$\mathcal{Z}\left[x(n)\right]=X(z),\alpha<\left|z\right|<\beta$$

则序列 x(-n) 的双边 z 变换为

$$\mathcal{Z}\left[\begin{array}{c}{x(-n)}\\ \end{array}\right]=\sum_{n=-\infty}^{\infty}x\left(\begin{array}{c}{-n}\end{array}\right)z^{-n}$$

令 k = -n，则

$$\mathcal{Z}\left[\begin{array}{c}{x(-n)}\\ \end{array}\right]=\sum_{k=-\infty}^{\infty}x(k)\left(z^{-1}\right)^{-k}=X(z^{-1})$$

且收敛域为 $\alpha < |z^{-1}| < \beta$，即 $1/\alpha > |z| > 1/\beta$。

#### 2. 扩展性质

若序列 $x(n)$ 的双边 z 变换为

$$\mathcal{Z}[x(n)]=X(z),\alpha<\mid z\mid<\beta$$

其中 $\alpha$ 和 $\beta$ 为大于 0 的常数。假设常数 a > 0，则序列 $x\left(\frac{n}{a}\right)$ 的双边 z 变换为

$$\mathcal{Z}\left[x\left(\frac{n}{a}\right)\right]=\sum_{n=-\infty}^{\infty}x\left(\frac{n}{a}\right)z^{-n}$$

令 $k = \frac{n}{a}$，则

$$\mathcal{Z}\Big[x\Big(\frac{n}{a}\Big)\Big]=\sum_{k=-\infty}^{\infty}x(k)(z^{a})^{-k}=X(z^{a})$$

且收敛域为 $\alpha < |z^a| < \beta$，即 $\alpha^{\frac{1}{a}} < |z| < \beta^{\frac{1}{a}}$。

单边 z 变换的扩展特性与双边 z 变换相同。当 a < 0 时，则可将运算看作扩展与反褶的组合，相关结论请读者自行推导。

#### 3. 位移性质

位移是序列比较常见的运算，包括左移和右移两种情况，在单边z变换中由于序列的位移可能导致从n=0开始的序列样值增加和减少，而双边z变换只存在序列位置不同，不存在序列样值的增减问题，因此两者的性质有较大差别。

##### （1）双边z变换

若序列 $x(n)$ 的双边 z 变换为

$$\mathcal{Z}\left[x(n)\right]=X(z),\alpha<\left|z\right|<\beta$$

假设整数 m > 0，则位移序列 $x(n \pm m)$ 的双边 z 变换满足

$$\mathcal{Z}\left[\begin{array}{c}{x(n\pm m)}\\ \end{array}\right]=z^{\pm m}X(z),\ \alpha<\mid z\mid<\beta$$

根据双边z变换的定义，可得

$$\mathcal{Z}\left[\;x(n\pm m)\;\right]=\sum_{n=-\infty}^{\infty}x(n\pm m)z^{-n}$$

令 $k = n \pm m$，则

$$\begin{aligned}\mathcal{Z}\left[x\left(n\pm m\right)\right]&=\sum_{n=-\infty}^{\infty}x(k)z^{\pm m-k}=z^{\pm m}\sum_{n=-\infty}^{\infty}x(k)z^{-k}\\&=z^{\pm m}X(z)\end{aligned}$$

其收敛域仍然为 $\alpha < |z| < \beta$。

式(7.3.3)表明，序列 $x(n)$ 在时域位移 $\pm m$ 位的运算，相当于其 z 变换 $X(z)$ 乘以 $z^{\pm m}$，这和双边拉普拉斯变换的微分积分特性是相对应的，也就是说，从信号的变换与变换域因子运算关系来看，序列右移对应于连续信号的微分，左移对应于积分。

##### （2）单边z变换

若 $x(n)$ 是双边序列，其单边 z 变换为

$$\begin{array}{r}{\mathcal{Z}\left[\begin{array}{l}{x(n)u(n)}\end{array}\right]=X(z),\quad\left\vert z\right\vert>a}\end{array}$$

则位移序列 $x(n \pm m)$ 的单边 z 变换为

$$\mathcal{Z}\left[\begin{array}{c}{x(n+m)u(n)}\\ \end{array}\right]=z^{m}\left[\begin{array}{c}{X(z)}\\ \end{array}-\sum_{k=0}^{m-1}x(k)z^{-k}\right],\quad\left|z\right|>a$$

$$\mathcal{Z}\left[\begin{array}{c}{x\left(n-m\right)u\left(n\right)}\\ \end{array}\right]=z^{-m}\left[X\left(z\right)\right.+\sum_{k=-m}^{-1}x\left(k\right)z^{-k}\left.\right],\left|z\right|>a$$

根据单边z变换的定义，可得

$$\mathcal{Z}\left[\begin{matrix}{x\left(\begin{matrix}{n+m}\\ \end{matrix}\right)u\left(\begin{matrix}{n}\\ \end{matrix}\right)}\\ \end{matrix}\right]=\sum_{n=0}^{\infty}x\left(\begin{matrix}{n+m}\\ \end{matrix}\right)z^{-n}=z^{m}\sum_{n=0}^{\infty}x\left(\begin{matrix}{n+m}\\ \end{matrix}\right)z^{-(n+m)}$$

令 k=n+m，则有

$$\begin{aligned}\mathcal{Z}\left[\;x\left(n+m\right)u\left(n\right)\;\right]&=\;z^{m}\sum_{k=m}^{\infty}x\left(k\right)z^{-k}\\&=\;z^{m}\left[\;\sum_{k=0}^{\infty}x\left(k\right)z^{-k}\;-\;\sum_{k=0}^{m-1}x\left(k\right)z^{-k}\;\right]\\&=\;z^{m}\left[\;X\left(z\right)\;-\;\sum_{k=0}^{m-1}x\left(k\right)z^{-k}\;\right]\\ \end{aligned}$$

进一步，对于因果序列 $x(n)$ 而言，式(7.3.5)右边的 $\sum_{k=-m}^{-1} x(k) z^{-k}$ 项等于零，则序列右移的单边 z 变换为

$$\mathcal{Z}\left[\begin{matrix}{x(n-m)u(n)}\\ \end{matrix}\right]=z^{-m}X(z)$$

而左移序列的单边 z 变换仍为式(7.3.4)。

### §7.3.2 基于序列幅度运算的性质

基于序列幅度运算的性质包括序列幅度的四则运算，对于连续时间信号还包括积分和微分运算。如同傅里叶变换和拉普拉斯变换的讨论，我们将一般信号的相乘运算特性归类到变换域卷积特性；与特殊序列的相乘运算特性归类到z域特性；而序列不存在微分和积分运算，因此这里只讨论序列的加减运算特性，即z变换的线性。

若序列 $x_{1}(n)$ 和 $x_{2}(n)$ 的 z 变换分别为

$$\begin{aligned}\mathcal{Z}\left[\;x_{1}(n)\;\right]&=X_{1}(z)\quad\left(\alpha_{1}<\left|z\right|<\beta_{1}\right)\\\mathcal{Z}\left[\;x_{2}(n)\;\right]&=X_{2}(z)\quad\left(\alpha_{2}<\left|z\right|<\beta_{2}\right)\end{aligned}$$

则对任意常数 $c_{1}$ 和 $c_{2}$，有

$$\mathcal{Z}\left[c_{1}x_{1}(n)+c_{2}x_{2}(n)\right]=c_{1}X_{1}\left(z\right)+c_{2}X_{2}\left(z\right)$$

基于收敛域的定义，上式结果的收敛域为 $X_1(z)$ 收敛域和 $X_2(z)$ 的交集，即 $\max(\alpha_1, \alpha_2) < |z| < \min(\beta_1, \beta_2)$。一般来说，凡是有多个序列参与的运算，其 $z$ 变换的收敛域为所有参与运算的序列 $z$ 变换收敛域的交集，所以通常不大于单个序列 $z$ 变换的收敛域。但是，若在运算过程中，出现不同序列 $z$ 变换的零点和极点抵消的情况，则运算后的收敛域可能扩大。

例如，序列 $u(n)$ 和 $u(n-1)z$ 变换的收敛域都是 $|z| > 1$，当进行减法运算时，即 $u(n) - u(n-1)$，由于运算结果为 $\delta(n)$，而 $\mathcal{Z}[\delta(n)]$ 的收敛域为全 $z$ 平面，则收敛域相应地扩大为全 $z$ 平面。再从 $z$ 域角度来看，$u(n)$ 和 $u(n-1)z$ 变换的极点均为 $z = 1$，而基于线性关系将两者的 $z$ 变换相减时出现了 $z = 1$ 的零点，零极点抵消，收敛域扩大。

线性是一种较为直观和简单的特性，在应用中关键是发现信号之间的线性关系，例如利用线性关系可以求得常用的正弦或余弦序列的 z 变换。

例题 7.3.1 求因果余弦序列 $\cos(\omega_{0}n)u(n)$ 的 z 变换。

解：

利用欧拉公式，得到

$$\cos(\omega_{0}n)=\frac{1}{2}(\mathrm{e}^{\mathrm{j}\omega_{0}n}+\mathrm{e}^{-\mathrm{j}\omega_{0}n})$$

因为

$$\mathcal{Z}\left[\mathrm{e}^{\pm\mathrm{j}\omega_{0}n}\mathrm{u}\left(n\right)\right]=\frac{z}{z-\mathrm{e}^{\pm\mathrm{j}\omega_{0}}},\quad\left|z\right|>1$$

则

$$\begin{aligned}\mathcal{Z}\left[\cos\left(\omega_{0}n\right)u\left(n\right)\right]&=\frac{1}{2}\left(\frac{z}{z-\mathrm{e}^{\mathrm{j}\omega_{0}}}+\frac{z}{z-\mathrm{e}^{-\mathrm{j}\omega_{0}}}\right)\\&=\frac{z^{2}-z\cos\omega_{0}}{z^{2}-2z\cos\omega_{0}+1}\quad\left|z\right|>1\end{aligned}$$

同样地，可以得到相应的正弦序列的 z 变换，即

$$\mathcal{Z}[\sin(\omega_{0}n)u(n)]=\frac{z\sin\omega_{0}}{z^{2}-2\cos\omega_{0}+1},\quad|z|>1$$

### §7.3.3 基于z域运算的性质

需要指出的是序列在时间取值上是离散的，但其z变换却是z变量的连续函数。序列z变换的z域运算可以通过在时域中序列乘以特殊的序列加以实现，而从时域角度来看，特殊序列在乘法运算中，可以将其由一般的运算变量看作为某种运算关系，实现z域中的特定运算。这在连续信号的傅里叶变换和拉普拉斯变换的讨论中我们已经指出过。在此基础上，可以考虑将其他信号或序列转化为特殊信号或序列，从而得到新的运算规则，这种方法在实际的科学研究中并不乏见。下面我们介绍z域中的微分运算和压扩运算。

#### 1. z 域微分——序列线性加权

对于序列 $x(n)$,

$$X(z)=\sum_{n=-\infty}^{\infty}x(n)z^{-n},\ \alpha<\mid z\mid<\beta$$

将上式两边对 z 求导数，得

$$\frac{\mathrm{d}X(z)}{\mathrm{d}z}=\frac{\mathrm{d}}{\mathrm{d}z}\sum_{n=-\infty}^{\infty}x(n)z^{-n}$$

交换求导与求和的次序，得到

$$\begin{aligned}\frac{\mathrm{d}X\left(z\right)}{\mathrm{d}z}&=\sum_{n=-\infty}^{\infty}x\left(n\right)\frac{\mathrm{d}}{\mathrm{d}z}\left(z^{-n}\right)\\&=-\ z^{-1}\sum_{n=-\infty}^{\infty}nx\left(n\right)z^{-n}\end{aligned}$$

由z变换的定义可得

$$\frac{\mathrm{d}X(z)}{\mathrm{d}z}=-z^{-1}\mathcal{Z}\left[n x(n)\right]$$

所以得到

$$\mathcal{Z}[n x(n)]=-z\frac{\mathrm{d}X(z)}{\mathrm{d}z},\quad\alpha<|z|<\beta$$

也就是说，序列线性加权（乘以 n）的 z 变换，等于其 z 变换取导数且乘以 $(-z)$。由于 $X(z)$ 是复变量 z 的幂级数，其导数是具有相同收敛域的另一个

幂级数，故式(7.3.8)的收敛域与 $X(z)$ 的收敛域相同。

上述结果推广至 $x(n)$ 乘以 n 的正整数 m 次幂的情况，可得

$$\mathcal{Z}\left[n^{m}x(n)\right]=\left[-z\frac{\mathrm{d}}{\mathrm{d}z}\right]^{m}X(z),\alpha<\mid z\mid<\beta$$

式中，符号 $\left[-z\frac{d}{dz}\right]^{m}$ 作用在 $X(z)$ 上表示

$$-z\frac{\mathrm{d}}{\mathrm{d}z}\left\{-z\frac{\mathrm{d}}{\mathrm{d}z}\left[-z\frac{\mathrm{d}}{\mathrm{d}z}\cdots\left(-z\frac{\mathrm{d}}{\mathrm{d}z}X(z)\right)\right]\right\}$$

共求导 m 次。

显然，我们可以直接利用式(7.3.8)来求另一个基本序列——斜变序列 $nu(n)$ 的z变换。由于 $\mathcal{Z}[u(n)]=\frac{z}{z-1}$，所以

$$\mathcal{Z}\left[nu\left(n\right)\right]=-z\frac{\mathrm{d}}{\mathrm{d}z}\mathcal{Z}\left[u\left(n\right)\right]=-z\frac{\mathrm{d}}{\mathrm{d}z}\left(\frac{z}{z-1}\right)=\frac{z}{\left(z-1\right)^{2}}$$

#### 2. z 域压扩—序列指数加权

若已知序列 $x(n)$ 满足

$$\mathcal{Z}[{~x(~n~)~}]=X(z)\quad(\alpha<\mid z\mid<\beta)$$

则 $x(n)$ 乘指数序列 $a^{n}$ 后的 z 变换为（其中 a 为非零常数），则

$$\mathcal{Z}\left[\begin{array}{c}{a^{n}x\left(n\right)}\\ \end{array}\right]=\sum_{n=-\infty}^{\infty}a^{n}x\left(n\right)z^{-n}=\sum_{n=-\infty}^{\infty}x\left(n\right)\left(\frac{z}{a}\right)^{-n}$$

由 z 变换的定义，得到

$$\mathcal{Z}\left[a^{n}x(n)\right]=X\left(\frac{z}{a}\right)\quad\left(\alpha<\left|\frac{z}{a}\right|<\beta\right)$$

可见，x(n)乘以指数序列对应于X(z)在z平面尺度的压扩。利用式(7.3.10)，可以直接得到

$$\mathcal{Z}\left[a^{-n}x(n)\right]=X(az)\quad(\alpha<\mid az\mid<\beta)$$

$$\mathcal{Z}\left[(-1)^{n}x(n)\right]=X(-~z)\quad(\alpha<|z|<\beta)$$

式(7.3.12)显示，通过时域乘以 $(-1)^{n}$，可以实现序列z变换在z域中的反褶运算。

### §7.3.4 基于卷积运算的性质

#### 1. 时域卷积特性

若 $x_{1}(n)$ 和 $x_{2}(n)$ 的 z 变换分别为

$$\begin{aligned}{X_{1}\left(z\right)}&{{}=\mathcal{Z}\left[\left.x_{1}\left(n\right)\right.\right]}&{}&{{}\left(\alpha_{1}<\left|z\right|<\beta_{1}\right)}\\ {X_{2}\left(z\right)}&{{}=\mathcal{Z}\left[\left.x_{2}\left(n\right)\right.\right]}&{}&{{}\left(\alpha_{2}<\left|z\right|<\beta_{2}\right)}\\ \end{aligned}$$

则

$$\mathcal{Z}\left[\;x_{1}(n)\bigotimes x_{2}(n)\;\right]=X_{1}\left(z\right)X_{2}\left(z\right)$$

其收敛域一般为 $\max(\alpha_1, \alpha_2) < |z| < \min(\beta_1, \beta_2)$，进一步的情况在线性特性的讨论中已有说明。

根据双边z变换的定义，有

$$\begin{aligned}\mathcal{Z}\left[\;x_{1}(n)\otimes x_{2}(n)\;\right]&=\sum_{n=-\infty}^{\infty}\left[\;x_{1}(n)\otimes x_{2}(n)\;\right]z^{-n}\\&=\sum_{n=-\infty}^{\infty}\sum_{m=-\infty}^{\infty}x_{1}(m)x_{2}(n-m)z^{-n}\\&=\sum_{m=-\infty}^{\infty}x_{1}(m)\sum_{n=-\infty}^{\infty}x_{2}(n-m)z^{-(n-m)}z^{-m}\\&=\sum_{m=-\infty}^{\infty}x_{1}(m)z^{-m}X_{2}(z)\\ \end{aligned}$$

所以

$$\mathcal{Z}\left[\;x_{1}\left(n\right)\bigotimes x_{2}\left(n\right)\;\right]=X_{1}\left(z\right)X_{2}\left(z\right)$$

这说明时域中的卷积运算对应于 z 域中的乘积运算，这和连续时间信号傅里叶变换和拉普拉斯变换的情况相同。

#### 2. z 域卷积特性

若两 $x_{1}(n)$ 和 $x_{2}(n)$ 的 z 变换分别为：

$$\begin{aligned}{\mathcal{Z}\left[\begin{array}{c c}{x_{1}(n)}\\ \end{array}\right]}&{{}=X_{1}(z)}&{(\alpha_{1}<\mid z\mid<\beta_{1})}\\ {\mathcal{Z}\left[\begin{array}{c c}{x_{2}(n)}\\ \end{array}\right]}&{{}=X_{2}(z)}&{(\alpha_{2}<\mid z\mid<\beta_{2})}\\ \end{aligned}$$

则

$$\mathcal{Z}\left[\begin{array}{c}{x_{1}\left(n\right)x_{2}\left(n\right)}\\ \end{array}\right]=\frac{1}{2\pi\mathrm{j}}\oint_{c}X_{1}\bigg(\frac{z}{v}\bigg)X_{2}\left(v\right)v^{-1}\mathrm{d}v$$

收敛域一般为 $\alpha_1\alpha_2 < |z| < \beta_1\beta_2$。式中 $C$ 表示为 $X_1\left(\frac{z}{v}\right)$ 与 $X_2(v)$ 收敛域重叠部分内逆时针方向的围线。式(7.3.14)的证明过程与时域卷积特性证明相似，有兴趣的读者可以自行推导。

### §7.3.5 基于z变换定义的性质

一般来说，应该首先介绍基于变换定义的性质，之所以在最后讨论，是因为讨论中要用到前面介绍的性质。

#### 1. 初值定理

若 $x(n)$ 是因果序列，已知

$$X(z)=\mathcal{Z}[x(n)]=\sum_{n=0}^{\infty}x(n)z^{-n}$$

则

$$x(0)=\lim_{z\to\infty}X(z)$$

因为

$$X(z)=\sum_{n=0}^{\infty}x(n)z^{-n}=x(0)+x(1)z^{-1}+x(2)z^{-2}+\cdots$$

当 $z \to \infty$，在上式的级数中除了第一项 x(0) 外，其他各项都趋近于零，所以可得

$$\lim_{z\to\infty}X(z)=\lim_{z\to\infty}\sum_{n=0}^{\infty}x(n)z^{-n}=x(0)$$

#### 2. 终值定理

若 $x(n)$ 是因果序列，已知

$$X(z)\;=\mathcal{Z}[x(n)]=\sum_{n=0}^{\infty}x(n)z^{-n}$$

则

$$x(\infty)=\lim_{n\rightarrow\infty}x\left(n\right)=\lim_{z\rightarrow1}\left[\left(z-1\right)X\left(z\right)\right]$$

应用线性、位移性质可以得到

$$\mathcal{Z}\left[\begin{matrix}{x(n+1)}&{-x(n)}\\ \end{matrix}\right]=z X(z)-z x(0)-X(z)=(z-1)X(z)-z x(0)$$

取 $z \to 1$ 的极限，得

$$\begin{aligned}\lim_{z\to1}(z-1)X(z)&=x(0)+\lim_{z\to1}\sum_{n=0}^{\infty}\left[x(n+1)-x(n)\right]z^{-n}\\&=x(0)+\left[x(1)-x(0)\right]+\left[x(2)-x(1)\right]+\cdots\\&=x(0)-x(0)+x(\infty)\end{aligned}$$

所以

$$\lim_{z\to1}(z-1)X(z)=x(\infty)$$

应用终值定理的前提是序列存在确定性终值，也就是说只有当 $n \to \infty$，$x(n)$ 收敛才可应用。从变换域来说，$X(z)$ 的极点必须处在单位圆内（或一阶极点位于 $z = +1$ 的单位圆上），对此我们在后面关于系统稳定性的讨论中会加以说明。下面我们通过一个简单例题给读者一个直观的感受。

例题7.3.2 已知某一因果序列的z变换为 $X(z)=\frac{z}{z-a},\quad|z|>|a|$（其中a为实数）。求 $x(0)$、$x(1)$ 及 $x(\infty)$。

解：

由初值定理有

$$x(0)=\lim_{z\to\infty}X(z)=\lim_{z\to\infty}\frac{z}{z-a}=1$$

根据位移特性有

$$\mathcal{Z}\left[\begin{matrix}{x(n+1)\operatorname{u}(n)}\\ \end{matrix}\right]=z\left[\begin{matrix}{X(z)}\\ \end{matrix}\right.-x(0)]$$

对上式应用初值定理有

$$x\left(1\right)=\lim_{z\rightarrow\infty}z\left[X\left(z\right)-x\left(0\right)\right]=\lim_{z\rightarrow\infty}\left(\frac{z^{2}}{z-a}-z\right)=a$$

由终值定理有

$$x\left(\ \infty\ \right)\ =\lim_{z\rightarrow1}\left(z-1\ \right)X\left(z\ \right)\ =\lim_{z\rightarrow1}\left(z-1\ \right)\left(\frac{z}{z-a}\right)\ =\left\{\begin{matrix}0\quad\left|a\right|<1\\1\quad a=1\\\end{matrix}\right.$$

实际上，通过前面基本序列 $z$ 变换的讨论，我们已经知道上面例题中的序列 $x(n) = a^n u(n)$。显然当 $|a| < 1$ 及 $a = 1$ 时以上结果正确。当 $a = -1$ 时原序列为 $x(n) = (-1)^n u(n)$，其终值不存在；当 $|a| > 1$ 时，终值发散，不存在。

### §7.3.6 z 变换性质的应用

与求解连续时间信号傅里叶变换以及拉普拉斯变换的方法相同，一般序列的z变换主要通过该序列与基本序列的运算关系，以基本序列的z变换为基础，利用体现运算关系的z变换的性质，求得其相应的z变换。虽然问题的关键是序列间的运算关系，但前提和基础是选取合适的基本序列。由于离散序列不存在微分和积分运算，所以相对连续时间信号简单一些。

例题 7.3.1 就是直接利用 z 变换的性质求解常用序列 z 变换的示例，下面我们通过例题讨论稍微复杂一点的情况。

例题 7.3.3 已知 $x(n)=a^{n-2}$，求 $x(n)$ 的单边 z 变换 $X(z)$。

解：

本题讨论两种解法。

方法一 应用位移性质。令 $x_{1}(n)=a^{n}$，则 $x_{1}(n)$ 的单边 z 变换为

$$X_{1}\left(z\right)=\mathcal{Z}\left[a^{n}\right]=\mathcal{Z}\left[a^{n}u\left(n\right)\right]=\frac{z}{z-a},\quad\left|z\right|>\left|a\right|$$

根据单边z变换位移性质，则

$$\begin{aligned}X(z)&=\mathcal{Z}\left[a^{n-2}u(n)\right]=\mathcal{Z}\left[x_{1}(n-2)u(n)\right]=z^{-2}\left[X_{1}(z)+\sum_{k=-2}^{-1}x_{1}(k)z^{-k}\right]\\&=z^{-2}\left[\frac{z}{z-a}+\sum_{k=-2}^{-1}a^{k}z^{-k}\right]=\frac{a^{-2}z}{z-a},\quad\left|z\right|>\quad\left|a\right|\end{aligned}$$

方法二 将位移作为序列的加权。因为 $x(n) = a^{n-2} = a^{-2}a^n$，则其单边 z 变换为

$$\begin{array}{r}{\mathcal{Z}\left[x~(n~)\right]=a^{-2}\mathcal{Z}\left[a^{n}u(n)\right]=a^{-2}\frac{z}{z-a}}\end{array}$$

因为序列乘以一个常数不改变其 z 变换的收敛域，则 $X(z)$ 的收敛域为 $\left|z\right| > \left|a\right|$。

显然，第二种方法比第一种简单得多，其关键是将序列位移运算转换为序列乘以一个常数，从而简化处理过程。这就是通过改变观察问题的角度而得到的效果，实际上就是转变思维方式的一种具体体现。

例题 7.3.4 已知 $x(n) = 3^n [u(n+1) - u(n-2)]$，求 $x(n)$ 的双边 z 变换及其收敛域。

解：

本题我们可以考虑用3种方法来求解。

方法一 在拉普拉斯变换的位移特性中，我们曾指出应注意 $x(t)u(t)$、$x(t-t_{0})u(t)$、$x(t)u(t-t_{0})$ 以及 $x(t-t_{0})u(t-t_{0})$ 的关系。对于离散序列，我们同样也注意区别 $x(n)u(n)$、$x(n-n_{0})u(n)$、$x(n)u(n-n_{0})$ 以及 $x(n-n_{0})u(n-n_{0})$ 的异同。将 $x(n)$ 表示为

$$\begin{aligned}x(n)=&3^{n}u(n+1)-3^{n}u(n-2)\\=&3^{-1}\cdot3^{n+1}u(n+1)-3^{2}\cdot3^{n-2}u(n-2)\end{aligned}$$

由于

$$\mathcal{Z}\left[3^{n}u(n)\right]=\frac{z}{z-3},\quad\left|z\right|>3$$

根据双边z变换位移性质，得

$$\mathcal{Z}\left[3^{n+1}u\left(n+1\right)\right]=z\cdot\frac{z}{z-3}=\frac{z^{2}}{z-3},\quad3<\left|z\right|<\infty$$

$$\mathcal{Z}\left[3^{n-2}u(n-2)\right]=z^{-2}\cdot\frac{z}{z-3}=\frac{1}{z(z-3)},\quad|z|>3$$

根据线性性质，得到

$$\begin{aligned}X(z)=\mathcal{Z}\left[x(n)\right]=&\frac{z^{2}}{3(z-3)}-\frac{9}{z(z-3)}=\frac{z^{3}-27}{3z(z-3)}\\ =&\frac{z^{2}+3z+9}{3z},\quad\left.0<\mid z\mid<\infty\right.\end{aligned}$$

方法二 由于 $x(n)$ 为有限长序列，所以将 $x(n)$ 表示为

$$x{\left(n\right)}=3^{-1}\delta{\left(n+1\right)}+3^{0}\delta{\left(n\right)}+3^{1}\delta{\left(n-1\right)}$$

由于

$$\mathcal{Z}\left[\begin{array}{l}{\delta\left(n\right)}\end{array}\right]=1$$

应用 z 变换位移性质，得到

$$\begin{aligned}X(z)&=\mathcal{Z}\left[x(n)\right]=3^{-1}z+1+3z^{-1}\\&=\frac{z}{3}+1+\frac{3}{z}=\frac{z^{2}+3z+9}{3z}\end{aligned}$$

显然，除了0和 $\infty$ 之外，上式在 $z$ 平面所有点收敛，故收敛域为 $0<|z|<\infty$。

方法三 我们将 $3^n$ 看作指数加权因子，对 $[u(n+1) - u(n-2)]$ 的 $z$ 变换进行 $z$ 域扩展运算。由于

$$\mathcal{Z}\left[u\left(n+1\right)-u\left(n-2\right)\right]=\frac{z^{2}}{z-1}-\frac{z^{-1}}{z-1}=\frac{z^{2}-z^{-1}}{z-1}$$

根据z域压扩性质，

$$X(z)\ =\frac{\left(\frac{z}{3}\right)^{2}-\left(\frac{z}{3}\right)^{-1}}{\frac{z}{3}-1}=\frac{z^{2}-27z^{-1}}{3z-9}=\frac{z^{3}-27}{3z(z-3)}=\frac{z^{2}+3z+9}{3z}$$

同样地，收敛域为 $0 < |z| < \infty$。

在上面例题中，第一种方法以 $3^n u(n)$ 作为基本信号；第二种方法以 $\delta(n)$ 作为基本信号；第三种方法以 $[u(n+1) - u(n-2)]$ 作为基本信号。第二种方法适用于序列较短的有限长序列，第三种方法实际上说明了我们前面所讨论的基本信号 $a^n u(n)$ 是可以看作对 $u(n)$ 指数加权而导致 $z$ 域压扩。但从另一方面来看，$u(n)$ 又是 $a^n u(n)$ 在 $a=1$ 时的特例。

例题 7.3.5 计算 $na^{n}u(n)$ 序列的 z 变换 (0 < a < 1)。

解：

本题讨论3种求解方法。

方法一 应用 z 域微分特性

因为

$$\mathcal{Z}\left[\begin{array}{l}{a^{n}u\left(n\right)}\\ \end{array}\right]=\frac{z}{z-a},\quad\left|z\right|>\left|a\right|$$

应用z域微分特性，可得

$$\mathcal{Z}\left[n a^{n}u(n)\right]=-z\frac{\mathrm{d}}{\mathrm{d}z}\left(\frac{z}{z-a}\right)=\frac{a z}{\left(z-a\right)^{2}}$$

由于微分不改变收敛域，则上式的收敛域为 $|z| > |a|$。

方法二 应用 z 域微分和 z 域压扩性质。

因为

$$\mathcal{Z}\left[\mathrm{u}(n)\right]=\frac{z}{z-1},\quad\left|z\right|>1$$

应用z域微分性质，得到

$$\mathcal{Z}\left[nu\left(n\right)\right]=\frac{z}{\left(z-1\right)^{2}},\quad\left|z\right|>1$$

再应用z域压扩性质，得到

$$\begin{align*}\mathcal{Z}\left[a^{n} n u(n)\right]&=\frac{\frac{z}{a}}{\left(\frac{z}{a}-1\right)^{2}},\quad\left|\frac{z}{a}\right|>1\\&=\frac{az}{(z-a)^{2}},\quad\left|z\right|>\left|a\right|\end{align*}$$

方法三 应用 z 域卷积性质。

因为

$$X_{1}\left(z\right)=\mathcal{Z}\left[nu\left(n\right)\right]=\frac{z}{\left(z-1\right)^{2}}\quad\left(\left|z\right|>1\right)$$

$$X_{2}(z)=\mathcal{Z}\left[a^{n}u(n)\right]=\frac{z}{z-a}\quad(\mathrm{~}\left|z\right|>\mathrm{~}\left|a\right|)\quad$$

由z域卷积定理知

$$\begin{align*}\mathcal{Z}[na^{n}u(n)]&=\frac{1}{2\pi\mathrm{j}}\oint_{c}X_{1}(v)X_{2}\Big(\frac{z}{v}\Big)\frac{\mathrm{d}v}{v}\\&=\frac{1}{2\pi\mathrm{j}}\oint_{c}\frac{v}{\left(v-1\right)^{2}}\cdot\frac{\Big(\frac{z}{v}\Big)}{\Big(\frac{z}{v}-a\Big)}\cdot\frac{\mathrm{d}v}{v}\\&=\frac{1}{2\pi\mathrm{j}}\oint_{c}\frac{z}{\left(v-1\right)^{2}(z-av)}\mathrm{d}v\end{align*}$$

其收敛域为 $|v| > 1$ 与 $\left|\frac{z}{v}\right| > a$ 的重叠区域，即

要求 $1 < |v| < \left|\frac{z}{a}\right|$。因为 $|z| > 1, |a| < 1$，

所以围绕 C 只包围一个二阶极点 v = 1，如图

7.3.2 所示。

## §7.4 逆z变换

在介绍了z变换的定义及其性质后，我们来讨论z变换的逆变换。从z变换与抽样信号拉普拉斯变换，以及s平面与z平面的对应关系来看，从数学角度我们可以猜测到逆z变换的形式是一个闭合的围线积分，且一般的求解方法是留数法。

基于信号的指数分解与序列的指数分解，常系数线性微分方程与常系数线性差分方程的对应关系，我们可以得到一般序列及离散系统单位样值响应的z变换的表现形式为z变量的有理多项式分式的形式，这部分从表7.3.2常用序列z变换的形式中得到了验证。

因此，参照拉普拉斯逆变换的讨论顺序以及实际中的应用，我们首先介绍基于z变换定义的逆z变换求解法，其次介绍最常用的部分分式分解法，最后介绍逆z变换的定义以及相应的留数求解法。

### §7.4.1 幂级数法

由序列 $x(n)$ 的 z 变换的定义

$$X(z)=\sum_{n=-\infty}^{\infty}x(n)z^{-n}$$

可得，只要把 $X(z)$ 展开成幂级数形式，则幂级数的系数就是相应的 $x(n)$。例如对于 $X(z)=\frac{z}{z^{2}-4z+4}$，当收敛域为 $\left|z\right|>2$ 时，$x(n)$ 为右边序列，则将 $X(z)$ 表示为

$$X(z)=\frac{z}{z^{2}-4z+4}$$

进行长除，有

$$\begin{array}{r} \begin{aligned}z^{2}-4z+4&\underbrace{z^{-1}+4z^{-2}+12z^{-3}+32z^{-4}+\cdots}_{z}\\&\frac{z}{-4}-4\quad+4z^{-1}\\&\quad4\quad-4z^{-1}\\&\quad\frac{4}{12z^{-1}-16z^{-2}}\\&\quad\frac{12z^{-1}-48z^{-2}+48z^{-3}}{32z^{-2}-48z^{-3}}\end{aligned}&\quad:\end{array}$$

于是，得到

$$\begin{array}{l}X(z)=z^{-1}+4z^{-2}+12z^{-3}+\cdots+n2^{n-1}z^{-n}+\cdots\\=\displaystyle\sum_{n=0}^{\infty}n2^{n-1}\mathrm{u}(n)z^{-n}\end{array}$$

所以 $x(n) = n2^{n-1}u(n) = \begin{cases} 0 & 1 & 4 & 12 & \cdots \end{cases}$。

而若收敛域为 $\left|z\right|<2$ 时，$x(n)$ 为左边序列，则将 $X(z)$ 表示为

$$X(z)=\frac{z}{4-4z+z^{2}}$$

进行长除。有

$$\begin{array}{r} \begin{aligned} \frac{1}{4}z+\frac{1}{4}z^{2}+\frac{3}{16}z^{3}+\frac{1}{8}z^{4}+\cdots\\ 4-4z+z^{2}\overbrace{\quad z\quad }\\ \quad\underline{\quad z\quad} -z^{2}\quad+\frac{1}{4}z^{3}\\ \quad z^{2}\quad-\frac{1}{4}z^{3}\\ \quad z^{2}\quad-z^{3}\quad+\frac{1}{4}z^{4}\\ \quad\underline{\quad z\quad} \\ \quad\frac{3}{4}z^{3}\quad-\frac{1}{4}z^{4}\\ \quad\frac{3}{4}z^{3}\quad-\frac{3}{4}z^{4}\quad+\frac{3}{16}z^{5}\\ \quad\underline{\quad z\quad} \\ \frac{1}{2}z^{4}\quad-\frac{3}{16}z^{5}\end{aligned} \\ : \end{array}$$

于是，得到

$$\begin{array}{c} X(z)={\frac{1}{4}}z+{\frac{1}{4}}z^{2}+{\frac{3}{16}}z^{3}+\cdots \\ =\displaystyle\sum_{n=-\infty}^{-1}-n2^{n-1}\mathrm{u}(-n-1)z^{-n} \end{array}$$

所以 $x(n) = -n2^{n-1}u(-n-1) = \left\{ \begin{array}{ll} \cdots, & \frac{3}{16}, \frac{1}{4}, \frac{1}{4}, \\ & \quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\quad\end{array} \right\}$。

显然，通过幂级数系数来求逆z变换，一般情况下对于无限长序列不易得到闭式表达式。另外该方法适用于单极点（包括多重单极点）的z变换或者求单边z变换的逆变换。对于双边z变换的逆变换更多地采用部分分式分解法。

### §7.4.2 部分分式分解法

求逆 z 变换的部分分式分解法的思路就是，将所讨论的 z 变换分解为基本序列 z 变换的组合，则逆 z 变换等于相应的基本序列的组合。具体地，将 $X(z)$ 分解成

$$X(z)=\sum_{i}X_{i}(z)$$

其中每个 $X_{i}(z)$ 为基本序列的 z 变换，求得 $X_{i}(z) \leftrightarrow x_{i}(n)$，由线性特性得

$$x\left(n\right)=\sum_{i}x_{i}\left(n\right)$$

前面已经指出，我们讨论的 z 变换的表现形式一般为 z 变量的有理多项式，即

$$X(z)=\frac{B(z)}{A(z)}=\frac{b_{m}z^{m}+b_{m-1}z^{m-1}+\cdots+b_{1}z+b_{0}}{a_{n}z^{n}+a_{n-1}z^{n-1}+\cdots+a_{1}z+a_{0}}$$

因此我们考虑将其分解为基本形式 $\frac{kz}{z-a}$ 的组合，其中 $k$ 为常数。当收敛域为 $|z| > |a|$ 时，其对应的序列为 $ka^n u(n)$；而当收敛域为 $|z| < |a|$ 时，其对应的序列为 $-ka^n u(-n-1)$。需要提醒读者的是，在求解拉普拉斯逆变换中，我们选取的基本信号是 $ke^{at} u(t)$，其拉普拉斯变换为 $\frac{k}{z-a}$。

为了求解系数，在将 $X(z)$ 分解时，用 $\frac{X(z)}{z}$ 进行部分分式分解，然后乘以 z，得到 $\frac{z}{z-a}$ 的分解形式。值得指出的是，在一般情况下 $\frac{X(z)}{z}$ 引入了 z=0 的极点，在对 $\frac{X(z)}{z}$ 进行部分分式分解时应考虑因子 $\frac{k}{z}$。最后 $\frac{k}{z}$ 乘以变量 z 时得到常数 k，其逆 z 变换为 $k\delta(n)$。下面我们首先通过例题说明 $X(z)$ 只含一阶极点时求逆 z 变换的部分分式分解法。

例题 7.4.1 已知 $X(z) = \frac{5z}{-3z^2 + 7z - 2}$，其收敛域分别为：(1) $|z| > 2$；

(2) $|z| < \frac{1}{3}$；(3) $\frac{1}{3} < |z| < 2$，求 $x(n)$。

解：

$X(z)$ 表示成零极点形式

$$X(z)\;=\frac{5z}{\;-3z^{2}+7z-2\;}=\frac{-\frac{5}{3}z}{\left(z-2\right)\left(z-\frac{1}{3}\right)}$$

将 $\frac{X(z)}{z}$ 分解为

$$\frac{X(z)}{z}=\frac{-\frac{5}{3}}{\left(z-2\right)\left(z-\frac{1}{3}\right)}=\frac{K_{1}}{z-2}+\frac{K_{2}}{z-\frac{1}{3}}$$

其中

$$K_{1}=\left(z-2\right)\frac{X\left(z\right)}{z}\mid_{z=2}=-1$$

$$K_{2}=\left(z-\frac{1}{3}\right)\frac{X(z)}{z}\mid_{z=\frac{1}{3}}=1$$

则

$$X(z)=\frac{-z}{z-2}+\frac{z}{z-\frac{1}{3}}$$

（1）当 $\left|z\right|>2$，$x(n)$ 为右边序列，得

$$x\left(n\right)=-2^{n}u\left(n\right)+\left(\frac{1}{3}\right)^{n}u\left(n\right)=\left[\left(\frac{1}{3}\right)^{n}-2^{n}\right]u\left(n\right)$$

(2) 当 $\left|z\right| < \frac{1}{3}$，$x(n)$ 为左边序列，得

$$x\left(n\right)=2^{n}u\left(-n-1\right)-\left(\frac{1}{3}\right)^{n}u\left(-n-1\right)=\left[2^{n}-\left(\frac{1}{3}\right)^{n}\right]u\left(-n-1\right)$$

(3) 当 $\frac{1}{3}<|z|<2$，$x(n)$ 为双边序列，得

① $\frac{-z}{z-2}$ 对应左边序列，即 $x_{1}(n)=2^{n}u(-n-1)$

② $\frac{z}{z-\frac{1}{3}}$ 对应右边序列，即 $x_{2}(n)=\left(\frac{1}{3}\right)^{n}u(n)$

所以

$$x(n)=2^{n}\mathrm{u}(-n-1)+\left(\frac{1}{3}\right)^{n}\mathrm{u}(n)$$

下面我们通过例题观察 X(z) 含多重极点时求逆 z 变换的部分分式分解法。

例题 7.4.2 已知 $X(z)=\frac{z(z^{3}+2z^{2}-4z+8)}{(z-2)^{2}(z^{2}+4)}(|z|>2)$，求 $x(n)$。

解：

先将 $\frac{X(z)}{z}$ 进行部分分式展开

$$\begin{aligned}\frac{X(z)}{z}&=\frac{z^{3}+2z^{2}-4z+8}{\left(z-2\right)^{2}\left(z^{2}+4\right)}=\frac{z^{3}+2z^{2}-4z+8}{\left(z-2\right)^{2}\left(z+\mathrm{j}2\right)\left(z-\mathrm{j}2\right)}\\&=\frac{K_{1}}{\left(z-2\right)^{2}}+\frac{K_{2}}{z-2}+\frac{K_{3}}{z+\mathrm{j}2}+\frac{K_{4}}{z-\mathrm{j}2}\end{aligned}$$

$$K_{1}=\left(z-2\right)^{2}\frac{X(z)}{z}\big|_{z=2}=2,\quad K_{2}=\frac{\mathrm{d}}{\mathrm{d}z}\bigg[\left(z-2\right)^{2}\frac{X(z)}{z}\bigg]_{z=2}=1$$

$$K_{3}=\left(z+\mathrm{j}2\right)\frac{X(z)}{z}\bigg|_{z=-\mathrm{j}2}=\frac{\mathrm{j}}{2},\quad K_{4}=\left(z-\mathrm{j}2\right)\frac{X(z)}{z}\bigg|_{z=\mathrm{j}2}=-\frac{\mathrm{j}}{2}$$

所以

$$\begin{aligned}X(z)&=\frac{2z}{\left(z-2\right)^{2}}+\frac{z}{z-2}+\frac{\frac{\mathrm{j}}{2}z}{z+\mathrm{j}2}+\frac{-\frac{\mathrm{j}}{2}z}{z-\mathrm{j}2}\\&=\frac{2z}{\left(z-2\right)^{2}}+\frac{z}{z-2}+\frac{2z}{z^{2}+4}\end{aligned}$$

$$\frac{2z}{\left(z-2\right)^{2}}\leftrightarrow n2^{n}\mathrm{u}\left(n\right),\quad\frac{z}{z-2}\leftrightarrow2^{n}\mathrm{u}\left(n\right)$$

$$\frac{2z}{z^{2}+4}=\frac{2z\sin90^{\circ}}{z^{2}-2z\times2\cos90^{\circ}+4}\leftrightarrow2^{n}\sin\left(\frac{n\pi}{2}\right)u\left(n\right)$$

求得

$$x(n)=(n+1)2^{n}u(n)+2^{n}sin\left(\frac{n\pi}{2}\right)u(n)$$

### §7.4.3 围线积分法

对于 $x(n)$ 的 z 变换

$$X(z)=\sum_{n=0}^{\infty}x(n)z^{-n}$$

上式两端乘以 $z^{m-1}$，再进行围线积分，得到

$$\frac{1}{2\pi\mathrm{j}}\oint_{c}X(z)z^{m-1}\mathrm{d}z=\frac{1}{2\pi\mathrm{j}}\oint_{c}\sum_{n=0}^{\infty}x(n)z^{-n}z^{m-1}\mathrm{d}z$$

交换积分和求和的顺序，得到

$$\frac{1}{2\pi\mathrm{j}}\oint_{c}X(z)z^{m-1}\mathrm{d}z=\sum_{n=0}^{\infty}x(n)\frac{1}{2\pi\mathrm{j}}\oint_{c}z^{-n+m-1}\mathrm{d}z$$

令积分环线为 $z = Re^{j\theta}$，则式(7.4.7)右端

$$\begin{align*}\sum_{n=0}^{\infty}x\left(n\right)\frac{1}{2\pi\mathrm{j}}\oint_{c}z^{-n+m-1}\mathrm{d}z&=\sum_{n=0}^{\infty}x\left(n\right)\frac{1}{2\pi\mathrm{j}}\int_{-\pi}^{\pi}R^{m-n-1}\mathrm{e}^{\mathrm{j}\left(m-n-1\right)\theta}\mathrm{j}\operatorname{Re}^{\mathrm{j}\theta}\mathrm{d}\theta\\&=\sum_{n=0}^{\infty}x\left(n\right)\frac{1}{2\pi}R^{m-n}\int_{-\pi}^{\pi}\mathrm{e}^{\mathrm{j}\left(m-n\right)\theta}\mathrm{d}\theta\end{align*}$$

由第三章中讨论的指数函数的正交性可得，若 $m \neq n$，则式(7.4.8)为0。而

当 m=n 时，$\int_{-\pi}^{\pi}e^{j(m-n)\theta}d\theta=2\pi$，由式(7.4.7)可得

$$x(n)=\frac{1}{2\pi\mathrm{j}}\oint_{c}X(z)z^{n-1}\mathrm{d}z$$

该式便是z变换的逆变换表达式，其中C是z平面上包含 $X(z)z^{n-1}$ 所有极点的逆时针闭合环路积分路线，如图7.4.1所示。

根据留数定律，式(7.4.9)中的沿围线 C 的积分等于 C 所包围的 $X(z)z^{n-1}$ 极点的留数之和，即

## §7.5 利用z变换求解离散系统响应

和拉普拉斯变换应用于常系数线性微分方程的求解相同，利用z变换来求解常系数线性差分方程，比时域求解相应的差分方程要简单。其基本过程包括：首先对差分方程两边进行z变换，这里主要涉及z变换的位移特性和线性；其次求得响应的z变换；最后求逆z变换，即得相应的响应。在具体求解过程中，单边z变换可将系统的起始条件包含在相应的z变换中，既可分别求得零输入响应、零状态响应，也可同时求得系统的全响应。下面针对描述离散时间系统的差分方程的一般形式，应用上述过程，推导出离散时间系统完全响应、零输入响应及零状态响应的一般表达式。

线性时不变离散系统的差分方程一般形式为

$$\sum_{k=0}^{N}a_{k}y(n-k)=\sum_{r=0}^{M}b_{r}x(n-r)$$

将等式两边取单边 z 变换，并利用 z 变换的位移特性

$$\mathcal{Z}\left[\begin{matrix}{x\left(n-m\right)u\left(n\right)}\\ \end{matrix}\right]=z^{-m}\left[\begin{matrix}{X\left(z\right)}&{+~\displaystyle\sum_{k=-\infty}^{-1}x\left(k\right)z^{-k}}\\ \end{matrix}\right]$$

得到

$$\sum_{k=0}^{N}a_{k}z^{-k}\left[Y(z)+\sum_{l=-k}^{-1}y(l)z^{-l}\right]=\sum_{r=0}^{M}b_{r}z^{-r}\left[X(z)+\sum_{m=-r}^{-1}x(m)z^{-m}\right]$$

因此得到系统完全响应的 z 变换为

$$Y(z)=\frac{\displaystyle\sum_{r=0}^{M}b_{r}z^{-r}\left[\begin{array}{l l}{X(z)}&{+\displaystyle\sum_{m=-r}^{-1}x(m)z^{-m}}\end{array}\right]}{\displaystyle\sum_{k=0}^{N}a_{k}z^{-k}}-\frac{\displaystyle\sum_{k=0}^{N}\left[\begin{array}{l l}{a_{k}z^{-k}\cdot\displaystyle\sum_{l=-k}^{-1}y(l)z^{-l}}\end{array}\right]}{\displaystyle\sum_{k=0}^{N}a_{k}z^{-k}}$$

当系统的激励为0即 $x(n)=0$ 时，式(7.5.4)右边第一项为0，所得结果

$$Y(z)=-\frac{\displaystyle\sum_{k=0}^{N}\Big[a_{k}z^{-k}\cdot\sum_{l=-k}^{-1}y(l)z^{-l}\Big]}{\displaystyle\sum_{k=0}^{N}a_{k}z^{-k}}$$

为系统零输入响应的 z 变换。

而当 $y(l)=0$，其中 $l=-N,\cdots,-1$ 时，即系统起始状态为0时，式(7.5.4)右边第二项为0，所得结果

$$Y(z)=\frac{\displaystyle\sum_{r=0}^{M}b_{r}z^{-r}\left[X(z)+\sum_{m=-r}^{-1}x(m)z^{-m}\right]}{\sum_{k=0}^{N}a_{k}z^{-k}}$$

为系统零状态响应的 z 变换。

当激励 $x(n)$ 为因果序列时，系统零状态响应的 z 变换可由式 (7.5.6) 得到

$$Y(z)=X(z)\cdot\frac{\displaystyle\sum_{r=0}^{M}b_{r}z^{-r}}{\displaystyle\sum_{k=0}^{N}a_{k}z^{-k}}$$

下面我们通过例题给读者一个直观的感受。

例题 7.5.1 — 离散系统的差分方程为

$$y(n)+3y(n-1)+2y(n-2)=x(n)$$

已知 $y(-1)=0$, $y(-2)=2$, $x(n)=2^n u(n)$。求系统的零输入响应、零状态响应和完全响应。

解：

对差分方程两边取 z 变换，得到

$$Y(z)+3\left[z^{-1}Y(z)+y(-1)\right]+2\left[z^{-2}Y(z)+y(-2)+y(-1)z^{-1}\right]=X(z)$$

$$\left(1+3z^{-1}+2z^{-2}\right)Y(z)+\left[\left(3+2z^{-1}\right)y(-1)+2y(-2)\right]=X(z)$$

可见经过 z 变换后，差分方程变换为代数方程。由上式可得

$$Y(z)=\frac{-\left[\left(3+2z^{-1}\right)y(-1)+2y(-2)\right]}{1+3z^{-1}+2z^{-2}}+\frac{X(z)}{1+3z^{-1}+2z^{-2}}$$

上式第一项是零输入响应的 z 变换，第二项为零状态响应的 z 变换。将起始状态及激励的 z 变换 X(z) 代入上式，整理得到

$$\begin{aligned}Y(z)&=\frac{-4z^{2}}{z^{2}+3z+2}+\frac{z^{2}}{z^{2}+3z+2}\cdot\frac{z}{z-2}\\&=\frac{-4z^{2}}{\left(z+1\right)\left(z+2\right)}+\frac{z^{3}}{\left(z+1\right)\left(z+2\right)\left(z-2\right)}\\&=Y_{zi}(z)+Y_{zs}(z)\\ \end{aligned}$$

将 $Y_{zi}(z)$ 和 $Y_{zs}(z)$ 展开成部分分式可得

$$Y_{zi}(z)=\frac{4z}{z+1}-\frac{8z}{z+2}$$

$$Y_{z s}\left(z\right)=\frac{-\frac{1}{3}z}{z+1}+\frac{z}{z+2}+\frac{\frac{1}{3}z}{z-2}$$

对上两式分别取逆 z 变换，即可分别求出系统的零输入响应和零状态响应

$$y_{\mathrm{zi}}(n)=\left[4\left(-1\right)^{n}-8\left(-2\right)^{n}\right]\mathrm{u}(n)$$

$$y_{z s}(n)=\left[-\frac{1}{3}(-1)^{n}+(-2)^{n}+\frac{1}{3}(2)^{n}\right]\mathrm{u}(n)$$

且系统的完全响应为

$$y(n)=y_{\mathrm{zi}}(n)+y_{\mathrm{zs}}(n)=\left[\frac{11}{3}\left(-1\right)^{n}-7\left(-2\right)^{n}+\frac{1}{3}\left(2\right)^{n}\right]u(n)$$

## §7.6 单位样值响应的z变换——离散系统函数

类似于连续时间系统的变换域分析，对于离散时间系统而言，同样可以通过系统单位样值响应 $h(n)$ 的z变换 $H(z)$，从变换域的角度观察系统的特性，不仅加深对时域分析结果的理解，同时得到时域分析所没有的新结果。对应于拉普拉斯变换，离散时间系统z域分析的思路和方式和连续时间系统s域分析是类似的。我们依次介绍离散系统函数 $H(z)$ 的定义、由 $H(z)$ 极点分布判断 $h(n)$ 时域特点，以及基于 $H(z)$ 用最少的延时器实现系统的框图。

### §7.6.1 离散时间系统函数

从时域出发，离散系统的系统函数为系统单位样值响应的z变换，即

$$H(z)=\sum_{n=0}^{\infty}h(n)z^{-n}$$

再从系统响应角度出发，系统单位样值响应是 $\delta(n)$ 激励系统的零状态响应，由式（7.5.7）可知，

$$Y(z)=X(z)\cdot\frac{\displaystyle\sum_{r=0}^{M}b_{r}z^{-r}}{\displaystyle\sum_{k=0}^{N}a_{k}z^{-k}}$$

因为 $\mathcal{Z}[\delta(n)]=1$，所以

$$H(z)=\frac{\displaystyle\sum_{r=0}^{M}b_{r}z^{-r}}{\displaystyle\sum_{k=0}^{N}a_{k}z^{-k}}=\frac{Y(z)}{X(z)}$$

即系统函数等于系统零状态响应的 z 变换与激励的 z 变换的比值。

由上式可以得到，当要求序列 $x(n)$ 作用于系统的零状态响应时，只要知道系统函数 $H(z)$，便可直接得到系统零状态响应的 z 变换为 $X(z)H(z)$，通过逆 z 变换即可求得相应的 $y(n)$。这种方法通常比时域中求两个序列的卷积和要简单。

### §7.6.2 通过系统函数零极点分布确定单位样值响应

类似于连续时间系统函数 $H(s)$，我们从逆 z 变换部分分式分解法中可以看到，离散系统函数 $H(z)$ 的极点与相应的逆 z 变换结果具有直接的对应关系，例如对于因果序列而言，$\frac{z}{z-a}$ 对应于时域的 $a^{n}u(n)$。显然若 $|a|>1$ 则序列幅度随着 n 增大逐渐增大；若 $|a|<1$ 则逐渐减小。下面我们系统的归纳相应的结果。

将 $H(z)$ 表示为多项式相乘的形式，即

$$H(z)=\frac{\displaystyle\sum_{r=0}^{M}b_{r}z^{-r}}{\displaystyle\sum_{k=0}^{N}a_{k}z^{-k}}=G\frac{\prod_{r=1}^{M}\left(1-z_{r}z^{-1}\right)}{\prod_{k=1}^{N}\left(1-p_{k}z^{-1}\right)}$$

其中 G 为常数，$z_{r}$ 和 $p_{k}$ 分别为 $H(z)$ 的零点和极点。

不失一般性地，假设 $H(z)$ 只有一阶极点，将 $H(z)$ 展开，得到

$$H(z)=A_{0}+\sum_{k=1}^{N}\frac{A_{k}z}{z-p_{k}}$$

其中 $A_{0}, A_{1}, \cdots, A_{N}$ 均为常数。对于因果序列 $h(n)$ 而言，

$$h\left(n\right)=A_{0}\delta\left(n\right)\;+\;\sum_{k=1}^{N}A_{k}\left(p_{k}\right)^{n}u\left(n\right)$$

因此，我们得到当一阶极点位于单位圆内时，随着 n 增大对应序列的幅度逐渐衰减；极点在单位圆外时逐渐增大；极点在单位圆上时幅度序列的幅度保持不变。对于多重极点，在单位圆内和单位圆外的衰减和增长特性不变，但在单位圆上时，则对应的序列幅度逐渐增长。在上述各种情况中，若极点为实数，对应的序列为指数序列或指数序列乘以 n 的多项式形式；若是成对出现的共轭复数，则对应的序列为正弦（或余弦）序列或正弦（或余弦）序列乘以 n 的多项式形式。我们将这些结论列于表7.6.1中

## §7.7 离散系统的因果性及稳定性

类似于连续时间系统函数 $H(s)$ 在系统特性分析中的作用，我们现在进一步通过 $H(z)$ 分析 LTI 离散时间系统的因果性和稳定性，其基本的分析思路仍然是对离散时间系统单位样值响应 $h(n)$ 在时域中的规律，通过 z 变换得到通过 $H(z)$ 描述的变换域中的规律，从变换域角度来进一步观察这些特性，以得到更丰富和简单的系统特性描述方法。

### §7.7.1 离散系统因果性的z域体现

从时域来看，一个离散线性时不变系统是因果系统的充分必要条件是

$$h(n)=h(n)u(n)$$

即 $h(n)$ 为因果序列。

由于因果序列 $z$ 变换的收敛域为 $|z|>R$，因此，如果系统函数的收敛域具有 $|z|>R$ 的形式，则单位冲激响应是因果序列，即该系统是因果的；否则，系统是非因果的。这样系统因果性的充分必要条件可以用 $H(z)$ 表示，即系统函数 $H(z)$ 的收敛域为

$$\left|z\right|>R$$

其中 R 为非负实数。这也就是说，对于因果系统而言，其系统函数 $H(z)$ 的极点分布在 z 平面上一个半径有限的圆内。

### §7.7.2 离散系统稳定性的z域体现

基于系统函数 $H(z)$ 极点位置与 $h(n)$ 时域变化趋势的关系，我们可以用系统函数来研究稳定性问题。已知离散系统为稳定系统时域中的充分必要条件是

$$\sum_{n=-\infty}^{\infty}\left|h(n)\right|<M$$

其中 M 为有界正值。上式也可写作

$$\sum_{n=-\infty}^{\infty}\left|h(n)\right|<\infty$$

上式表明，$\sum_{n=-\infty}^{\infty}\left|h(n)z^{-n}\right|$ 在单位圆 $\left|z\right|=1$ 上是收敛的，根据收敛域的定义，单位圆在 $H(z)=\sum_{n=-\infty}^{\infty}h(n)z^{-n}$ 的收敛域内。因此，系统为稳定的必要条件是系统函数 $H(z)$ 的收敛域包含单位圆。

如果系统是因果的，那么稳定性的条件是 $H(z)$ 的收敛域是包含单位圆在内的某个圆的外部，由于收敛域中不能含有极点，故 $H(z)$ 的所有极点均应在单位圆内。因此，因果系统稳定的充要条件是：$H(z)$ 的所有极点均在单位圆内。

下面我们通过例题对离散时间系统的因果性和稳定性加以进一步说明。

例题 7.7.1 某 LTI 离散时间系统的差分方程为 $y(n)-2y(n-1)=x(n)$

（1）求系统函数 $H(z)$ 并确定可能的单位样值响应，说明系统的因果性与稳定性。

（2）求由该差分方程确定的因果系统的在 $x(n) = u(n + 1)$ 作用下的零状态响应。

解：

（1）由差分方程可得 $H(z)$ 表达式

$$H(z)=\frac{1}{1-2z^{-1}}=\frac{z}{z-2}$$

极点为 z=2，因此，可能的收敛域为① 当 $|z| < 2$ 时，单位样值响应为左边序列且 $h(n) = -2^n u(-n-1)$，显然系统是非因果系统。对于因果系统而言，要使得系统稳定，$H(z)$ 的极点要求在单位圆内。但对于非因果系统，要使得系统稳定，则 $H(z)$ 的极点必须在单位圆外。这里，因为极点 z = 2 在单位圆外，所以此时系统为非因果、稳定系统。

② 当 $|z| > 2$ 时，此时单位样值响应为右边序列且 $h(n) = 2^n u(n)$，系统是因果的。但由于极点 z = 2 在单位圆外，所以系统是非稳定的。

（2）方法一 时域法

由(1)的结果知道，满足题设条件的系统单位样值响应为

$$h(n)=2^{n}u(n)$$

因此

$$\begin{aligned}y_{zs}\left(n\right)&=x\left(n\right)\bigotimes h\left(n\right)=u\left(n+1\right)\bigotimes2^{n}u\left(n\right)\\&=\left[\sum_{m=-1}^{n}2^{n-m}\right]u\left(n+1\right)=\left(2\cdot2^{n+1}-1\right)u\left(n+1\right)\end{aligned}$$

方法二 z域法

对差分方程取双边 z 变换，得

$$\left(1-2z^{-1}\right)Y_{zs}(z)=X(z)$$

则

$$Y_{z s}(z)=\frac{1}{1-2z^{-1}}X(z)=z\bigg[\frac{1}{\left(1-z^{-1}\right)\left(1-2z^{-1}\right)}\bigg]=z\bigg[\frac{2}{1-2z^{-1}}-\frac{1}{1-z^{-1}}\bigg]$$

因此

$$y_{\mathrm{zs}}(n)=\mathcal{Z}^{-1}\left[Y_{\mathrm{zs}}(z)\right]=2\cdot2^{n+1}u(n+1)-u(n+1)=\left(2\cdot2^{n+1}-1\right)u(n+1)$$

在离散系统中通常采用先存储再处理的后处理技术，因此常遇到非因果处理系统。下面讨论一个非因果系统的例子，作为本章第5节用z变换求解差分方程的一个补充。

例题 7.7.2 已知某非因果 LTI 离散系统的差分方程为

$$y(n)-5y(n-1)+6y(n-2)=x(n)$$

若 $x(n) = u(n)$，求响应 $y(n)$。

解：

因为系统是非因果的，故方程两边取双边 z 变换，得到

$$Y(z)\left(1-5z^{-1}+6z^{-2}\right)=X(z)$$

所以

$$H(z)=\frac{1}{1-5z^{-1}+6z^{-2}}=\frac{z^{2}}{(z-2)(z-3)}$$

则

$$Y(z)=X(z)H(z)=\frac{z^{3}}{\left(z^{2}-5z+6\right)(z-1)}$$

因为系统是非因果的，则系统函数 $H(z)$ 的收敛域为 $|z|<2$；而由题意知 $X(z)$ 的收敛域为 $|z|>1$，因此 $Y(z)$ 的收敛域为 $1<|z|<2$，将 $Y(z)$ 作部分分式分解，可得

$$Y(z)\;=\frac{\frac{1}{2}z}{z-1}-\frac{4z}{z-2}+\frac{\frac{9}{4}z}{z-3}$$

（1）极点 z=1 在 $Y(z)$ 收敛环的内侧，其对应右边序列，故

$$\mathcal{Z}^{-1}\left[\frac{\frac{1}{2}z}{z-1}\right]=\frac{1}{2}u\left(n\right)$$

（2）极点 z=2, z=3 在 Y(z) 收敛环的外侧，对应左边序列，故

$$\mathcal{Z}^{-1}\left[-\frac{4z}{z-2}+\frac{\frac{9}{4}z}{z-3}\right]=\left(4\cdot2^{n}-\frac{9}{4}\cdot3^{n}\right)\mathrm{u}\left(-n-1\right)$$

故系统响应为

$$y(n)=\left(4\cdot2^{n}-\frac{9}{4}\cdot3^{n}\right)\mathrm{u}(-n-1)+\frac{1}{2}\mathrm{u}(n)$$

## §7.8 序列的傅里叶变换

本章开始便指出，离散时间序列的z变换对应于连续时间信号的拉普拉斯变换，对应于连续时间信号的傅里叶变换，序列同样存在相应的傅里叶变换。数字信号的傅里叶变换是数字信号处理的重要内容，本书这里主要介绍序列傅里叶变换的定义，并不加证明地给出序列傅里叶变换的性质，从序列z变换与傅里叶变换关系的角度加以定义说明。

### §7.8.1 序列傅里叶变换的定义

离散时间序列 $x(n)$ 的傅里叶变换，又称为离散时间傅里叶变换（Discrete Time Fourier Transform，简写为 DTFT）。我们将 z 变量以极坐标表示，即 $z = r \mathrm{e}^{\mathrm{j}\omega}$，其中 r 为模，$\omega$ 为辐角序列，则 $x(n)$ 的 z 变换别为

$$X(r\mathrm{e}^{\mathrm{j}\omega})=\sum_{n=-\infty}^{\infty}x(n)(r\mathrm{e}^{\mathrm{j}\omega})^{-n}$$

即

$$X(r\mathrm{e}^{\mathrm{j}\omega})=\left[\sum_{n=-\infty}^{\infty}x(n)r^{-n}\right]\mathrm{e}^{-\mathrm{j}\omega n}$$

所以 $X(re^{\mathrm{j}\omega})$ 为序列 $x(n)$ 乘以实指数 $r^{-n}$ 后的傅里叶变换。当 r=1 即 $\left|z\right|=1$ 时，

$$X(\mathrm{e}^{\mathrm{j}\omega})=X(z)\mid_{z=\mathrm{e}^{\mathrm{j}\omega}}=\sum_{n=-\infty}^{\infty}x(n)\mathrm{e}^{-\mathrm{j}n\omega}$$

称为序列 $x(n)$ 的傅里叶变换，即单位圆上的 z 变换为序列的傅里叶变换。

由 z 变换逆变换的定义，序列傅里叶变换的逆变换为

$$\begin{aligned}{x\left(n\right)}&{{}=\frac{1}{2\pi\mathrm{j}}\oint_{|_{z}|=1}X\left(z\right)z^{n-1}d z}\\ {}&{{}=\frac{1}{2\pi\mathrm{j}}\oint_{|_{z}|=1}X(\mathrm{e}^{\mathrm{j}\omega})\mathrm{e}^{\mathrm{j}n\omega}\mathrm{e}^{-\mathrm{j}\omega}d(\mathrm{e}^{\mathrm{j}\omega})}\\ \end{aligned}$$

$$\begin{aligned}=&\frac{1}{2\pi\mathrm{j}}\int_{-\pi}^{\pi}X(\mathrm{e}^{\mathrm{j}\omega})\mathrm{e}^{\mathrm{j}n\omega}\mathrm{e}^{-\mathrm{j}\omega}\mathrm{j}\mathrm{e}^{\mathrm{j}\omega}d\omega\\=&\frac{1}{2\pi}\int_{-\pi}^{\pi}X(\mathrm{e}^{\mathrm{j}\omega})\mathrm{e}^{\mathrm{j}n\omega}d\omega\end{aligned}$$

因此，我们得到 $x(n)$ 傅里叶变换和逆变换分别为

$$\mathcal{F}\left[x(n)\right]=X(\mathrm{e}^{\mathrm{j}\omega})=\sum_{n=-\infty}^{\infty}x(n)\mathrm{e}^{-\mathrm{j}\omega n}$$

$$\mathcal{F}^{-1}\left[X(\mathrm{e}^{\mathrm{j}\omega})\right]=x(n)=\frac{1}{2\pi}\int_{-\pi}^{\pi}X(\mathrm{e}^{\mathrm{j}\omega})e~^{\mathrm{j}\omega n}d\omega$$

$X(e^{j\omega})$ 一般是复数，可以写成实部和虚部的形式

$$X(\mathrm{e}^{\mathrm{j}\omega})=X_{\mathrm{R}}(\mathrm{e}^{\mathrm{j}\omega})+\mathrm{j}X_{I}(\mathrm{e}^{\mathrm{j}\omega})$$

或者是幅度和相位的形式

$$X(\mathrm{e}^{\mathrm{j}\omega})=\mid X(\mathrm{e}^{\mathrm{j}\omega})\mid \mathrm{e}^{\mathrm{j}\arg}[X(\mathrm{e}^{\mathrm{j}\omega})]}=\mid X(\mathrm{e}^{\mathrm{j}\omega})\mid \mathrm{e}^{\mathrm{j}\varphi(\omega)}$$

$X(e^{j\omega})$ 表示 $x(n)$ 的频率特性，也称为 $x(n)$ 的频谱，而 $\left|X(e^{j\omega})\right|$ 为 $x(n)$ 的幅度谱，$\varphi(\omega)$ 为 $x(n)$ 的相位谱，它们分别为

$$\mid X(\mathrm{e}^{\mathrm{j}\omega})\mid=\sqrt{X_{\mathrm{R}}^{2}(\mathrm{e}^{\mathrm{j}\omega})+X_{\mathrm{I}}^{2}(\mathrm{e}^{\mathrm{j}\omega})}$$

$$\varphi\left(\omega\right)=\arg[X(\mathrm{e}^{\mathrm{j}\omega})]=\arctan\frac{X_{\mathrm{I}}(\mathrm{e}^{\mathrm{j}\omega})}{X_{\mathrm{R}}(\mathrm{e}^{\mathrm{j}\omega})}$$

从式(7.8.3)可以看出，离散序列的频谱 $X(e^{jw})$ 具有如下特点：

（1）任何序列的频谱 $X(e^{j\omega})$ 都是频率 $\omega$ 的周期函数，且周期为 $2\pi$。$\omega = 0$ 附近是低频段，$\omega$ 逐渐增大，到 $\omega = \pi$ 为高频段；

(2) 当 $x(n)$ 为实序列时，幅度谱 $\left|X(e^{j\omega})\right|$ 是关于 $\omega=0$ 和 $\omega=\pi$ 的偶对称函数，相位谱 $\varphi(\omega)$ 是关于 $\omega=0$ 和 $\omega=\pi$ 的奇对称函数。

序列的傅里叶变换和连续时间信号的傅里叶变换有一个根本的区别，就是序列的傅里叶变换是以 $2\pi$ 为周期的 $\omega$ 的连续函数，而连续时间信号的傅里叶变换是 $\omega$ 的非周期函数。

需要提醒的是，和连续时间信号的傅里叶变换相同，并不是任何序列 $x(n)$ 的傅里叶变换都是存在的。当序列 $x(n)$ 绝对可和时，即

$$\sum_{n=-\infty}^{\infty}\left|x(n)\right|<\infty$$

$x(n)$ 的傅里叶变换存在。$x(n)$ 绝对可和是其傅里叶变换存在的充分条件。例如 $\mathrm{u}(n)$、$\cos(\omega_{0}n)$ 以及其他各种周期序列，都不是绝对可和，一般认为它们的傅里叶变换不存在。但是，如果引入奇异函数的概念，那么这类不是绝对可和的序列也存在傅里叶变换。这和连续时间系统中的情况相同。

例题 7.8.1 求 $x(n) = a^n u(n) (\left|a\right| < 1)$ 的傅里叶变换 $X(e^{j\omega})$，并画出频谱图。

解：

由式(7.8.3)得到

$$\begin{aligned}X(\mathrm{e}^{\mathrm{j}\omega})&=\sum_{n=-\infty}^{\infty}x(n)\mathrm{e}^{-\mathrm{j}\omega n}=\sum_{n=-\infty}^{\infty}a^{n}\mathrm{u}(n)\mathrm{e}^{-\mathrm{j}\omega n}=\sum_{n=0}^{\infty}\left(a\mathrm{e}^{-\mathrm{j}\omega}\right)^{n}=\frac{1}{1-a\mathrm{e}^{-\mathrm{j}\omega}}\\&=\frac{1}{1-a(\cos\omega-\mathrm{j}\sin\omega)}=\frac{1}{1-a\cos\omega+\mathrm{j}a\sin\omega}\end{aligned}$$

所以

$$\mid X(\mathrm{e}^{\mathrm{j}\omega})\mid=\frac{1}{\sqrt{1+a^{2}-2a\cos\omega}}$$

$$\varphi\left(\omega\right)=-\arctan\left(\frac{a\sin\omega}{1-a\cos\omega}\right)$$

其幅度谱 $\left|X(e^{j\omega})\right|$ 与相位谱 $\varphi(\omega)$ 如图 7.8.1 所示。由图中可见，$\left|X(e^{j\omega})\right|$ 与 $\varphi(\omega)$ 都是以 $2\pi$ 为周期的连续的周期函数。

前面已经多次强调，信号与系统分析的基本思路是通过一般信号与基本信号的关系来分析一般信号的特点。对于序列的傅里叶变换而言，一般方法并不是直接代入定义计算，而是以基本序列为基础，通过一般序列与基本序列之间的运算关系来分析一般序列的傅里叶变换，下面我们观察序列时域中的运算关系在频域中的具体体现，即序列傅里叶变换的性质。

### §7.8.2 序列傅里叶变换的性质

序列的傅里叶变换的基本性质与 z 变换的基本性质有许多相同之处，因此这里只给出结论，不进行证明。

#### 1. 奇偶虚实性

若 $x(n)$ 为实序列，$\mathcal{F}[x(n)] = X(\mathrm{e}^{\mathrm{j}\omega})$，其实部和虚部分别为 $\mathrm{Re}[X(\mathrm{e}^{\mathrm{j}\omega})]$ 和 $\mathrm{Im}[X(\mathrm{e}^{\mathrm{j}\omega})]$，也可写作模与辐角形式

$$X(\mathrm{e}^{\mathrm{j}\omega})=\left|X(\mathrm{e}^{\mathrm{j}\omega})\right|\mathrm{e}^{\mathrm{j}\varphi(\omega)}$$

复函数 $X(e^{j\omega})$ 的实部为偶函数，虚部为奇函数；模为偶函数，辐角是奇函数。$X(e^{j\omega})$ 与 $X(e^{-j\omega})$ 共轭，即

$$\mathrm{Re}\left[X(\mathrm{e}^{\mathrm{j}\omega})\right]=\mathrm{Re}\left[X(\mathrm{e}^{-\mathrm{j}\omega})\right]$$

$$\mathrm{Im}\left[X(\mathrm{e}^{\mathrm{j}\omega})\right]=-\mathrm{Im}\left[X(\mathrm{e}^{-\mathrm{j}\omega})\right]$$

$$\big|\;X\big(\mathrm{e}^{\mathrm{j}\omega}\big)\;\big|\;=\;\big|\;X\big(e~^{-\mathrm{j}\omega}\big)\;\big|$$

$$\varphi\left(\omega\right)=-\varphi\left(-\omega\right)$$

$$X(\mathrm{e}^{\mathrm{j}\omega})=X^{*}(\mathrm{e}^{-\mathrm{j}\omega})$$

由以上表示可以看出，序列的傅里叶变换特性与连续时间信号的傅里叶变换的特性情况一致。

#### 2. 序列的位移特性

若

$$\mathcal{F}[x(n)]=X(\mathrm{e}^{\mathrm{j}\omega})$$

则

$$\mathcal{F}\left[x\left(n-n_{0}\right)\right]=\mathrm{e}^{-\mathrm{j}\omega n_{0}}X\left(\mathrm{e}^{\mathrm{j}\omega}\right)$$

时域位移对应频域的相移。

3. 序列的时域扩展

若

$$\begin{aligned}&\mathcal{F}\left[x(n)\right]=X(\mathrm{e}^{\mathrm{j}\omega})\\ &\\ &\mathcal{F}\left[x\left(\frac{n}{k}\right)\right]=X(\mathrm{e}^{\mathrm{j}k\omega})\\ \end{aligned}$$

则

显然，序列的时域扩展对应频域压缩，这和连续时间信号是相同的。当 k = -1 时，得到

$$\mathcal{F}\left[\begin{array}{l l}{x(-n)}\\ \end{array}\right]=X(e~^{-\mathrm{j}\omega})$$

#### 4. 线性

DTFT 变换是一种线性变换，具有线性性质。若

$$\mathcal{F}\left[\begin{matrix}{x_{1}(n)}\\ \end{matrix}\right]=X_{1}\left(\begin{matrix}{\mathrm{e}^{\mathrm{j}\omega}}\\ \end{matrix}\right)$$

$$\mathcal{F}\left[x_{2}(n)\right]=X_{2}(\mathrm{e}^{\mathrm{j}\omega})$$

则

$$\mathcal{F}\left[a x_{1}(n)+b x_{2}(n)\right]=a X_{1}\left(\mathrm{e}^{\mathrm{j}\omega}\right)+b X_{2}\left(\mathrm{e}^{\mathrm{j}\omega}\right)$$

式中 a、b 为任意常数。

5. 序列的线性加权

若

$$\begin{array}{c}{{\mathcal{F}\left[x\left(n\right)\right]=X\left(\mathrm{e}^{\mathrm{j}\omega}\right)}}\\ {{}}\\ {{}}\\ {{\mathcal{F}\left[n x\left(n\right)\right]=\mathrm{j}\left[\frac{\mathrm{d}}{\mathrm{d}\omega}X\left(\mathrm{e}^{\mathrm{j}\omega}\right)\right]}}\\ \end{array}$$

则时域的线性加权对应频域微分。

6. 频域位移特性

若

$$\begin{array}{c}{\mathcal{F}\left[\begin{array}{c}{x(n)}\\ \end{array}\right]=X\left(\mathrm{e}^{\mathrm{j}\omega}\right)}\\ {}\\ {}\\ {\mathcal{F}\left[\begin{array}{c}{\mathrm{e}^{\mathrm{j}\omega_{0}n}x\left(n\right)}\\ \end{array}\right]=X\left[\begin{array}{c}{\mathrm{e}^{\mathrm{j}\left(\omega-\omega_{0}\right)}}\\ \end{array}\right]}\\ \end{array}$$

则

这表示频域位移对应时域的调制。

7. 时域卷积定理

若

$$\begin{aligned}\mathcal{F}\left[x(n)\right]&=X(\mathrm{e}^{\mathrm{j}\omega})\\\mathcal{F}\left[h(n)\right]&=H(\mathrm{e}^{\mathrm{j}\omega})\end{aligned}$$

则

$$\mathcal{F}\left[\;x(n)\bigotimes h(n)\;\right]=X(\mathrm{e}^{\mathrm{j}\omega})H(\mathrm{e}^{\mathrm{j}\omega})$$

即时域卷积对应频域相乘。

8. 频域卷积定理

若

$$\begin{aligned}{X(\mathrm{e}^{\mathrm{j}\omega})}&{{}=\mathcal{F}\left[x(n)\right]}\\ {H(\mathrm{e}^{\mathrm{j}\omega})}&{{}=\mathcal{F}\left[h(n)\right]}\\ \end{aligned}$$

则

$$\begin{aligned}{\frac{1}{2\pi}\bigl[X(\mathrm{e}^{\mathrm{j}\omega})\otimes H(\mathrm{e}^{\mathrm{j}\omega})\bigr]}&{{}=\frac{1}{2\pi}\int_{-\pi}^{\pi}X(e~^{\mathrm{j}\theta})H\bigl[e~^{\mathrm{j}\left(\omega-\theta\right)}\bigr]\mathrm{d}\theta}\\ {}&{{}=\mathcal{F}\bigl[x(n)h(n)\bigr]}\\ \end{aligned}$$

即时域相乘对应频域卷积。

9. 帕塞瓦尔定理

若

$$\mathcal{F}[x(n)]=X(\mathrm{e}^{\mathrm{j}\omega})$$

则

$$\sum_{n=-\infty}^{\infty}\left|x(n)\right|^{2}=\frac{1}{2\pi}\int_{-\pi}^{\pi}\left|X(e^{j\omega})\right|^{2}\mathrm{d}\omega$$

式(7.8.23)左边表示的是序列在时域中的能量，等式右边表示的是序列在频域中的能量。Parseval定理说明，信号在时域中的能量等于频域中的能量。所以，Parseval定理又称为能量守恒定理。

下面通过两道例题对上述若干性质加以简单应用。

例题 7.8.2 求 $x(n)=\left(\frac{1}{3}\right)^{n-2}u(n-2)$ 的傅里叶变换 $X(e^{j\omega})$。

$$x(n)=x_{1}(n-2)$$

$$X(\mathrm{e}^{\mathrm{j}\omega})=\frac{\mathrm{e}^{-\mathrm{j}2\omega}}{1-\frac{1}{3}\mathrm{e}^{-\mathrm{j}\omega}}$$

## §7.9 离散系统的频率响应

在从时域及 z 域观察系统特性后，我们同样可以从频域来观察离散系统对序列的作用，以进一步了解和认识离散系统的特性，并为进一步学习相关系统设计提供必要的基础知识。与连续时间系统类似，我们首先介绍离散时间系统频率响应的定义及其物理意义，然后应用系统函数 $H(z)$ 零极点在z平面的分布，采用几何方法作出系统频率响应的特性，包括幅频特性和相频特性。

### §7.9.1 离散时间系统频率响应

所谓离散时间系统的频率响应就是系统单位样值响应的傅里叶变换，根据序列傅里叶变换存在的条件，系统应该是稳定的。对于单位样值响应为 $h(n)$ 的系统，其系统频率响应为

$$H(\mathrm{e}^{\mathrm{j}\omega})=\mathcal{F}\left[h(n)\right]=H(z)\left|_{z=\mathrm{e}^{\mathrm{j}\omega}}\right.$$

从系统激励与相应的零状态响应的傅里叶变换关系来看，

$$H(\mathrm{e}^{\mathrm{j}\omega})=\frac{Y(z)\big|_{z=\mathrm{e}^{\mathrm{j}\omega}}}{X(z)\big|_{z=\mathrm{e}^{\mathrm{j}\omega}}}=\frac{Y(\mathrm{e}^{\mathrm{j}\omega})}{X(\mathrm{e}^{\mathrm{j}\omega})}$$

将 $H(e^{j\omega})$ 表示为模与辐角的形式，即

$$H(\mathrm{e}^{\mathrm{j}\omega})=\left|H(\mathrm{e}^{\mathrm{j}\omega})\right|e~^{\mathrm{j}\varphi(\omega)}$$

则其模 $\left|H\left(\mathrm{e}^{\mathrm{j}\omega}\right)\right|$ 称为系统的幅频特性，辐角 $\varphi(\omega)$ 称为系统的相频特性。

现在观察复指数序列 $x(n) = \mathrm{e}^{\mathrm{j}\omega_{0}n} \mathrm{u}(n)$ 作用于频响特性为 $H(\mathrm{e}^{\mathrm{j}\omega})$ 的因果稳定系统后的稳态响应。对 $x(n)$ 求 z 变换得到

$$X(z)=\frac{z}{z-\mathrm{e}^{\mathrm{j}\omega_{0}}}$$

则系统响应的 z 变换为

$$Y(z)=\frac{z}{z-\mathrm{e}^{\mathrm{j}\omega_{0}}}\cdot H(z)$$

由于系统为因果稳定系统，$H(z)$ 极点均位于单位圆内，不会与 $X(z)$ 的极点 $e^{j\omega_{0}}$ 相重合。这样，$Y(z)$ 可分解为

$$Y(z)=\frac{a z}{z-\mathrm{e}^{\mathrm{j}\omega_{0}}}+\sum_{m=1}^{M}\frac{\bar{A}_{m}z}{z-z_{m}}$$

其中常数 $a = H \left( e^{j\omega_{0}} \right)$，则稳态响应为

$$\begin{array}{r}{y(n)=H(\mathrm{e}^{\mathrm{j}\omega_{0}})\mathrm{e}^{\mathrm{j}\omega_{0}n}\mathrm{u}(n)}\end{array}$$

这就是说，序列 $\mathrm{e}^{\mathrm{j}\omega_{0}\mathrm{n}}\mathrm{u}(n)$ 经过一离散时间系统，所得稳态响应依然是 $\mathrm{e}^{\mathrm{j}\omega_{0}\mathrm{n}}\mathrm{u}(n)$，但受到该系统频率响应 $H\left(\mathrm{e}^{\mathrm{j}\omega_{0}}\right)$ 的加权相乘。

现在我们再来观察实数正弦序列 $x(n) = (\sin \omega_0 n) u(n)$ 激励系统后的稳态响应，利用欧拉公式可得

$$\sin\omega_{0}n=\frac{1}{2\mathrm{j}}(\mathrm{e}^{\mathrm{j}\omega_{0}n}-\mathrm{e}^{-\mathrm{j}\omega_{0}n})$$

应用式(7.9.6)的结果，得到此时系统的稳态响应为

$$y(n)=\frac{1}{2\mathrm{j}}\big[H\big(\mathrm{e}^{\mathrm{j}\omega_{0}}\big)\mathrm{e}^{\mathrm{j}\omega_{0}n}-H\big(\mathrm{e}^{-\mathrm{j}\omega_{0}}\big)\mathrm{e}^{-\mathrm{j}\omega_{0}n}\big]$$

因为系统单位样值响应 $h(n)$ 为实数序列，根据实数序列傅里叶变换的奇偶虚实性，有

$$\begin{aligned}{}&{{}H(e~^{\mathrm{j}\omega_{0}})=\left|\begin{matrix}{H(e~^{\mathrm{j}\omega_{0}})}\\ \end{matrix}\right|e~^{\mathrm{j}\varphi(\omega_{0})}}\\ {}&{{}H(e~^{-\mathrm{j}\omega_{0}})=\left|\begin{matrix}{H(e~^{\mathrm{j}\omega_{0}})}\\ \end{matrix}\right|e~^{-\mathrm{j}\varphi(\omega_{0})}}\\ \end{aligned}$$

所以，得到

$$\begin{aligned}{y(n)}&{{}=\big|H\big(\mathrm{e}^{\mathrm{j}\omega_{0}}\big)\big|\frac{1}{2j}\big[e^{j\left[\varphi\left(\omega_{0}\right)+\omega_{0}n\right]}-e^{-j\left[\varphi\left(\omega_{0}\right)+\omega_{0}n\right]}\big]}\\ {}&{{}=\big|H\big(\mathrm{e}^{\mathrm{j}\omega_{0}}\big)\big|\sin\big(n\omega_{0}+\varphi\big)}\\ \end{aligned}$$

这说明，正弦序列激励系统所得的稳态响应依然为同频率的正弦序列，但幅度受到系统在该频率点处的幅频特性的加权相乘，相位受到相应的相频特性的加权相加。若激励信号为余弦序列时，可以得到相同的结论，感兴趣的读者不妨自行推导。

由式(7.9.3)看出，由于 $e^{j\omega}$ 是周期函数，因此离散系统的频率响应是周期函数，其周期为序列的重复频率 $\omega_{s}=\frac{2\pi}{T}$，若令 $T=1$，则 $\omega_{s}=2\pi$，这是离散系统频响特性区别于连续系统频响特性的一个突出特点。实际上，$H(e^{j\omega})$ 作为序列 $h(n)$ 的傅里叶变换，由序列傅里叶变换的周期性也可以得到相同的结论。

离散系统依其幅频特性，也有低通、高通、带通、带阻及全通之分。由于频率响应 $H(e^{j\omega})$ 为周期函数，因此这些特性可以在 $-\pi$ 到 $\pi$ 范围内得到区分。由于离散系统幅频特性为偶函数，实际中只需观察 0 到 $\pi$ 范围即可。图 7.9.1 分别给出了低通、高通、带通、带阻数字滤波器的幅频特性。

在连续时间系统中我们知道，理想滤波器是物理不可实现的，离散时间系统中同样如此。图 7.9.2 表示一个实际的低通滤波器幅频特性，$\omega_p$ 和 $\omega_s$ 分别称为通带截止频率和阻带截止频率。通带频率范围为 $0 \leq \omega \leq \omega_p$，在通带中要求 $(1 - \delta_1) < |H(e^{j\omega})| \leq 1$；阻带频率范围为 $\omega_s \leq \omega \leq \pi$，在阻带中要求 $|H(e^{j\omega})| \leq \delta_2$；从 $\omega_p$ 到 $\omega_s$ 称为过渡带，一般是单调下降的。通带内和阻带内允许的衰减一般用 dB 数表示。当幅度下降到 $\sqrt{2}/2$ 时，$\omega = \omega_c$，此时通带衰减为 3 dB，称 $\omega_c$ 为 3 dB 通带截止频率。$\omega_p$、$\omega_c$ 和 $\omega_s$ 统称为边界频率，它们属于滤波器设计中重要的设计参数。

### §7.9.2 频率响应的几何作图法

由于离散系统频率响应 $H(e^{j\omega})$ 是系统函数 $H(z)$ 在单位圆上的 z 变换，所以类似于连续时间系统频率响应 $H(\omega)$ 借助系统函数 $H(s)$ 在 s 平面上零极点的位置用几何法作出 $H(\omega)$ 的曲线，我们也可以通过 $H(z)$ 在 z 平面上零极点的位置作出 $H(e^{j\omega})$ 的曲线。

由第6章式(6.3.2)所描述的离散时间系统一般性差分方程可知，离散系统的 $H(z)$ 为z变量的有理多项式分式，进而可以表示为如下形式

$$H(z)=k\frac{\displaystyle\prod_{j=1}^{M}(z-z_{j})}{\displaystyle\prod_{i=1}^{N}(z-p_{i})}$$

其中 k 为常数，$z_{j}(j=1,2,\cdots,M)$ 为 $H(z)$ 的零点，$p_{i}(i=1,2,\cdots,N)$ 为 $H(z)$ 的极点。则可得系统频率响应为

$$H(\mathrm{e}^{\mathrm{j}\omega})=k\frac{\displaystyle\prod_{j=1}^{M}(\mathrm{e}^{\mathrm{j}\omega}-z_{j})}{\displaystyle\prod_{i=1}^{N}(\mathrm{e}^{\mathrm{j}\omega}-p_{i})}=\left|H(\mathrm{e}^{\mathrm{j}\omega})\right|\mathrm{e}^{\mathrm{j}\varphi(\omega)}$$

令

$$e^{\mathrm{j}\omega}-z_{j}=A_{j}e^{\mathrm{j}\varphi_{j}},\ e^{\mathrm{j}\omega}-p_{i}=B_{i}e^{\mathrm{j}\theta_{i}}$$

则系统的幅频特性为

$$\mid H(e^{\mathrm{j}\omega})\mid=k\frac{\displaystyle\prod_{j=1}^{M}A_{j}}{\displaystyle\prod_{i=1}^{N}B_{i}}$$

相频特性为

$$\varphi\left(\omega\right)=\sum_{j=1}^{M}\varphi_{j}-\sum_{i=1}^{N}\theta_{i}$$

其中，式中 $A_{j}$、$\varphi_{j}$ 分别表示 z 平面上零点 $z_{j}$ 到单位圆上某点 $e^{j\omega}$ 的向量 ($e^{j\omega} - z_{j}$) 的长度和夹角，$B_{i}$、$\theta_{i}$ 表示极点 $p_{i}$ 到 $e^{j\omega}$ 的向量 ($e^{j\omega} - p_{i}$) 的长度和夹角，如图 7.9.5 所示。

如果单位圆上 $e^{j\omega}$ 点从 $\omega = 0$ 沿单位圆滑动到 $\omega = 2\pi$，得到不同的 $A_j$ 和 $B_i$，通过式(7.9.12)便可计算得到系统的幅频特性；同时得到不同的 $\varphi_j$ 和 $\theta_i$，通过式(7.9.13)便可计算得到系统的相频特性。可见频率响应的形状取决于 $H(z)$ 的零极点分布，也就是取决于离散系统的形式及差分方程各系数的大小。不难看出，位于 $z = 0$ 处的零点或极点对幅频特性不产生作用，

在图7.10.2中，从连续时间信号 $x_{c}(t)$ 到离散时间序列 $x_{d}(n)$ 的变换，可以表示成理想抽样和冲激串映射为序列的过程。离散时间序列 $x_{d}(n)$ 与 $y_{d}(n)$ 可以分别表示为：

$$x_{\mathrm{d}}(n)=x_{\mathrm{c}}(n T)$$

$$y_{\mathrm{d}}(n)=y_{\mathrm{c}}(nT)$$

式中 T 为抽样信号的抽样周期。

为了得到连续时间信号 $x_{c}(t)$ 和它的离散时间表示 $x_{d}(n)$ 之间频谱的关系，以 $\omega$ 表示连续时间信号的频率，以 $\Omega$ 表示离散时间信号的频率，两者的物理意义都是频率，只不过这里用来区别不同类型信号的变换而已。

抽样信号 $x_{p}(t)$ 可以表示为

$$x_{\mathrm{p}}\left(t\right)=\sum_{\mathrm{n}=-\infty}^{\infty}x_{\mathrm{c}}\left(n T\right)\delta\left(t-n T\right)$$

由于 $\delta(t-nT)$ 的傅里叶变换是 $e^{-j\omega nT}$，所以得到

$$X_{p}(\mathrm{j}\omega)=\sum_{n=-\infty}^{\infty}x_{\mathrm{c}}(n T)\mathrm{e}^{-\mathrm{j}\omega n T}$$

现在考虑 $x_{d}(n)$ 的离散时间傅里叶变换，即

$$X_{\mathrm{d}}(\mathrm{e}^{\mathrm{j}\Omega})=\sum_{n=-\infty}^{\infty}x_{\mathrm{d}}(n)\mathrm{e}^{-\mathrm{j}\Omega n}$$

由式(7.10.1)，将 $x_{d}(n)$ 用 $x_{c}(nT)$ 表示，得到

$$X_{\mathrm{d}}\left(\mathrm{e}^{\mathrm{j}\Omega}\right)=\sum_{n=-\infty}^{\infty}x_{\mathrm{c}}\left(n T\right)\mathrm{e}^{-\mathrm{j}\Omega n}$$

将式(7.10.4)和式(7.10.6)对比，可得 $X_{\mathrm{d}}(\mathrm{e}^{\mathrm{j}\Omega})$ 和 $X_{p}(j\omega)$①之间的关系为

$$X_{\mathrm{d}}(\mathrm{e}^{\mathrm{j}\Omega})=X_{\mathrm{p}}(\mathrm{j}\Omega/T)$$

另外，由连续信号与其理想抽样信号傅里叶变换的关系可得

$$X_{\mathrm{p}}(\mathrm{j}\omega)=\frac{1}{T}\sum_{k=-\infty}^{\infty}X_{\mathrm{c}}\left[\mathrm{j}(\omega-k\omega_{\mathrm{s}})\right]$$

其中 $\omega_{s}=\frac{2\pi}{T}$。由此得到

$$X_{\mathrm{d}}(\mathrm{e}^{\mathrm{j}\alpha})=\frac{1}{T}\sum_{k=-\infty}^{\infty}X_{\mathrm{c}}\left[\mathrm{j}(\Omega-2\pi k)/T\right]$$

式(7.10.9)就是离散时间序列 $x_{d}(n)$ 与对应的连续时间信号 $x_{c}(t)$ 频谱之间的关系，离散时间序列 $y_{d}(n)$ 与对应的连续时间信号 $y_{c}(t)$ 频谱之间的关系也是如此，只是将式(7.10.9)中的 X 改写为 $Y_{0}$。连续时间信号 $y_{c}(t)$ 的恢复可以由序列 $y_{d}(n)$ 产生一个连续时间冲激串 $y_{p}(t)$ 并使其通过低通滤波器来实现。图7.10.3给出了连续信号 $x_{c}(t)$、理想抽样信号 $x_{p}(t)$ 以及离散序列 $x_{d}(n)$ 三者频谱之间的关系。

## §7.11 本章小结

本章是在第6章离散时间信号与系统时域分析基础上展开的变换域z域分析，在内容方面基本上对应于连续时间信号与系统的拉普拉斯变换分析，包括序列z变换、逆z变换以及z变换的性质等关于离散信号的z域分析；应用z变换求解差分方程的系统响应z域分析；以及系统函数及其相关内容的离散时间系统z域分析三大部分。同时简要介绍了序列的傅里叶变换及其性质，最后通过数字滤波器实现模拟滤波功能将本书讨论的连续时间与离散时间信号与系统的分析形成一个整体。

本章讨论的 z 变换与第 5 章讨论的拉普拉斯变换具有突出的对应性，其基础便在于序列 z 变换的定义与抽样信号拉普拉斯变换的等值性，以及 z 平面与 s 平面的关系。其实从历史来看，人们对 z 变换的研究早于拉普拉斯变换的出现。尽管如此，这里实际显示了一种科学研究的规律和方法，即在研究新的领域或问题时，可以借助相同数学模型或数值关系的已有研究成果，去预测和指导研究工作，并在实际研究过程中加以求证。本章具体内容所用的研究规律和方法实际上和拉普拉斯变换讨论中大致相同的，所以在本章具体内容中就没有过多赘述。

由于数字存储比较方便，离散系统中非因果系统的应用要比连续系统更为普遍，因此理解和掌握双边z变换的必要性要大于双边拉普拉斯变换。同样地，收敛域对于双边z变换而言是一个不可忽略的因素。作为重要的计算工具，z变换的性质及逆z变换是读者应高度重视的部分，由于信号及系统的特点，z变换的主要形式是有理多项式的分式，因此借助基本信号z变换的形式，采用部分分式分解法是求逆z变换的主要手段。实际中，变换的基本形式不是一成不变的，例如本章采用的z变换的基本形式是 $\frac{z}{z-a}$，实际上同样可以采用

$\frac{1}{z-a}$ 的形式，只是所对应的基本序列不同而已。z变换不仅可以用来简化差分方程的求解，同时也是求解序列卷积和的重要工具。

作为离散时间系统特性 z 域的具体体现，离散系统函数 $H(z)$ 与连续时间系统中的 $H(s)$ 具有几乎相同的功能。一方面作为计算系统零状态响应的桥梁，同时通过其零极点位置的分布，迅速判断系统的因果性、稳定性等特性，并且通过几何方法确定系统的频响特性。这进一步体现了变换这种方法在科学研究中的意义和价值。

序列的傅里叶变换描述的是序列频域特性，是可以脱离z变换来定义其正变换和逆变换的，本书对此不进行过多讨论，而是作为z变换讨论的延伸和补充。序列及数字信号的傅里叶分析是数字信号处理课程的重要内容，读者可以阅读相关书籍对此有更多的了解。

作为本书的最后一节，我们讨论了利用离散时间系统实现对模拟信号滤波的问题，以期将连续时间系统与离散时间系统的讨论形成一个闭环。这里介绍了模拟滤波器频响特性与相应的离散系统频响特性的关系，以及信号在整个过程中的变化情况，如何设计相应的离散系统也是数字信号处理课程的重要内容。
