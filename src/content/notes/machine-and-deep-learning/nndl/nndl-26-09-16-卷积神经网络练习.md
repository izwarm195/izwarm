——用 LeNet-5 在 MNIST 上做图像分类：手写卷积算子做边缘检测、Subset 抽样、GPU 训练、最优保存，以及"设了种子为什么还不复现"的排查

# 一、公式总结

**记号**：输入 $\boldsymbol X\in\mathbb R^{N\times C_{in}\times H\times W}$（$N$ 批量、$H\times W$ 空间尺寸），卷积核 $\boldsymbol W\in\mathbb R^{C_{out}\times C_{in}\times U\times V}$，偏置 $\boldsymbol b\in\mathbb R^{C_{out}}$。

**① 二维互相关**（书 §5.1；PyTorch 的 `conv2d` 做的就是互相关，**核不翻转**）：

$$
Y_{i,j}=\sum_{u=0}^{U-1}\sum_{v=0}^{V-1}X_{i+u,\;j+v}\,W_{u,v}+b
$$

> 手写 `Conv2d.forward` 里"滑窗 → 逐元素乘 → 求和"正好就是这个式子，没有翻转，所以和 `nn.functional.conv2d` 的数值能对上（实测最大差 $9.5\times10^{-7}$，纯浮点误差）。如果要写成严格意义的卷积，核要先 `flip(0).flip(1)`。

**② 输出尺寸**（书式(5.1)，$p$ 填充、$s$ 步长、$k$ 核边长）：

$$
H_{out}=\left\lfloor\frac{H+2p-k}{s}\right\rfloor+1,\qquad W_{out}=\left\lfloor\frac{W+2p-k}{s}\right\rfloor+1
$$

**③ 拉普拉斯边缘检测算子**（8 邻域版）：

$$
\nabla^2 I(i,j)\;\approx\;8\,I(i,j)-\sum_{(u,v)\in\mathcal N_8(i,j)}I(i+u,\,j+v)
\quad\Longleftrightarrow\quad
\boldsymbol W_{\text{lap}}=\begin{bmatrix}-1&-1&-1\\-1&8&-1\\-1&-1&-1\end{bmatrix}
$$

> **核元素和 $=0$ 是这套算子的全部要害**：元素和为 0 ⟺ 对任意常数平面（平坦区域）响应恒为 0 ⟺ 输出只反映"曲率/轮廓"，与亮度无关。反过来，元素和不为 0 的核会把亮度也卷进来（见踩坑 B-1，随机核看起来像"负片"就是这个原因）。

**④ 参数量**（本练习的 LeNet-5，输入 $[N,1,28,28]$）：

| 层 | 配置 | 输出形状 | 权重形状 | 参数量 |
|---|---|---|---|---|
| conv1 | $3\times3$, $p=1$ | $[N,6,28,28]$ | $[6,1,3,3]$ | $6\cdot1\cdot9+6=60$ |
| pool1 | MaxPool $2\times2$ | $[N,6,14,14]$ | — | 0 |
| conv2 | $5\times5$ | $[N,12,10,10]$ | $[12,6,5,5]$ | $12\cdot6\cdot25+12=1812$ |
| pool2 | MaxPool $2\times2$ | $[N,12,5,5]$ | — | 0 |
| flatten | — | $[N,300]$ | — | 0 |
| linear1 | $300\to80$ + ReLU | $[N,80]$ | $[80,300]$ | $24080$ |
| linear2 | $80\to10$ | $[N,10]$ | $[10,80]$ | $810$ |
| **合计** | | | | **26762** |

> 记住这个数：训练集只有 1000 张时，参数 : 样本 $\approx 27:1$——这是第四节的起点。

**⑤ softmax + 交叉熵的合成梯度**（与第二部分式①同一件事）：

$$
\hat y_{nc}=\frac{\exp z_{nc}}{\sum_{c'}\exp z_{nc'}},\qquad
\mathcal R=-\frac1N\sum_{n=1}^{N}\log\hat y_{n,y_n},\qquad
\delta\boldsymbol Z=\frac{\partial\mathcal R}{\partial\boldsymbol Z}=\frac1N\Big(\hat{\boldsymbol Y}-\boldsymbol Y_{\text{one-hot}}\Big)
$$

> `nn.CrossEntropyLoss` 内部自带 `log_softmax`，所以**喂进去的必须是 logits（未过激活的原始输出）**。这条在踩坑 B-2 里是要害：末层再套一个 ReLU，等于把 logits 的一半取值域切掉。

**⑥ 小批量更新**（一个 epoch 走 $\lceil N/B\rceil$ 次，本练习 $N=20000,B=64$ → 每轮 313 次）：

$$
\boldsymbol\theta\leftarrow\boldsymbol\theta-\eta\cdot\frac{1}{B}\sum_{n\in\mathcal B}\frac{\partial\mathcal R_n}{\partial\boldsymbol\theta}
$$

**⑦ 最优保存与早停的判定**：

$$
\text{improved}=\begin{cases}m_{dev}>\text{best},&\texttt{higher\_is\_better}\\[2pt] m_{dev}<\text{best},&\text{otherwise}\end{cases}
\qquad
\texttt{no\_improve}\ge\texttt{patience}\;\Longrightarrow\;\text{early stop}
$$

> `improved` 为真时才 `save(best_path)`；**`best_path` 没传就什么都不会存**——这一条在踩坑 B-4 里直接吃掉了 0.5 个百分点。

**⑧ "全局统一 seed"到底要钉住几处**：

| 随机源 | 由谁控制 |
|---|---|
| Python `random` | `random.seed(SEED)` |
| NumPy | `np.random.seed(SEED)` |
| torch CPU / CUDA 全局 RNG（决定权重初始化） | `torch.manual_seed(SEED)` + `torch.cuda.manual_seed_all(SEED)` |
| `DataLoader(shuffle=True)` 的抽样顺序 | 独立的 `torch.Generator().manual_seed(SEED)` |
| **cuDNN 卷积算法选择** | `torch.backends.cudnn.deterministic = True`、`benchmark = False` |

> 前四行是"设种子"，第五行才是"复现"。cuDNN 默认会给卷积挑带 `atomicAdd` 的实现，浮点加法不满足结合律 → 同一份代码两次跑，权重从第 4 个 epoch 起在小数末位分叉。详见踩坑 D。

# 二、完整代码

> 可视化单元（训练曲线、单样本前向过程图、第一层卷积核图）略。

```python
# ---------------- imports ----------------
import torch
import torch.nn as nn
from pathlib import Path

# ---------------- 全局统一随机种子 ----------------
import random

import numpy as np

SEED = 3          # 由 seed 0~9 扫描挑出（dev_metric 最好的那个），改这一行即可整套换种子


def set_seed(seed=SEED):
    """把 random / numpy / torch(CPU+CUDA) 的随机源统一钉到同一个 seed。"""
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    torch.cuda.manual_seed_all(seed)
    # 只设种子还不够：cuDNN 给卷积挑的默认算法里有带 atomicAdd 的非确定性实现，
    # 同一份代码跑两遍，权重会从第 4 个 epoch 起在最后几位小数上分叉（实测）。
    # 这两行强制走确定性算法，代价是卷积稍慢一点。
    torch.backends.cudnn.deterministic = True
    torch.backends.cudnn.benchmark = False
    return seed


set_seed(SEED)
print(f'global seed = {SEED}')

# ---------------- Runner ----------------
class Runner():
    def __init__(self, model, loss_fn, metric_fn, optimizer, higher_is_better=False, device=None):
        self.model = model
        self.loss_fn = loss_fn
        self.metric_fn = metric_fn
        self.optimizer = optimizer
        self.higher_is_better = higher_is_better
        self.device = torch.device(device) if device is not None else None
        if self.device is not None:
            self.model.to(self.device)
        self.history = {
            'train_loss': [], 'train_metric': [],
            'dev_loss': [], 'dev_metric': [],
            'batch_loss': []
        }

    def _to_device(self,batch):
        if self.device is not None:
            return tuple(t.to(self.device) if torch.is_tensor(t) else t for t in batch)
        else: 
            return batch

    def fit(self, train_loader, dev_loader = None, num_epochs=100, log_every = 1, patience = None, seed = None, best_path = None):
        if patience is not None and patience < 1:
            print('invalid "patience"')
        if log_every is not None and log_every < 1:
            print('invalid "log_every"')
        if seed is not None:
            torch.manual_seed(seed)
        best = -float('inf') if self.higher_is_better else float('inf')
        no_improve = 0
        

        for epoch in range(num_epochs):
            self.model.train()
            batch_loss, batch_metric, n = 0.0, 0.0, 0
            for batch in train_loader:
                *inputs, y = self._to_device(batch)
                self.optimizer.zero_grad()
                out = self.model(*inputs)
                loss = self.loss_fn(out,y)
                metric = self.metric_fn(out,y)
                loss.backward()
                self.optimizer.step()
                batch_size = y.shape[0]
                batch_loss += loss * batch_size
                batch_metric += metric * batch_size
                n += batch_size
                self.history['batch_loss'].append(loss)
            train_loss = batch_loss / n
            train_metric = batch_metric / n
            self.history['train_loss'].append(train_loss)
            self.history['train_metric'].append(train_metric)
            
            should_log = log_every is not None and ((epoch+1) % log_every == 0) 
            should_stop = False
            improved = 0
            if dev_loader is not None:
                dev_loss, dev_metric = self.evaluate(dev_loader)
                self.history['dev_loss'].append(dev_loss)
                self.history['dev_metric'].append(dev_metric)
                improved = (dev_metric > best) if self.higher_is_better else (dev_metric < best)
                if improved:
                    best = dev_metric
                    no_improve = 0
                    if best_path is not None:
                        self.save(best_path)
                else:
                    no_improve += 1
                if should_log:
                    mark = '*'if improved else ''
                    print(f'epoch {epoch+1:2d}: '
                          f'train_loss={train_loss:.4f} train_metric={train_metric:.4f} '
                          f'dev_loss={dev_loss:.4f} dev_metric={dev_metric:.4f} '
                          f'{mark}')
                if patience is not None and(no_improve >= patience):
                    if log_every is not None:
                        print(f'early stop at epoch {epoch+1}')
                    should_stop = True
            elif should_log:
                print(f'epoch {epoch+1:4d} train_loss={train_loss:.4f}')
            if should_stop:
                break

    @torch.no_grad()
    def evaluate(self, loader):
        was_training = self.model.training
        self.model.eval()
        try:
            batch_loss, batch_metric, n = 0.0, 0.0, 0
            for batch in loader:
                *inputs, y = self._to_device(batch)
                loss = self.loss_fn(self.model(*inputs), y)
                metric = self.metric_fn(self.model(*inputs), y)
                batch_size = y.shape[0]
                batch_loss += loss * batch_size
                batch_metric += metric * batch_size
                n += batch_size
            dev_loss = batch_loss / n
            dev_metric = batch_metric / n if self.metric_fn is not None else dev_loss
            return dev_loss, dev_metric
        finally:
            self.model.train(was_training)
                
    def save(self,best_path):
        Path(best_path).parent.mkdir(parents = True, exist_ok = True)
        torch.save(self.model.state_dict(), best_path)

    def load(self, path):
        state = torch.load(path, weights_only = True, map_location = self.device)
        self.model.load_state_dict(state)

# ---------------- 手写 Conv2d（互相关，与 PyTorch 语义一致） ----------------
class Conv2d():
    def __init__(self, weight, padding = 0, stride = 1):
        self.weight = weight 
        self.padding = padding
        self.stride = stride

    def forward(self,X):
        new_X = nn.functional.pad(X, pad=(self.padding,self.padding,self.padding,self.padding), mode='constant', value = 0)
        u,v = self.weight.shape
        output_w = (new_X.shape[1] - u) // self.stride + 1
        output_h = (new_X.shape[2] - v) // self.stride + 1
        output = X.new_zeros((X.shape[0],output_w,output_h))
        for i in range(output_w):
            for j in range(output_h):
                output[:,i,j] = (torch.sum(
                    new_X[:, self.stride * i: self.stride * i + u, self.stride * j:self.stride * j + v] * self.weight, dim = (1,2)
                ))
        return output

# ---------------- Data + 拉普拉斯边缘检测 ----------------
from pathlib import Path
from torchvision import datasets
from torchvision.transforms import Compose, Resize, ToTensor, Normalize

CACHE = str(Path.home() / '.cache' / 'torch_data')
MNIST = datasets.MNIST(
    CACHE, train = True, download = True, transform=ToTensor()
)
MNIST_test = datasets.MNIST(
    CACHE, train=False, download = True, transform=ToTensor()
)
img, label = MNIST[0]

# --laplacian convolution--：核必须在构造时传进去，否则 Conv2d 用的还是随机权重
laplacian = torch.tensor([[-1,-1,-1],[-1,8,-1],[-1,-1,-1]])
conv = Conv2d(laplacian, 1, 1)
l_img = conv.forward(img)

# ---------------- Subset 抽样 ----------------
from torch.utils.data import DataLoader, Subset
train_dataset = Subset(MNIST, range(20000))
dev_dataset = Subset(MNIST, range(20000, 20200))
test_dataset = Subset(MNIST_test, range(200))

# ---------------- LeNet-5 ----------------
class LeNet_5(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(1,6,kernel_size=(3,3),stride =1, padding= 1) # 6*28*28
        self.pool1 =nn.MaxPool2d(kernel_size=(2,2)) # 6*14*14
        self.conv2 = nn.Conv2d(6,12,kernel_size= 5) # 12*10*10
        self.pool2 = nn.MaxPool2d(kernel_size=(2,2))# 12*5*5
        self.linear1 = nn.Linear(12*5*5, 80)
        self.linear2 = nn.Linear(80,10)
        self.ac = nn.functional.relu
        
    def forward(self, x):
        x = self.pool1(self.conv1(x))
        x = self.pool2(self.conv2(x))
        x = self.ac(self.linear1(x.flatten(1)))   # flatten(1)：只压平 C,H,W，保留 batch 维
        x = self.linear2(x.flatten(1))            # 末层不接激活：返回 logits 给 CrossEntropyLoss
        return x

# ---------------- Loaders + 训练 ----------------
def make_loader(dataset, batch_size=64, shuffle=True):
    """每个 loader 自带一个固定 seed 的 Generator —— shuffle 顺序也钉死，
    否则它走全局 RNG，SEED 换了它也跟着变，实验不可复现。"""
    return DataLoader(dataset, batch_size=batch_size, shuffle=shuffle,
                      generator=torch.Generator().manual_seed(SEED))


train_loader = make_loader(train_dataset)
dev_loader = make_loader(dev_dataset)
test_loader = make_loader(test_dataset)

# Init
from nndl import accuracy

set_seed(SEED)          # 建模型前再钉一次：保证权重初始化与 SEED 一一对应
model = LeNet_5()
loss_fn = nn.CrossEntropyLoss()
metric_fn = accuracy
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
runner = Runner(model, loss_fn, metric_fn, optimizer, higher_is_better=True, device='cuda')

runner.fit(train_loader=train_loader, dev_loader=dev_loader, num_epochs=50, log_every=1,
           patience=10, best_path='checkpoint/lenet5_best.pt', seed=SEED)
```

# 三、踩坑记录——出现的错误逐个分析

## A. 报错级（一跑就崩，最好修）

1. **`Runner` 只搬了 batch，没搬模型**（本次最花时间的一个）
   - 报错：`RuntimeError: Input type (torch.cuda.FloatTensor) and weight type (torch.FloatTensor) should be the same`。
   - 原因：`__init__` 里存了 `self.device`、`_to_device` 把 batch 送到 cuda，但**从没写过 `self.model.to(self.device)`**——权重还留在 cpu。
   - 修正：`__init__` 里补 `if self.device is not None: self.model.to(self.device)`。
   - 附带一条：`optimizer` 是在 `Runner` 之前用 `model.parameters()` 建的，**不需要重建**——`nn.Module.to()` 就地替换 `param.data`，`Parameter` 对象本身不变，优化器照样指向它。

2. **`x.flatten()` 少了 `1`**
   - 报错：`RuntimeError: mat1 and mat2 shapes cannot be multiplied (1x1200 and 300x80)`。
   - 原因：`pool2` 输出是 $[N,12,5,5]$，`flatten()` 默认从第 0 维开始压，把 **batch 维也压平了** → $[N\cdot300]$；`Linear(300,80)` 收到一个 $1\times1200$ 的矩阵。正确写法是 `x.flatten(1)` → $[N,300]$。
   - **教训：任何"展平"操作都要显式写出 `start_dim`，不要依赖默认值。**

3. **`should_log = ((epoch+1) % log_every == 0) and log_every is not None`**
   - 原因：想用 `and` 短路来挡 `log_every=None`，但**判断顺序反了**——`%` 先执行，`log_every=None` 时直接 `TypeError: unsupported operand type(s) for %: 'int' and 'NoneType'`。
   - 修正：把便宜且安全的布尔判断放前面：`log_every is not None and ((epoch+1) % log_every == 0)`。
   - **教训：`and` 短路保护的是"右操作数的求值"，被保护的条件必须写在右边，被保护的操作不能出现在左边。**

## B. 静默错误级（不崩但错，最难发现）

1. **拉普拉斯核定义了却没用上**（本次第一现场）
   - 现象：`laplacian` 张量写得好好的，但右边那张边缘检测图看起来像**原图的负片/浮雕**，不是轮廓。
   - 原因：`l_img = conv.forward(img)` 用的是 `conv` 自己的权重，而当时 `Conv2d.__init__(self, kernel_size, ...)` 里是 `self.weight = torch.randn(kernel_size, kernel_size)`——**随机初始化，且没有任何参数能把核传进去**。定义好的 `laplacian` 在下一行被彻底遗忘。
   - 实测证据：

     | 指标 | 数值 |
     |---|---|
     | `l_img` 与真拉普拉斯响应最大差 | 8.59 |
     | 两者相关系数 | −0.356 |
     | 随机核元素和 | −2.324（拉普拉斯核应为 0） |
     | corr(随机核响应, 原图) | −0.657（**强负相关 = 负片**） |
     | 笔画内部平均响应 / 背景 | −2.414 / −0.012 |

   - 修正：把核做成构造参数（`Conv2d(laplacian, 1, 1)`）。改完后与 `nn.functional.conv2d` 的最大差降到 $9.5\times10^{-7}$——**说明手写的滑窗逻辑本来就是对的，锅全在核上**。
   - **教训：核元素和是否为 0，决定了输出是"边缘"还是"亮度图"。看到卷积结果像原图的反相/浮雕，先算一下核的和。**

2. **末层接了 ReLU**
   - 写法：`x = self.ac(self.linear2(x.flatten(1)))`。
   - 原因：`nn.CrossEntropyLoss` 要的是 **logits**，中间层接 ReLU 没问题，但最后一层不能接——ReLU 会把所有负 logits 截成 0（实测输出 `min = 0.0`），类别排序被削掉一半取值域。
   - 危害：**完全不报错**，只表现为"训练得慢/上不去"，是最难反查的一类。
   - 修正：`return self.linear2(...)`，把激活去掉。

3. **`imshow(cmap='RdBu_r')` 的色标中点不是 0**
   - 原因：`imshow` 默认按**数据范围**取色，`RdBu_r` 的中性色落在 `(min+max)/2`，不是 0。那次随机核输出范围 $(-4.811,\,2.399)$，中点 $-1.206$——"白色"代表的其实是 $-1.206$，负值区域被系统性误读。
   - 修正：有符号响应必须显式对称：`m = img.abs().max()`，`imshow(img, cmap='RdBu_r', vmin=-m, vmax=m)`，再加一根 `colorbar`。

4. **`best_path` 没传 → 最优权重被丢掉**（本次实际损失最大的一处）
   - 现象：日志里 `*` 只在 epoch 5 和 10 出现过，之后一百多轮再没出现过。
   - 推演：`early stop at epoch 116` + `patience=100` ⇒ **最后一次 `*`（即 dev 最优）在第 16 轮**，之后 100 轮一次都没涨过。
   - 后果：`runner.fit(...)` 里没有传 `best_path`，于是 `if best_path is not None: self.save(best_path)` 永不执行——**第 16 轮那份 dev 0.8850 的权重从没落盘**，训练结束时内存里是第 116 轮的模型（dev 0.8800）。
   - 修正：传 `best_path='checkpoint/lenet5_best.pt'`，训练完再 `runner.load(best_path)` 回到最优那一版。
   - **教训：`patience=100` 在 20000 张样本上等于没有早停；早停和最优保存是配套的，只开一半等于白训练 100 轮。**

## C. 维度 / 形状约定级

1. **手写 `Conv2d` 把 `X.shape[0]` 当 batch**
   - `img, label = MNIST[0]` 拿到的是 $[C,H,W]=[1,28,28]$（**没有 batch 维**），而 `forward` 按 $[N,H,W]$ 解释输入：`X.shape[0]` 被当成 batch、`X.shape[1]/[2]` 被当成空间维。单通道时 $C=1$ 碰巧等于 $N=1$，所以能跑；
   - 喂真 batch 立刻炸：`RuntimeError: Trying to create tensor with negative dimension -1: [4, -1, 28]`（`new_X.shape[1]` 取到的是通道数 1，减掉核边长 3 得负）。
   - 修正：先约定清楚是 $[N,H,W]$ 还是 $[N,C,H,W]$；前者只适合单通道演示，后者要 `img[None]` 补 batch 或显式按通道维循环。

2. **类名 `Conv2d` 遮蔽了 `torch.nn.Conv2d`**
   - 本文件里 `LeNet_5` 用的是带前缀的 `nn.Conv2d` 所以没出事，但一旦有人写 `from torch.nn import Conv2d` 就会被这个自定义类顶掉。建议改名 `MyConv2d`。

3. **零填充 + 零和核会在图像边缘造出假边**
   - 原因：padding 填 0，而核的元素和是 0、图像边缘却不是 0，于是边界处响应不为 0，四周出现一圈假"轮廓"。
   - 本练习不显现：实测 MNIST 这张图外圈 108 个像素全为 0，所以边界响应正好是 0；换成居中/满幅图像就会暴露。稳妥写法是 `padding_mode='replicate'`（或 `'reflect'`）。

## D. 复现性级（设了种子也不复现）

1. **notebook 里散着三套互不相干的随机源**
   - `random.seed(0)`（数据单元）、`torch.manual_seed(100)` + `generator=manual_seed(100)`（训练单元）、`Runner.fit(seed=7)`。
   - 最要命的是：`model = LeNet_5()` 在 `fit` **之前**执行，`fit` 里的 `torch.manual_seed(7)` 管不到权重初始化——**每次重跑权重都不一样**。

2. **统一成一个 `set_seed()` 之后，仍然不复现**
   - 验证方法：把 notebook 前 9 个单元在**两个独立命名空间**里各跑一遍，逐字符比对 stdout、逐元素比对 `state_dict`。
   - 第一次结果：**权重不一致**，从第 4 个 epoch 起分叉（小数末位）：

     ```
     run1: epoch  4: train_loss=0.3303 train_metric=0.9042 dev_loss=0.3503 dev_metric=0.8850 *
     run2: epoch  4: train_loss=0.3303 train_metric=0.9041 dev_loss=0.3503 dev_metric=0.8850 *
     ```

   - 原因：**cuDNN 给卷积挑的默认算法里有带 `atomicAdd` 的非确定性实现**。多个线程用原子加累加同一个输出元素，浮点加法不满足结合律 → 每次求和顺序不同 → 结果在末位分叉 → 经反向传播放大。
   - 修正：`torch.backends.cudnn.deterministic = True` + `torch.backends.cudnn.benchmark = False`。
   - 修正后：两次独立运行 **stdout 逐字符相同、权重逐元素相同、与 notebook 内嵌日志也逐字符相同**。
   - **教训：`manual_seed` 只解决"抽哪个数"，不解决"算的时候顺序一样不一样"。GPU 上要复现，必须同时管住 RNG 和算子实现。**

## E. 工程 / 自检级

1. **`history` 里存的是带梯度的 tensor**
   - `self.history['batch_loss'].append(loss)`：`loss` 是带 `grad_fn` 的 0 维 tensor，**永久持有计算图**；`batch_loss += loss * batch_size` 同样是一路带图累加，整个 epoch 的计算图在 epoch 结束前都活着。
   - 危害：GPU 上跑多轮会看到显存持续上涨。跑 50 轮以内不明显，换大模型/长序列就会 OOM。
   - 修正：`loss.item()`。画图时若拿到的是 tensor，先 `.detach()` 再 `float()`——不 detach 会刷 `Converting a tensor with requires_grad=True to a scalar` 警告，本次就是这个警告把问题暴露出来的。

2. **`evaluate` 里每个 batch 前向两次**
   - 写成 `self.loss_fn(self.model(*inputs), y)` 和 `self.metric_fn(self.model(*inputs), y)`，白白多跑一遍前向。`fit` 那边已经改成 `out = self.model(*inputs)` 了，`evaluate` 没跟上。

# 四、思考：dev_metric 为什么卡在 0.88（附 10 组种子 + 12 组消融）

**现象**（早期一轮训练，训练集只有 1000 张）：

| | epoch 10 | epoch 30 | epoch 115 |
|---|---|---|---|
| train_loss | 0.2379 | **0.0086** | 0.0005 |
| train_metric | 0.9270 | **1.0000** | 1.0000 |
| dev_loss | 0.4570 | 0.4402 | **0.5807 ↑** |
| dev_metric | 0.8450 | 0.8800 | 0.8800 |

训练集在 epoch 30 被 100% 记住，之后 85 个 epoch 里 dev 准确率一步没动，dev_loss 却从 0.44 单调涨到 0.58——**教科书式的过拟合**。而 LeNet-5 有 **26762** 个参数，训练样本 1000 张、10 类每类约 100 张，参数 : 样本 $\approx 27:1$。**0.88 不是模型的上限，是 1000 张样本的上限。**

## 4.1 消融实验

统一设置：dev = 2000 张 MNIST_test、test = 另外 8000 张，都按 dev 最优选权重。

| 配置（训练 1000 张） | best_dev | test_acc | 相对① |
|---|---|---|---|
| ① 原始：`ToTensor` + SGD lr=0.1 | 0.8870 | 0.9130 | — |
| ② ① + `Normalize((0.1307,),(0.3081,))` | 0.8970 | 0.9204 | **+0.7%** |
| ③ ② + `weight_decay=1e-4` | 0.8960 | 0.9200 | +0.7% |
| ④ ② + **数据增强** `RandomAffine(10°, 0.1, 0.9~1.1)` | 0.9420 | **0.9546** | **+4.2%** |
| ⑤ ④ + weight_decay + Dropout(0.5) | 0.9380 | 0.9495 | +3.7%（反而降了） |
| ⑥ ⑤ + Adam(lr=1e-3) | 0.9225 | 0.9387 | +2.6%（也降了） |
| ⑦ ② + SGD lr=**0.1** + momentum=0.9 | 0.6840 | **0.7288** | **−18%** |
| ⑧ ② + SGD lr=**0.01** + momentum=0.9 | 0.8910 | 0.9169 | +0.4%（和不用 momentum 持平） |

**只加数据量（都开增强）：**

| 训练样本 | best_dev | test_acc |
|---|---|---|
| 1000 | 0.9420 | 0.9546 |
| 2000 | 0.9650 | 0.9732 |
| 5000 | 0.9790 | 0.9838 |
| **60000（全量）** | **0.9905** | **0.9902** |

## 4.2 结论（按收益排序）

1. **数据量是第一优先级**，1000 → 60000 带来 **+7.7%**，比其余所有手段之和还多。`Subset` 抽样是练习要求，练完就该换回全量。
2. **数据增强是第二优先级**，+4.2%，小样本下唯一真正管用的一招。手写数字对小幅平移/旋转本来就不敏感，`RandomAffine(degrees=10, translate=(0.1,0.1), scale=(0.9,1.1))` 就够。
   注意：**训练集用增强版、验证集必须用干净版**，否则验证指标也在随机抖动。
3. **`Normalize` 要加**，+0.7% 且收敛更稳。原来的 `transforms` 里 `Normalize` 已经 import 了却没用。
4. **`weight_decay` 加了没坏处也没好处**（0.9204 → 0.9200），别指望它救小样本。
5. **Dropout 和 Adam 在这个设置下都是负收益**（−0.5%、−1.6%），小样本 + 已增强时 Dropout 0.5 会削弱拟合能力。
6. **加 momentum 必须同步降 lr**：`lr=0.1 + momentum=0.9` 直接崩到 0.73 / 0.59；降到 `lr=0.01` 才回到 0.9169，和不用 momentum 的 0.9204 基本持平。要么不加，要么 `SGD(lr=0.01, momentum=0.9)`。
7. **dev / test 都太小**：200 张时 1 张 = 0.5%，准确率标准差 $\sqrt{0.88\times0.12/200}\approx2.3\%$。日志里 0.8750 / 0.8800 / 0.8850 之间**没有统计显著性差异**，"按 dev 选最优模型"实际上是在过拟合验证集。dev 至少 2000，test 用全量 10000。

# 五、与上一次练习的对照

第二部分是**全连接 + autograd + 小批量**，这次把"层"从 `Linear` 换成 `Conv2d`，把"数据"从 Iris 换成 MNIST。真正新增的东西有四块：

| | 第二部分（MLP） | 这次（LeNet-5） |
|---|---|---|
| 核心算子 | `Linear`：全连接，权重 $[M,D]$ | `Conv2d`：局部连接 + 权重共享，核 $[C_{out},C_{in},U,V]$，**参数量与图像尺寸无关** |
| 输入约定 | 二维 $[N,M]$，展平 | 四维 $[N,C,H,W]$，**空间结构必须保住**（这也是 `flatten` 必须写 `start_dim=1` 的原因） |
| 手工实现的对象 | 各层 `backward`（链式法则） | 前向的滑窗互相关（反向交给 autograd） |
| 新增工程件 | `Runner` 雏形 | best-checkpoint + early stop + 设备搬运 + **全局可复现** |
