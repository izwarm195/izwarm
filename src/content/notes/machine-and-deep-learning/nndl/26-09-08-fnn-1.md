——用 Op 类手写两层 MLP，并手动反向传播梯度

承接 [NNDL 26-09-03 Logistic回归练习](/notes/machine-and-deep-learning/nndl/26-09-03-logistic/)：这次把"一个线性层"升级成**两层全连接网络**（`Linear + Logistic` 叠两次），仍然不用 PyTorch autograd，**手工推导并实现每一层的反向传播**，在 `make_moons(noise=0.01)` 上训练，画学习曲线和**弯曲的**决策面。练习目标：把"链式法则 → 每层 backward → 参数梯度 → 更新"这条链亲手打通，并验证手写梯度与"公式长什么样"一一对应。

# 一、公式总结

**记号**：批量时 $\boldsymbol{X}\in\mathbb R^{N\times M}$、$\boldsymbol{Y}\in\mathbb R^{N\times D}$，**每行是一个样本**；$\boldsymbol{W}\in\mathbb R^{M\times D}$，$\boldsymbol{b}\in\mathbb R^{1\times D}$。单样本推导用小写 $\boldsymbol{x}\in\mathbb R^M,\ \boldsymbol{y}\in\mathbb R^D$。损失记 $\mathcal R$；$\delta\boldsymbol A=\tfrac{\partial\mathcal R}{\partial\boldsymbol A}$ 为上游传来的梯度。层标 $^{(l)}$：$(1)$=隐藏层、$(2)$=输出层；算子推导中去掉层标（书 §4.2.4.3 提醒）。

**前向**（两层激活均为 Logistic，输出 $\hat{\boldsymbol y}$；损失为二分类交叉熵，书式(3.5)）：

$$
\boldsymbol a^{(0)}=\boldsymbol X,\qquad \boldsymbol z^{(l)}=\boldsymbol a^{(l-1)}\boldsymbol W^{(l)}+\boldsymbol b^{(l)},\qquad \boldsymbol a^{(l)}=\sigma\big(\boldsymbol z^{(l)}\big)\ \,(l=1,2),\qquad \hat{\boldsymbol y}=\boldsymbol a^{(2)}
$$

**① 损失对输出 $\hat{\boldsymbol y}$（公式(4.10)）**（$\frac{1}{\hat{\boldsymbol y}}$ 为逐元素倒数，$\odot$ 逐元素积，$\boldsymbol y$ 标签）：

$$
\frac{\partial\mathcal R}{\partial\hat{\boldsymbol y}}=-\frac{1}{N}\Big(\frac{1}{\hat{\boldsymbol y}}\odot\boldsymbol y-\frac{1}{1-\hat{\boldsymbol y}}\odot(1-\boldsymbol y)\Big)
$$

**② Logistic 激活反向（公式(4.14)/(4.15)）**，$\delta\boldsymbol a$ 为上游梯度：

$$
\delta\boldsymbol z=\boldsymbol a\odot(1-\boldsymbol a)\odot\delta\boldsymbol a\qquad\overset{\text{批量}}{\Longrightarrow}\qquad\delta\boldsymbol Z=\boldsymbol A\odot(1-\boldsymbol A)\odot\delta\boldsymbol A
$$

**③ 线性层反向（公式(4.17)–(4.22)）**，$\delta\boldsymbol y$ 为上游梯度：

- 输入梯度：$\delta\boldsymbol x=\boldsymbol W\,\delta\boldsymbol y$（单样本, (4.17)）$\Rightarrow\ \delta\boldsymbol X=\delta\boldsymbol Y\,\boldsymbol W^{\mathsf T}$（批量, (4.18)）
- 参数梯度：$\delta\boldsymbol W=\boldsymbol x\,\delta\boldsymbol y^{\mathsf T},\ \delta\boldsymbol b=\delta\boldsymbol y^{\mathsf T}$（单样本, (4.19)/(4.20)）
- 批量：$\delta\boldsymbol W=\boldsymbol X^{\mathsf T}\delta\boldsymbol Y,\qquad \delta\boldsymbol b=\boldsymbol 1^{\mathsf T}\delta\boldsymbol Y$（(4.21)/(4.22)，$\delta\boldsymbol b$ 即沿样本维 $N$ 求和，对应代码 `torch.sum(grads, dim=0)`）

  **④ 整网反向顺序**（图 4.4，自损失起沿图反传）：

  $$
  \hat{\boldsymbol y}\xrightarrow{\text{①}}\delta\hat{\boldsymbol y}\xrightarrow{\text{激活2 ②}}\delta\boldsymbol z^{(2)}\xrightarrow{\text{线性2 ③}}\big(\delta\boldsymbol W^{(2)},\delta\boldsymbol b^{(2)},\delta\boldsymbol a^{(1)}\big)\xrightarrow{\text{激活1 ②}}\delta\boldsymbol z^{(1)}\xrightarrow{\text{线性1 ③}}\big(\delta\boldsymbol W^{(1)},\delta\boldsymbol b^{(1)},\delta\boldsymbol X\big)
  $$

  **⑤ 优化器更新（§4.2.4.6, `BatchGD.step`）**：

  $$
  \boldsymbol W\leftarrow\boldsymbol W-\eta\,\delta\boldsymbol W,\qquad \boldsymbol b\leftarrow\boldsymbol b-\eta\,\delta\boldsymbol b
  $$

> 记忆点：① 是"损失→输出层"入口；② 是激活的**逐元素**门（只有它做 $\odot$，用**输出** $a$ 而不是净输入 $z$）；③ 线性层三件套 = 输入梯度转置回传 + 两个参数梯度；④ 决定了 backward 的调用顺序恰好是 forward 的逆序。

# 二、完整代码（用时约 90 min）

```python
import torch
from nndl import Op, Optimizer
from nndl.data import make_moons

# ---------------- data ----------------
X, y = make_moons(1000, noise=0.01)
X_train = X[:799]
y_train = y[:799].reshape(-1, 1)
X_dev = X[799:999]
y_dev = y[799:999].reshape(-1, 1)

# ---------------- BinaryCrossEntropyLoss(BCE) ----------------
class BCE_Loss(Op):
    def __init__(self, model):
        super().__init__()
        self.labels = self.predicts = None; self.num = None
        self.model = model

    def forward(self, labels, predicts):
        self.labels = labels
        self.predicts = predicts
        self.num = labels.shape[0]
        loss = -1 / self.num * (torch.matmul(self.labels.T, torch.log(self.predicts))
                                + torch.matmul((1 - self.labels).T, torch.log(1 - self.predicts)))
        loss = torch.squeeze(loss, dim=1)
        return loss

    def backward(self):
        inputs_grads = -1 / self.num * (self.labels / self.predicts
                                        - (1 - self.labels) / (1 - self.predicts))
        self.model.backward(inputs_grads)

# ---------------- Logistic 算子 ----------------
class Logistic(Op):
    def __init__(self):
        super().__init__()
        self.inputs = None
        self.params = None

    def forward(self, inputs):
        self.inputs = inputs
        self.outputs = 1 / (1 + torch.exp(-self.inputs))
        return self.outputs

    def backward(self, output_grads):
        output_grads_inputs = torch.mul(self.outputs, (1 - self.outputs))
        return torch.mul(output_grads, output_grads_inputs)

# ---------------- Linear 算子 ----------------
class Linear(Op):
    def __init__(self, input_size, output_size):
        super().__init__()
        self.inputs = None
        self.params = {
            'w': torch.randn(input_size, output_size),
            'b': torch.zeros(1, output_size)
        }
        self.grads = {}

    def forward(self, inputs):
        self.inputs = inputs
        return torch.matmul(inputs, self.params['w']) + self.params['b']

    def backward(self, grads):
        self.grads['w'] = torch.matmul(self.inputs.T, grads)
        self.grads['b'] = torch.sum(grads, dim=0)          # 沿样本维求和，对应 δb = 1ᵀδY
        return torch.matmul(grads, self.params['w'].T)     # 对输入的梯度 δX = δY Wᵀ

# ---------------- MLP：Linear→Logistic ×2 ----------------
class MLP(Op):
    def __init__(self, input_size, hidden_size, output_size):
        super().__init__()
        self.fc1 = Linear(input_size, hidden_size)
        self.ac1 = Logistic()
        self.fc2 = Linear(hidden_size, output_size)
        self.ac2 = Logistic()
        self.layers = [self.fc1, self.ac1, self.fc2, self.ac2]

    def forward(self, inputs):
        z1 = self.fc1(inputs)
        a1 = self.ac1(z1)
        z2 = self.fc2(a1)
        a2 = self.ac2(z2)
        return a2

    def backward(self, loss_grad):
        # 调用顺序 = forward 的逆序；变量名建议按"梯度是关于谁的净输入/活性值"命名
        gz2 = self.ac2.backward(loss_grad)   # 对 z2 的梯度
        ga1 = self.fc2.backward(gz2)         # 对 a1 的梯度；并写入 fc2.grads
        gz1 = self.ac1.backward(ga1)         # 对 z1 的梯度
        gx  = self.fc1.backward(gz1)         # 对 X 的梯度；并写入 fc1.grads

# ---------------- Optimizer ----------------
class BatchGD(Optimizer):
    def __init__(self, init_lr, model):
        super().__init__(init_lr, model)

    def step(self):
        for layer in self.model.layers:
            if hasattr(layer, 'params') and isinstance(layer.params, dict):  # 跳过激活层
                for key in layer.params.keys():
                    layer.params[key] = layer.params[key] - self.init_lr * layer.grads[key]

# ---------------- Runner ----------------
class Runner():
    def __init__(self, model, loss_fn, metric, optimizer):
        self.model = model
        self.loss_fn = loss_fn
        self.metric = metric
        self.optimizer = optimizer
        self.history = {
            'Train_loss': [], 'dev_loss': [],
            'Train_score': [], 'dev_score': []
        }

    def train(self, train_set, dev_set, num_epochs):
        X, y = train_set
        for epoch in range(num_epochs):
            logits = self.model.forward(X)
            train_loss = self.loss_fn(y, logits)
            train_score = self.metric(y, logits)
            self.loss_fn.backward()
            self.optimizer.step()
            self.history['Train_loss'].append(train_loss)
            self.history['Train_score'].append(train_score)

            dev_loss, dev_score = self.evaluate(dev_set)
            self.history['dev_loss'].append(dev_loss)
            self.history['dev_score'].append(dev_score)

    def evaluate(self, dev_set):
        X, y = dev_set
        logits = self.model.forward(X)
        loss = self.loss_fn(y, logits)
        score = self.metric(y, logits)
        return loss, score

# ---------------- metric ----------------
def accuracy(labels, predicts):
    predicts = (predicts >= 0.5).float()
    return (predicts == labels).float().mean().item()

# ---------------- train ----------------
model = MLP(2, 5, 1)
runner = Runner(model, BCE_Loss(model), accuracy, BatchGD(0.01, model))
runner.train([X_train, y_train], [X_dev, y_dev], 1000)

# ---------------- 可视化：左列上下两张折线图（损失/准确率），右侧大幅决策边界图 ----------------
import matplotlib.pyplot as plt

plt.rcParams['font.sans-serif'] = ['Microsoft YaHei', 'SimHei']
plt.rcParams['axes.unicode_minus'] = False
plt.rcParams['figure.dpi'] = 110          # 提高内嵌 PNG 分辨率，显示更锐利

h = runner.history
ep = list(range(1, len(h['Train_loss']) + 1))
loss_tr = [v.item() if torch.is_tensor(v) else v for v in h['Train_loss']]
loss_dv = [v.item() if torch.is_tensor(v) else v for v in h['dev_loss']]
acc_tr = h['Train_score']
acc_dv = h['dev_score']

fig = plt.figure(figsize=(14, 9), constrained_layout=True)
gs = fig.add_gridspec(2, 2, width_ratios=[1.0, 1.25])


def _decorate(ax, ylabel, title):
    ax.set_xlabel('epoch', fontsize=10)
    ax.set_ylabel(ylabel, fontsize=10)
    ax.set_title(title, fontsize=11)
    ax.grid(True, alpha=0.25, ls='--', lw=0.7)
    ax.legend(loc='best', frameon=True, framealpha=0.9, edgecolor='0.6', fontsize=9)


# 左上：损失曲线（train/dev 各成一线，独立坐标轴）
ax1 = fig.add_subplot(gs[0, 0])
ax1.plot(ep, loss_tr, color='#1f77b4', lw=1.6, label='train loss')
ax1.plot(ep, loss_dv, color='#ff7f0e', lw=1.6, ls='--', label='dev loss')
_decorate(ax1, 'loss', '损失曲线 (train vs dev)')

# 左下：准确率曲线（纵轴自动贴合数据，不与损失刻度混用）
ax2 = fig.add_subplot(gs[1, 0])
ax2.plot(ep, acc_tr, color='#2ca02c', lw=1.6, label='train accuracy')
ax2.plot(ep, acc_dv, color='#d62728', lw=1.6, ls='--', label='dev accuracy')
ax2.set_ylim(bottom=min(min(acc_tr), min(acc_dv)) - 0.05)
_decorate(ax2, 'accuracy', '准确率曲线 (train vs dev)')

# 右侧大图：MLP 决策边界（占满两行，特征空间网格上的 P(y=1)）
ax3 = fig.add_subplot(gs[:, 1])
xs = torch.linspace(X[:, 0].min() - 0.1, X[:, 0].max() + 0.1, 300)
ys = torch.linspace(X[:, 1].min() - 0.1, X[:, 1].max() + 0.1, 300)
GX, GY = torch.meshgrid(xs, ys, indexing='xy')
grid = torch.stack([GX.flatten(), GY.flatten()], dim=1)
with torch.no_grad():
    P = runner.model.forward(grid).reshape(GX.shape).numpy()
cf = ax3.contourf(GX.numpy(), GY.numpy(), P, levels=50, cmap='RdBu', alpha=0.5)
ax3.contour(GX.numpy(), GY.numpy(), P, levels=[0.5], colors='black', linewidths=2)
ax3.scatter(X[:, 0].numpy(), X[:, 1].numpy(), c=y.numpy(),
            cmap='RdBu_r', s=14, marker='.', edgecolor='none', zorder=5)  # 红蓝点交换、置顶
# 叠加 make_moons 原函数的两条无噪声弧线（点画线，颜色与其类别散点一致）
t = torch.linspace(0, torch.pi, 300)
ax3.plot(torch.cos(t).numpy(), torch.sin(t).numpy(), ls='-.', lw=1.6, zorder=6,
         color=plt.cm.RdBu_r(0.0), label='y=0 上弯月（原函数弧线）')
ax3.plot((1 - torch.cos(t)).numpy(), (0.5 - torch.sin(t)).numpy(), ls='-.', lw=1.6, zorder=6,
         color=plt.cm.RdBu_r(1.0), label='y=1 下弯月（原函数弧线）')
ax3.legend(loc='lower left', fontsize=9, frameon=True, framealpha=0.9, edgecolor='0.6')
ax3.set_xlabel('x1', fontsize=11)
ax3.set_ylabel('x2', fontsize=11)
ax3.set_title('MLP 决策边界（P(y=1)=0.5）', fontsize=12)
cb = fig.colorbar(cf, ax=ax3, fraction=0.045, pad=0.03)
cb.set_label('P(y=1)', fontsize=10)

plt.show()
```

# 三、踩坑记录——出现的错误逐个分析

## A. 语法 / 名字级（一跑就崩，最好修）

1. **`self.labels, self.predicts, self.num = None`**（BCE `__init__`）
   - 报错：实例化 BCE 时 `cannot unpack non-iterable NoneType`。
   - 原因：`a, b, c = None` 要求右边可迭代，单个 `None` 解不开。
   - 修正：`self.labels = self.predicts = None; self.num = None`。**教训：连等/解包要分清目标数量与右边结构。**

2. **BatchGD.step：`for key in layer.params[key]`**
   - 原因：想遍历字典键却写成了按变量取值；应为 `layer.params.keys()`。
   - 修正后还有下一层坑：`isinstance(layer.params, dict)` 在**没有 params 的层**（当时的 Logistic）上直接 `AttributeError`——加固为 `hasattr(layer, 'params') and isinstance(...)`（与库 `nndl.optim.BatchGD` 一致）。**教训：遍历容器先确认"遍历什么"；对可选属性先探测再 isinstance。**

## B. 维度 / 数学级（不崩但错，最难发现）

3. **`torch.sum(grads, dim=1)`（Linear 的 b 梯度）**
   - 报错（运行时才暴露）：`RuntimeError: size of tensor a (5) must match ... b (799)`。
   - 原因：`b` 形状 `[1, D]`，应**沿样本维求和**（公式 $\delta\boldsymbol b=\boldsymbol 1^{\mathsf T}\delta\boldsymbol Y$ 对 N 求和），即 `dim=0` → 形状 `[D]`；`dim=1` 沿特征维得到 `[N]=[799]`，和 `[1,5]` 相减形状崩。
   - 修正：`torch.sum(grads, dim=0)`。**教训：张量维度的"哪个轴是样本/哪个是特征"要和参数形状对齐，先心算形状再写求和轴。**

4. **Logistic.backward 用 `inputs*(1-inputs)`（乘在净输入 z 上）**
   - 原因：sigmoid 导数 $\sigma'(z)=a(1-a)$ 要乘在**输出** $a=\sigma(z)$ 上，而 forward 只存了净输入 $z$。
   - 修正：forward 存 `self.outputs`，backward 用 `outputs*(1-outputs)`（对应公式 ②）。
   - 危害：这是**最阴险的一类**——不报错，但梯度全链错误、loss 不降，只能靠"loss 该降不降"反查。**教训：激活反向 = 上游梯度 × 激活对净输入的导数，逐元素门要用输出算。**

5. **BCE.forward 括号错位**
   - 写成了 `matmul(yᵀ, log p + matmul((1-y)ᵀ, log(1-p)))`：`+` 被括进第一个 matmul 的第二个操作数，`yᵀ` 把整项都乘了，算出来**不是**交叉熵；因为广播机制能跑通、还不报错（更隐蔽）。
   - 修正：两项分别 matmul 再相加（书式 3.5）。**教训：矩阵形式公式的括号即结构；写完用 1 个已知样例手算核对数值。**

6. **BCE.backward 少乘 `1/N`**
   - 损失除以 N，梯度自然也要除以 N（式 4.10）；少了只是"梯度整体放大 N 倍"的等效 lr 问题——容易忽略但和公式要对齐。

7. **MLP.backward 变量名全部错位**（`lg_a2` 实际存对 z2 的梯度……）
   - 功能上顺序对，但名字表达的是"对谁的梯度"完全错位，阅读/排错极易误导。
   - 修正建议：按"梯度是关于哪个张量"命名（如 `gz2 / ga1 / gz1 / gx`，见上方源码）。

8. **过时的报错缓存误导排查**
   - 保存的 `TypeError: unhashable type: 'list'` 是**改前版本**（Linear 的 params 键当时是 `['w']` 列表）的遗留，代码已改成字符串键——旧输出没清，让人以为还在报那个错。
   - **教训：notebook 的输出是"过去某次运行的照片"，改完代码要重跑，别被旧 cell 输出带偏。**

# 四、思考：初始化随机性 vs 学习率（附 15 次实验）

**现象**：相同参数反复运行，只有约 30% 出现"明显弯曲"的分割线；把学习率上调到 2 后效果显著改善。

**实验**（其余完全同 notebook：hidden=5、1000 轮全批量、15 个随机种子）：

| 学习率 | dev 准确率范围 | 中位数 | dev ≥ 0.95 次数 |
|---|---|---|---|
| 0.01 | 0.83 – 0.89 | ≈0.83 | 0 / 15 |
| 2.0 | 0.87 – 1.00 | ≈0.97 | 8 / 15 |

**1) 初始化随机性影响大吗？——大，但只在优化太弱时才"这么"大。**
- 训练是**确定性全批量 GD**：固定初始化+固定数据，结果完全确定、没有随机扰动帮忙跳出坏区域；每次运行的随机性只来自 `randn` 初始化（以及 `make_moons` shuffle 造成 train/dev 子集变化）。
- `lr=0.01` 时 GD 对**几乎所有**初始化都停在差解（15 次全在 0.83–0.89），网络像"冻住"——最终模型 ≈ 初始点所在的那个局部盆地。于是每次运行的形态≈"从损失面上随机抽了一个盆地"：抽到能长出弯曲边界的盆地就明显弯曲（~30%），否则欠拟合歪斜。**初始化确实决定落哪个盆地，但小学习率才是把盆地影响放大成"运气"的原因。**

  **2) lr=2 显著改善说明什么？——说明失败不是容量/数据问题，而是步长尺度严重失配（欠优化）。**
- 梯度被 `1/N`（N=799）平均、特征量级 ~1，`dR/dW` 各元素通常 ≪1；`lr=0.01` 时每步权重移动 ~1e-3，1000 轮根本走不动 → 梯度尺度与步长不匹配（条件数差）。
- `lr=2` 让有效步长进入与权重/特征同量级的范围，GD 能真正穿过平坦区/盆地，多数初始化收敛到同一条好边界（中位 0.97）。**"调大 lr 就能跑好"反证了问题出在优化步长而非模型。**

  **3) 提醒**：`lr=2` 能 work 是因为全批量梯度被平均得很小、logistic 损失光滑有界，它已接近稳定上限，再大会震荡/发散。更稳的替代：lr 提到 0.1–0.5 留裕量、加 **momentum / 小批量 SGD**（随机性天然削弱"初始化决定命运"）、输入标准化、或隐藏层换 **ReLU** 改善梯度条件。

# 五、与上一次练习的对照

上一次是**单层** Logistic（边界必为直线，moons 上 ~0.8 封顶，靠多项式升维救）；这次是**两层 + 手工链式反向**（边界天然可弯），核心新东西 = 公式 ②③ 的**算子局部反向规则 + ④ 的逆序调用链**，以及"状态归属（params/grads 属于每层、optimizer 只遍历更新）、张量轴与公式维度对齐、旧输出缓存会骗人"这几条放之四海的教训。
