# 一、公式总结

**记号**：输入 $\boldsymbol X\in\mathbb R^{N\times C_{in}\times H\times W}$（$N$ 批量、$H\times W$ 空间尺寸），卷积核 $\boldsymbol W\in\mathbb R^{C_{out}\times C_{in}\times U\times V}$，偏置 $\boldsymbol b\in\mathbb R^{C_{out}}$。

**① 二维互相关**（书 §5.1；PyTorch 的 `conv2d` 做的就是互相关，**核不翻转**）：

$$
Y_{i,j}=\sum_{u=0}^{U-1}\sum_{v=0}^{V-1}X_{i+u,\;j+v}\,W_{u,v}+b
$$

> 手写 `Conv2d.forward` 里"滑窗 → 逐元素乘 → 求和"正好就是这个式子，没有翻转，所以和 `nn.functional.conv2d` 的数值能对上（实测最大差 $9.5\times10^{-7}$，纯浮点误差）。如果要写成严格意义的卷积，核要先 `flip(0).flip(1)`。

**② 输出尺寸**（书式(5.1)，$p$ 填充、$s$ 步长、$k$ 核边长）：

$$
H_{out}=\left\lfloor\frac{H+2p-k}{s}\right\rfloor+1,\qquad W_{out}=\left\lfloor\frac{W+2p-k}{s}\right\rfloor+1
$$

**③ 拉普拉斯边缘检测算子**（8 邻域版）：

$$
\nabla^2 I(i,j)\;\approx\;8\,I(i,j)-\sum_{(u,v)\in\mathcal N_8(i,j)}I(i+u,\,j+v)
\quad\Longleftrightarrow\quad
\boldsymbol W_{\text{lap}}=\begin{bmatrix}-1&-1&-1\\-1&8&-1\\-1&-1&-1\end{bmatrix}
$$

> **核元素和 $=0$ 是这套算子的全部要害**：元素和为 0 ⟺ 对任意常数平面（平坦区域）响应恒为 0 ⟺ 输出只反映"曲率/轮廓"，与亮度无关。反过来，元素和不为 0 的核会把亮度也卷进来（见踩坑 B-1，随机核看起来像"负片"就是这个原因）。

**④ 参数量**（本练习的 LeNet-5，输入 $[N,1,28,28]$）：

| 层 | 配置 | 输出形状 | 权重形状 | 参数量 |
|---|---|---|---|---|
| conv1 | $3\times3$, $p=1$ | $[N,6,28,28]$ | $[6,1,3,3]$ | $6\cdot1\cdot9+6=60$ |
| pool1 | MaxPool $2\times2$ | $[N,6,14,14]$ | — | 0 |
| conv2 | $5\times5$ | $[N,12,10,10]$ | $[12,6,5,5]$ | $12\cdot6\cdot25+12=1812$ |
| pool2 | MaxPool $2\times2$ | $[N,12,5,5]$ | — | 0 |
| flatten | — | $[N,300]$ | — | 0 |
| linear1 | $300\to80$ + ReLU | $[N,80]$ | $[80,300]$ | $24080$ |
| linear2 | $80\to10$ | $[N,10]$ | $[10,80]$ | $810$ |
| **合计** | | | | **26762** |

> 记住这个数：训练集只有 1000 张时，参数 : 样本 $\approx 27:1$——这是第四节的起点。

**⑤ softmax + 交叉熵的合成梯度**（与第二部分式①同一件事）：

$$
\hat y_{nc}=\frac{\exp z_{nc}}{\sum_{c'}\exp z_{nc'}},\qquad
\mathcal R=-\frac1N\sum_{n=1}^{N}\log\hat y_{n,y_n},\qquad
\delta\boldsymbol Z=\frac{\partial\mathcal R}{\partial\boldsymbol Z}=\frac1N\Big(\hat{\boldsymbol Y}-\boldsymbol Y_{\text{one-hot}}\Big)
$$

> `nn.CrossEntropyLoss` 内部自带 `log_softmax`，所以**喂进去的必须是 logits（未过激活的原始输出）**。这条在踩坑 B-2 里是要害：末层再套一个 ReLU，等于把 logits 的一半取值域切掉。

**⑥ 小批量更新**（一个 epoch 走 $\lceil N/B\rceil$ 次，本练习 $N=20000,B=64$ → 每轮 313 次）：

$$
\boldsymbol\theta\leftarrow\boldsymbol\theta-\eta\cdot\frac{1}{B}\sum_{n\in\mathcal B}\frac{\partial\mathcal R_n}{\partial\boldsymbol\theta}
$$

**⑦ 最优保存与早停的判定**：

$$
\text{improved}=\begin{cases}m_{dev}>\text{best},&\texttt{higher\_is\_better}\\[2pt] m_{dev}<\text{best},&\text{otherwise}\end{cases}
\qquad
\texttt{no\_improve}\ge\texttt{patience}\;\Longrightarrow\;\text{early stop}
$$

> `improved` 为真时才 `save(best_path)`；**`best_path` 没传就什么都不会存**——这一条在踩坑 B-4 里直接吃掉了 0.5 个百分点。

**⑧ "全局统一 seed"到底要钉住几处**：

| 随机源 | 由谁控制 |
|---|---|
| Python `random` | `random.seed(SEED)` |
| NumPy | `np.random.seed(SEED)` |
| torch CPU / CUDA 全局 RNG（决定权重初始化） | `torch.manual_seed(SEED)` + `torch.cuda.manual_seed_all(SEED)` |
| `DataLoader(shuffle=True)` 的抽样顺序 | 独立的 `torch.Generator().manual_seed(SEED)` |
| **cuDNN 卷积算法选择** | `torch.backends.cudnn.deterministic = True`、`benchmark = False` |

> 前四行是"设种子"，第五行才是"复现"。cuDNN 默认会给卷积挑带 `atomicAdd` 的实现，浮点加法不满足结合律 → 同一份代码两次跑，权重从第 4 个 epoch 起在小数末位分叉。详见踩坑 D。

# 二、完整代码

> 可视化单元（训练曲线、单样本前向过程图、第一层卷积核图）略。

```python
# ---------------- imports ----------------
import torch
import torch.nn as nn
from pathlib import Path

# ---------------- global seed ----------------
import random

import numpy as np

SEED = 3          

def set_seed(seed=SEED):
    """Pin random / numpy / torch(CPU+CUDA) to the same seed."""
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    torch.cuda.manual_seed_all(seed)
    
    torch.backends.cudnn.deterministic = True
    torch.backends.cudnn.benchmark = False
    return seed


set_seed(SEED)
print(f'global seed = {SEED}')

# ---------------- Runner ----------------
class Runner():
    def __init__(self, model, loss_fn, metric_fn, optimizer, higher_is_better=False, device=None):
        self.model = model
        self.loss_fn = loss_fn
        self.metric_fn = metric_fn
        self.optimizer = optimizer
        self.higher_is_better = higher_is_better
        self.device = torch.device(device) if device is not None else None
        if self.device is not None:
            self.model.to(self.device)
        self.history = {
            'train_loss': [], 'train_metric': [],
            'dev_loss': [], 'dev_metric': [],
            'batch_loss': []
        }

    def _to_device(self,batch):
        if self.device is not None:
            return tuple(t.to(self.device) if torch.is_tensor(t) else t for t in batch)
        else: 
            return batch

    def fit(self, train_loader, dev_loader = None, num_epochs=100, log_every = 1, patience = None, seed = None, best_path = None):
        if patience is not None and patience < 1:
            print('invalid "patience"')
        if log_every is not None and log_every < 1:
            print('invalid "log_every"')
        if seed is not None:
            torch.manual_seed(seed)
        best = -float('inf') if self.higher_is_better else float('inf')
        no_improve = 0
        

        for epoch in range(num_epochs):
            self.model.train()
            batch_loss, batch_metric, n = 0.0, 0.0, 0
            for batch in train_loader:
                *inputs, y = self._to_device(batch)
                self.optimizer.zero_grad()
                out = self.model(*inputs)
                loss = self.loss_fn(out,y)
                metric = self.metric_fn(out,y)
                loss.backward()
                self.optimizer.step()
                batch_size = y.shape[0]
                batch_loss += loss * batch_size
                batch_metric += metric * batch_size
                n += batch_size
                self.history['batch_loss'].append(loss)
            train_loss = batch_loss / n
            train_metric = batch_metric / n
            self.history['train_loss'].append(train_loss)
            self.history['train_metric'].append(train_metric)
            
            should_log = log_every is not None and ((epoch+1) % log_every == 0) 
            should_stop = False
            improved = 0
            if dev_loader is not None:
                dev_loss, dev_metric = self.evaluate(dev_loader)
                self.history['dev_loss'].append(dev_loss)
                self.history['dev_metric'].append(dev_metric)
                improved = (dev_metric > best) if self.higher_is_better else (dev_metric < best)
                if improved:
                    best = dev_metric
                    no_improve = 0
                    if best_path is not None:
                        self.save(best_path)
                else:
                    no_improve += 1
                if should_log:
                    mark = '*'if improved else ''
                    print(f'epoch {epoch+1:2d}: '
                          f'train_loss={train_loss:.4f} train_metric={train_metric:.4f} '
                          f'dev_loss={dev_loss:.4f} dev_metric={dev_metric:.4f} '
                          f'{mark}')
                if patience is not None and(no_improve >= patience):
                    if log_every is not None:
                        print(f'early stop at epoch {epoch+1}')
                    should_stop = True
            elif should_log:
                print(f'epoch {epoch+1:4d} train_loss={train_loss:.4f}')
            if should_stop:
                break

    @torch.no_grad()
    def evaluate(self, loader):
        was_training = self.model.training
        self.model.eval()
        try:
            batch_loss, batch_metric, n = 0.0, 0.0, 0
            for batch in loader:
                *inputs, y = self._to_device(batch)
                loss = self.loss_fn(self.model(*inputs), y)
                metric = self.metric_fn(self.model(*inputs), y)
                batch_size = y.shape[0]
                batch_loss += loss * batch_size
                batch_metric += metric * batch_size
                n += batch_size
            dev_loss = batch_loss / n
            dev_metric = batch_metric / n if self.metric_fn is not None else dev_loss
            return dev_loss, dev_metric
        finally:
            self.model.train(was_training)
                
    def save(self,best_path):
        Path(best_path).parent.mkdir(parents = True, exist_ok = True)
        torch.save(self.model.state_dict(), best_path)

    def load(self, path):
        state = torch.load(path, weights_only = True, map_location = self.device)
        self.model.load_state_dict(state)

# ---------------- Conv2d from scratch ----------------
class Conv2d():
    def __init__(self, weight, padding = 0, stride = 1):
        self.weight = weight 
        self.padding = padding
        self.stride = stride

    def forward(self,X):
        new_X = nn.functional.pad(X, pad=(self.padding,self.padding,self.padding,self.padding), mode='constant', value = 0)
        u,v = self.weight.shape
        output_w = (new_X.shape[1] - u) // self.stride + 1
        output_h = (new_X.shape[2] - v) // self.stride + 1
        output = X.new_zeros((X.shape[0],output_w,output_h))
        for i in range(output_w):
            for j in range(output_h):
                output[:,i,j] = (torch.sum(
                    new_X[:, self.stride * i: self.stride * i + u, self.stride * j:self.stride * j + v] * self.weight, dim = (1,2)
                ))
        return output

# ---------------- Data + Laplacian edge detection ----------------
from pathlib import Path
from torchvision import datasets
from torchvision.transforms import Compose, Resize, ToTensor, Normalize

CACHE = str(Path.home() / '.cache' / 'torch_data')
MNIST = datasets.MNIST(
    CACHE, train = True, download = True, transform=ToTensor()
)
MNIST_test = datasets.MNIST(
    CACHE, train=False, download = True, transform=ToTensor()
)
img, label = MNIST[0]

# --laplacian convolution--
laplacian = torch.tensor([[-1,-1,-1],[-1,8,-1],[-1,-1,-1]])
conv = Conv2d(laplacian, 1, 1)
l_img = conv.forward(img)

# ---------------- Subset sampling ----------------
from torch.utils.data import DataLoader, Subset
train_dataset = Subset(MNIST, range(20000))
dev_dataset = Subset(MNIST, range(20000, 20200))
test_dataset = Subset(MNIST_test, range(200))

# ---------------- LeNet-5 ----------------
class LeNet_5(nn.Module):
    def __init__(self):
        super().__init__()
        self.conv1 = nn.Conv2d(1,6,kernel_size=(3,3),stride =1, padding= 1) # 6*28*28
        self.pool1 =nn.MaxPool2d(kernel_size=(2,2)) # 6*14*14
        self.conv2 = nn.Conv2d(6,12,kernel_size= 5) # 12*10*10
        self.pool2 = nn.MaxPool2d(kernel_size=(2,2))# 12*5*5
        self.linear1 = nn.Linear(12*5*5, 80)
        self.linear2 = nn.Linear(80,10)
        self.ac = nn.functional.relu
        
    def forward(self, x):
        x = self.pool1(self.conv1(x))
        x = self.pool2(self.conv2(x))
        x = self.ac(self.linear1(x.flatten(1)))   # flatten(1): flatten C,H,W only, keep batch dim
        x = self.linear2(x.flatten(1))            # no activation on last layer: return logits for CrossEntropyLoss
        return x

# ---------------- Loaders + training ----------------
def make_loader(dataset, batch_size=64, shuffle=True):
    """Each loader gets its own seeded Generator so shuffle order is reproducible."""
    return DataLoader(dataset, batch_size=batch_size, shuffle=shuffle,
                      generator=torch.Generator().manual_seed(SEED))


train_loader = make_loader(train_dataset)
dev_loader = make_loader(dev_dataset)
test_loader = make_loader(test_dataset)

# Init
from nndl import accuracy

set_seed(SEED)   
model = LeNet_5()
loss_fn = nn.CrossEntropyLoss()
metric_fn = accuracy
optimizer = torch.optim.SGD(model.parameters(), lr=0.01)
runner = Runner(model, loss_fn, metric_fn, optimizer, higher_is_better=True, device='cuda')

runner.fit(train_loader=train_loader, dev_loader=dev_loader, num_epochs=50, log_every=1,
           patience=10, best_path='checkpoint/lenet5_best.pt', seed=SEED)
```

# 三、踩坑记录

低级错误小表格：

| 错误 | 修正 |
|---|---|
| `x.flatten()` 缺 `start_dim=1`，batch 维被压平 | `x.flatten(1)` |
| `and` 短路顺序写反，`%` 先执行导致 `TypeError` | 安全判断放前面：`log_every is not None and ...` |
| 自定义类名 `Conv2d` 遮蔽 `torch.nn.Conv2d` | 改名 `MyConv2d` |
| 零填充 + 零和核在图像边缘造出假边 | `padding_mode='replicate'` |
| `history` 存带梯度的 tensor，计算图不释放 | `loss.item()` |
| `evaluate` 里每个 batch 前向两次 | 先 `out = self.model(*inputs)` 再分别算 loss 和 metric |

中级错误：

**1. 模型没有搬到 GPU**

错误代码：

```python
class Runner():
    def __init__(self, model, ..., device=None):
        self.device = torch.device(device)
        # missing: self.model.to(self.device)
```

`_to_device` 把 batch 送到了 cuda，但模型权重留在 cpu，报 `Input type (torch.cuda.FloatTensor) and weight type (torch.FloatTensor) should be the same`。注意 optimizer 是在 `Runner` 之前用 `model.parameters()` 建的，不需要重建——`nn.Module.to()` 就地替换 `param.data`，`Parameter` 对象本身不变。

修正代码：

```python
if self.device is not None:
    self.model.to(self.device)
```

**2. 拉普拉斯核定义了却没传进去**

错误代码：

```python
class Conv2d():
    def __init__(self, kernel_size, ...):
        self.weight = torch.randn(kernel_size, kernel_size)  # random init, cannot pass external kernel

laplacian = torch.tensor([[-1,-1,-1],[-1,8,-1],[-1,-1,-1]])
conv = Conv2d(3, 1, 1)      # laplacian forgotten
l_img = conv.forward(img)   # uses random kernel
```

输出图像看起来像原图的负片而非轮廓。实测随机核元素和为 −2.324（拉普拉斯核应为 0），随机核响应与原图的相关系数为 −0.657（强负相关即负片）。核元素和是否为 0 决定了输出是"边缘"还是"亮度图"——元素和为 0 的核对平坦区域响应恒为 0，输出只反映曲率；不为 0 则把亮度也卷进来。

修正代码：

```python
class Conv2d():
    def __init__(self, weight, padding=0, stride=1):
        self.weight = weight  # kernel passed as constructor arg

conv = Conv2d(laplacian, 1, 1)
```

**3. 末层接了 ReLU**

错误代码：

```python
def forward(self, x):
    ...
    x = self.ac(self.linear2(x.flatten(1)))  # no activation on last layer
    return x
```

`nn.CrossEntropyLoss` 内部实现 softmax，无需激活。

修正代码：

```python
def forward(self, x):
    ...
    return self.linear2(x.flatten(1))  # return logits directly
```

**4. `best_path` 没传，最优权重被丢弃**

`runner.fit(...)` 调用时没传 `best_path`，`if best_path is not None: self.save(best_path)` 永不执行。日志显示最后一次 dev 最优在第 16 轮（0.8850），之后 100 轮再没涨过，但训练结束时内存里是第 116 轮的模型（dev 0.8800）。早停和最优保存是配套的，只开一半等于白训练 100 轮。

# 五、与上一次练习的对照

第二部分是全连接 + autograd + 小批量，这次把层从 `Linear` 换成 `Conv2d`，数据从 Iris 换成 MNIST。核心区别：卷积是局部连接 + 权重共享，参数量与图像尺寸无关；输入是四维 $[N,C,H,W]$，空间结构必须保住（`flatten` 必须写 `start_dim=1`）。工程上新增了 best-checkpoint + early stop + 设备搬运 + 全局可复现。
