# 问题描述
---
你正在为一台深空探测器编写飞行计算机的核心状态机。探测器有四个严格的操  
作状态：待机（IDLE）、发射中（LAUNCHING）、在轨运行（ORBITING）和深  
度睡眠（HIBERNATING）。为了保证飞行安全，状态的切换必须遵循严格的物  
理逻辑（例如，不能从“待机”直接跳跃到“在轨运行”）。  
 考察内容：  
一、 强类型枚举（Enum Class）的状态管理。  
二、 类的封装与状态转移的安全保护。  
三、 成员函数的重载与默认参数特性。  
要求：  
1) 使用 enum class 定义探测器的四种状态。  
2) 设计一个 SpaceProbe 类，私有成员包含当前状态（初始必须为 IDLE）和  
   探测器名称（字符串）。  
3) 提供成员函数实现状态切换：launch()（只能从 IDLE 切换）、enterOrbit()（只  
   能从 LAUNCHING 切换）、hibernate()（只能从 ORBITING 切换）。如果强  
   行进行非法切换，需打印错误警告并保持原状态。  
4) 提供一个名为 transmitTelemetry() 的成员函数，用于模拟发送遥测数据。该  
   函数要求利用默认参数：如果不传参数，默认以 100% 的发射功率（int power  
   = 100）发送；如果传入具体功率值，则按该功率发送。  
   输入/输出规范：  
- 输入：main 函数中硬编码的方法调用。  
- 输出：打印状态切换的成功或失败信息，以及遥测数据的功率。  
   测试样例：  
- 常规样例：  
   依 次 调 用 launch(), enterOrbit(), transmitTelemetry(), transmitTelemetry(50),  
   hibernate()。  
```
Expected Output:  
[Success] Probe launched.  
[Success] Entered orbit.  
Transmitting data at 100% power.  
Transmitting data at 50% power.  
[Success] Entered hibernation.  
```
- 边界样例（非法状态转移）：  
   创建一个新对象，直接调用 enterOrbit()。  
```
Expected Output:  
[Error] Invalid state transition to ORBITING.
```

# 我的程序
---
```cpp
#include <iostream>
#include <string>

enum class State
{
	IDLE,LAUNCHING,ORBITING,HIBERNATING
};

class SpaceProbe
{
private:
	std::string m_name;
	State state{ State::IDLE };

public:
	SpaceProbe(std::string name)
		:m_name{ name }, state{ State::IDLE }
	{

	}

	void launch()
	{
		if (state == State::IDLE) {
			state = State::LAUNCHING;
			std::cout << "[Success] Probe launched." << std::endl;
		}
		else std::cout << "[Error] LAUNCH UNAVAILABLE" << std::endl;
	}
	void enterOrbit()
	{
		if (state == State::LAUNCHING) {
			state = State::ORBITING;
			std::cout << "[Success] Entered orbit." << std::endl;
		}
		else std::cout << "[Error] ENTERORBIT UNAVAILABLE" << std::endl;
	}
	void hibernate()
	{
		if (state == State::ORBITING) {
			state = State::HIBERNATING;
			std::cout << "[Success] Entered hibernation." << std::endl;
		}
		else std::cout << "[Error]HIBERNATE UNAVAILABLE" << std::endl;
	}

	void transmitTelemetry(int power)
	{
		if (state == State::ORBITING && power > 0 && power <= 100)
		{
			std::cout << "Transmitting data at " << power << "% power." << std::endl;
		}
		else std::cout << "[Error] TRANSMIT UNAVAILABLE."<<std::endl;
	}
	
	void transmitTelemetry()
	{
		if (state ** State::ORBITING )
		{
			std::cout << "Transmitting data at 100% power." << std::endl;
		}
		else std::cout << "[Error] TRANSMIT UNAVAILABLE."<<std::endl;
	}
};

int main()
{
	SpaceProbe izwarm("izwarm001");
	izwarm.launch();
	izwarm.enterOrbit();
	izwarm.transmitTelemetry(20);
	izwarm.transmitTelemetry();
	izwarm.hibernate();
}
```

# 参考程序
---
```cpp
#include <iostream>
#include <string>

// 强类型枚举：四种探测器状态
enum class State {
    IDLE,
    LAUNCHING,
    ORBITING,
    HIBERNATING
};

class SpaceProbe {
private:
    std::string m_name;
    State m_state;

public:
    // 构造函数：探测器初始状态必须为 IDLE
    SpaceProbe(const std::string& name)
        : m_name{name}, m_state{State::IDLE}
    { }

    // IDLE → LAUNCHING
    void launch() {
        if (m_state ** State::IDLE) {
            m_state = State::LAUNCHING;
            std::cout << "[Success] Probe launched." << std::endl;
        } else {
            std::cout << "[Error] Invalid state transition to LAUNCHING." << std::endl;
        }
    }

    // LAUNCHING → ORBITING
    void enterOrbit() {
        if (m_state == State::LAUNCHING) {
            m_state = State::ORBITING;
            std::cout << "[Success] Entered orbit." << std::endl;
        } else {
            std::cout << "[Error] Invalid state transition to ORBITING." << std::endl;
        }
    }

    // ORBITING → HIBERNATING
    void hibernate() {
        if (m_state == State::ORBITING) {
            m_state = State::HIBERNATING;
            std::cout << "[Success] Entered hibernation." << std::endl;
        } else {
            std::cout << "[Error] Invalid state transition to HIBERNATING." << std::endl;
        }
    }

    // 遥测发送：默认参数 power = 100，替代函数重载
    void transmitTelemetry(int power = 100) {
        std::cout << "Transmitting data at " << power << "% power." << std::endl;
    }
};

int main() {
    // ——— 常规样例 ———
    SpaceProbe probe1("Voyager-X");
    probe1.launch();
    probe1.enterOrbit();
    probe1.transmitTelemetry();       // 默认 100% 功率
    probe1.transmitTelemetry(50);     // 指定 50% 功率
    probe1.hibernate();

    std::cout << "-----------------" << std::endl;

    // ——— 边界样例（非法转移）———
    SpaceProbe probe2("Fail-Probe");
    probe2.enterOrbit();              // IDLE 下直接调用 → 错误

    return 0;
}
```

### **修改说明**

**1. 错误信息统一为题目格式**
原代码写的是"LAUNCH UNAVAILABLE""ENTERORBIT UNAVAILABLE"，完全不符合 Expected Output。正确格式必须是：

```
[Error] Invalid state transition to <TARGET_STATE>.
```

这样每个非法操作都能动态指出用户试图跳转到哪个状态，而不是只笼统地说"不可用"。

**2. 用默认参数取代两个 `transmitTelemetry` 重载**
****原代码写了两个函数：`transmitTelemetry(int)` 和 `transmitTelemetry()`。题目明确要求利用默认参数，所以合并为一个：****

```cpp
void transmitTelemetry(int power = 100);
```

不传参时 `power` 自动为 100，传参时使用指定值。代码量减半，接口更清晰。

**3. 去掉 `transmitTelemetry` 中多余的状态限制和功率校验**
原代码要求"只有在 ORBITING 状态且功率在 1~100 之间"才能发送遥测，但题目从未提过这类限制——它只说"模拟发送遥测数据"。这些额外检查不仅偏离题意，还会导致边界样例的预期输出无法正确产生。简化后直接打印即可。

**4. 调整 `main` 中的测试调用顺序**
按 Expected Output，正确的顺序是先默认 100%，后指定 50%：

```cpp
probe1.transmitTelemetry();       // 100%
probe1.transmitTelemetry(50);     // 50%
```

**5. 移除 `state` 的类内冗余初始化**
原代码同时在类内 `State state{State::IDLE}` 和构造函数初始化列表 `state{State::IDLE}` 中赋值——**前者是多余的**。构造函数初始化列表会覆盖类内初始值，保留一处即可。
