# 问题描述： 

编写一个 C++ 程序，实现摄氏温度与华氏温度的相互转换。
- 要求：
> 1. 使用逗号表达式完成温度转换计算 Tip：result = (cout << ” 正在转换摄氏温度到华氏温度...”, temp * 9.0/ 5.0 + 32); //注意理解逗号表达式的返回结果！ 
> 2. 程序能够选择转换方向 
> 3. 用户可以输入温度值并看到转换结果 

Tip：摄氏转华氏 F = C × 9/5 + 32；华氏转摄氏 C = (F - 32) × 5/9。

# Note
- 逗号表达式一定用`()`括起；
- ([逗号表达式](/notes/cpp/tips/逗号表达式/))
(expression1, expression2, expression3, ..., expressionN)
- ([位运算](/notes/cpp/tips/位运算/))
- Why const char*:
* `const char` 是一个**单字符**类型（1 字节），而你调用时传入的是字符串字面量
* `"..."` 在 C++ 中的类型是 `const char[N]`（字符数组），会退化为 `const char*`
* 如果想更现代一点，也可以用 `std::string_view`

```cpp
  	#include <string_view>
   	double qna(std::string_view question) { ... }
```


# 我的程序

```cpp
#include <iostream>
double qna(const char *question) //why const char *
{
	std::cout << question;
	double answer{ 0 };
	std::cin >> answer;
	return answer;
}

int main() 
{
	double choice{ qna("摄氏转华氏[0] 华氏转摄氏[1]:") };
	if (!choice)
	{
		double temp{ qna("输入摄氏温度：") };
		double result{ temp * 9 / 5 + 32 };
		std::cout << "对应华氏温度：" << result << std::endl;
	}
	else if (choice)
	{
		double temp{ qna("输入华氏温度：") };
		double result{ (temp - 32) * 5 / 9 };
		std::cout << "对应摄氏温度：" << result << std::endl;
	}
}
```

# 参考程序
```cpp
#include <iostream>
using namespace std;
int main() {
    double temp, result;
    int choice;

    cout << "温度转换程序" << endl;
    cout << "1. 摄氏 → 华氏" << endl;
    cout << "2. 华氏 → 摄氏" << endl;
    cout << "请选择: ";
    cin >> choice;
    cout << "请输入温度值: ";
    cin >> temp;
    if (choice == 1) {
        // 使用逗号表达式：摄氏转华氏 \( F = C \times 9/5 + 32 \)
        result = (cout << "正在转换摄氏温度到华氏温度...", temp * 9.0 / 5.0 + 32);
        cout << temp << "°C = " << result << "°F" << endl;
    } else {
        // 使用逗号表达式：华氏转摄氏 \( C = (F - 32) \times 5/9 \)
        result = (cout << "正在转换华氏温度到摄氏温度...", (temp - 32) * 5.0 / 9.0);
        cout << temp << "°F = " << result << "°C" << endl;
    }
    return 0;
}
```
