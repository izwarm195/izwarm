### **C++ 创建对象的两种方式：栈 vs 堆**

---

The Cherno 在这期视频中讲解了 C++ 中实例化对象的两种方式，核心区别在于**对象的内存从哪来**。

---

### **方式一：栈上创建（推荐优先使用）**

```cpp
Entity entity;                 // 调用默认构造函数
Entity entity("Cherno");       // 调用带参构造函数
```

- 对象分配在**栈**上，内存由**作用域自动管理**
- 变量离开作用域（函数结束、`}` 等）时，对象自动销毁、内存自动释放
- **最快、最省心**——不需要手动释放
- 这是 C++ 独有的优势，Java/C# 做不到（Java 所有对象都在堆上）

  ---

### **方式二：堆上创建**

```cpp
Entity* entity = new Entity("Cherno");   // 返回指针
// 使用箭头操作符访问成员
entity->getName();
// 用完后必须手动释放
delete entity;
```

- `new` 在堆上分配内存，返回**指针**
- 对象的生命周期**由你手动控制**——它在堆上一直存在，直到你调用 `delete`
- 忘记 `delete` 会导致**内存泄漏**

  ---

### **什么时候必须用堆？**

| 场景 | 说明 |
|---|---|
| 对象需要活得比作用域更久 | 比如函数返回后，对象还需要继续存在 |
| 对象太大，栈放不下 | 栈通常只有 1\~2MB，大对象或大量对象需要放堆上 |

---

### **核心总结**

> 能用栈就用栈——它更快、更安全、自动管理。只有在对象需要跨作用域存活或栈空间不够时，才用堆。

Cherno 特别强调：从 Java/C# 转到 C++ 的人习惯到处 `new`，这在 C++ 中是**坏习惯**——不仅更慢，还得自己 `delete`，容易出问题。
