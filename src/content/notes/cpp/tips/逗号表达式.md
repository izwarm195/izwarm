## 逗号表达式

逗号表达式是由逗号运算符 `,` 连接的一组表达式，按**从左到右**的顺序依次求值，最终结果为**最后一个表达式的值**。

完整语法格式：

```cpp
(expression1, expression2, expression3, ..., expressionN)
```

整个逗号表达式的值为最后一个表达式 `expressionN` 的值。

示例：

```cpp
#include <iostream>
using namespace std;
int main() {
    // 基本逗号表达式
    int a = 5;
    int result = (a += 2, a * 3); // 先执行a+=2，然后计算a*3
    cout << "result = " << result << endl; // 输出21
    cout << "a = " << a << endl; // 输出7

    // 多个表达式
    int x = 1, y = 2, z = 3;
    int final = (x++, y++, z++, x + y + z);
    cout << "final = " << final << endl; // 输出9(2+3+4)
    cout << "x=" << x << ", y=" << y << ", z=" << z << endl; // x=2, y=3, z=4
    return 0;
}
```

> <img class="callout-badge" src="/media/icons/lightbulb.svg" alt="tip">**注意**
> 逗号表达式一定要用 `()` 括起，结果取最后一个表达式的值。
